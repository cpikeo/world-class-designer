# J4 · Typography — 排印（Typography Director 的全部手艺）

> 排印是设计里最诚实的手艺：字体、字距、行距、对齐、基线、比例、层级——
> 每一项都可被测量，也都必须被判断。参数是区间 + 理由（J1 §3.3）。
> 空间与网格归 J2；数字与字段的语义判断归 J5/J7，手艺归这里。

---

## 0. 一案一声（One Voice per Case）

| 声音 | 配对思路 | 性格 |
|:---|:---|:---|
| **Swiss 客观** | Grotesque 无衬线单一家族（Helvetica Now / Inter / 苹方） | 中性、精确、齐左 |
| **Editorial 社论** | 社论衬线 + 人文无衬线（Lora/Times + Inter；中文：思源宋 + 思源黑） | 智性、叙事、旁注 |
| **Report 咨询** | 几何/新怪诞无衬线 + 等宽数字（Inter + tabular figures） | 冷静、数据、可信 |
| **Luxury 静奢** | 高对比衬线 + 轻无衬线（Didot/Cormorant + Inter Light） | 克制的贵气 |
| **Tech 精密** | 几何无衬线 + 等宽标识（Outfit + JetBrains Mono） | 工程、理性 |
| **Cultural 在地** | 在地衬线/手写 + 温润无衬线 | 温度、人文 |

- **一主一辅为限**：主声定正文与主张，辅声只做对照（数字、引文、标注）。
- **声音统一是底线**：Swiss 网格 + 装饰衬线 + 拟物图标 = 即刻廉价（J6 §6）。
- 中文参考：标题思源宋体/黑体，正文思源黑体/苹方；中西文混排细则见 §5。

## 1. 字号阶与比例（Scale）

- **一案一阶，禁随手字号。** 参考阶梯：
  `特大主张 (48-72) → 页标题 (28-40) → 小节 (18-22) → 正文 (15-18) → 标签/眉题 (11-13) → 脚注/来源 (9-10)`
- **比例系统**（选一，写进判断卡，全案不换）：
  密档（报告/文档）小比值 **1.2**（层级多、落差缓）；中档（汇报/编辑）**1.25-1.333**；
  仪式档（海报/封面）大比值 **1.5-1.618**（层级少、落差狠）。
- **层级落差要诚实**：主角与次级视觉尺寸比 ≈ 2:1 以上；含糊 = 受众自己找主角。
- **大字压缩律**：≥48px 字距 `-0.02em ~ -0.05em`，行高 `0.95-1.15`——大字靠紧，气势才成立。
- **小字舒张律**：≤13px 标签字距 `0.08em ~ 0.18em`，大写/眉题全案统一。

---

## 2. 基线 · 行距 · 行长（Vertical Rhythm）

- 全案落在 **4pt/8pt 基线**上：行高取基线倍数（如 8px 基线，正文行高 24/26px）；
  段距、线距、块距同比例——"随手像素"是业余感的第一来源。
- 行距随字号反差：主张/大字 `0.95-1.15`；正文拉丁 `1.5-1.7`；中文 `1.7-1.9`。
- 行长：拉丁 45-75 字符；中文 20-40 汉字。
- **行距与行长耦合**：行长越长行距越松，越短越紧——先定行长，再修行距。

## 3. 微观排印（Micro-Typography —— 顶级与平庸的分界）

- **对齐**：正文齐左为默认；中文长文慎用两端对齐（字距河流）；数字列右对齐、
  文本列左对齐；小数竖向对齐用 tabular figures。
- **段首缩进 vs 段距**：二选一，全案统一（西文惯例段距；中文长文可用 2em 段首缩进配零段距）。
- **标点纪律**：悬挂标点用于引文与大字主张（标点出血不占版心）；中文避头尾必开；
  破折号/省略号成对完整；引号用排版引号（" "），不用直引号。
- **中西文混排**：中西文之间留约 1/4 em 间隙（或由字体特性处理，全案统一一种）；
  英文出现在中文句中字号 ×0.92 视觉对齐；数字与中文并置用 lining figures。
- **Rag 控制**（齐左文本右缘）：参差要有节奏，避免河流与阶梯；中文按字断行但避头尾，
  拉丁词与数字不拆行。
- **引文**：大字引文 ≤2 行最佳；引文与署名之间用留白或细线，不用引号装饰堆叠。

## 4. 数字与字段（Information Design 的手艺）

### 4.1 大数字（Big Number Pattern）
`数字(大, 半粗) + 单位(小, 基线对齐) + 限定词/口径(小) + 来源(更小, 灰)`
- 数字用 lining figures；表格/字段用 tabular figures 保证竖向对齐。
- 一页大数字 ≤4 个；只有一个数时**不要画图表**——排印它（J5 §2.1）。

### 4.2 字段行（Field-Label-Value）
`标签(小, 字距拉开, 中性色) ／ 值(大, 主色) ／ 注(小, 灰)`
- 字段行用**细分隔线**断行，不用卡片；标签列宽统一，值左对齐成轴。
- 表格：**无竖线**；横线 0.5-1px；数字右对齐、文本左对齐、表头小字距；
  行高宽松；来源行必有。

### 4.3 关键词与眉题
- 眉题（kicker）：栏目/章节语境，小字大字距，置于标题上方。
- 关键词强调用**字重或色阶**，不用下划线、不用荧光底、不用加大括号。

## 5. 层级装置（不止字号）

按"信号成本"从低到高使用，能用低层解决不升级：
1. **空隙**（分组靠距离）
2. **字重**（300/400/600 三档足够）
3. **色阶**（中性色 3-4 阶，见 J3）
4. **线**（细线断层级）
5. **字号**（最后动用最大信号）

装饰细节准入：任何线、点、框回答"删掉它损失什么"。答不出 → 删。

---

## 6. 排印底线（执行时）

- 一案 ≤2 个字体家族；字重档位 ≤4。
- 全案字号阶不破（判断卡为准）；基线对齐 4pt/8pt。
- 图标/数字/线的光学对齐：按视觉中心校准，不机械对齐外框。
- 禁忌：字距未判断的默认值、执行中随手微调字号、加粗当强调的唯一手段、
  中西文机械同号、标点悬在行首行尾。
