# 排印与多语言文字系统

排印要把语义、字形声音、文本块轮廓、层级、行长、断行、字重、间距、位置与色彩组织成可读、有辨识度的系统。

## 修正顺序

**内容与语义 → 信息层级 → 文本块和版心 → 字体角色与字形 → 断行及行长 → 行距/段距/字距 → 字号和细节。**

字号缩小、字距拉开和整段加粗不应成为默认补救。先判断问题出在文案、层级、容器还是字形执行。

## 建立文字角色，而不是堆砌字号

文字角色可包括主张、导航、解释、证据、标签或注释。通过占幅、位置、字重、字号、颜色和空间建立区别，不要求每个角色都换字体。

复杂项目为每个角色记录：语义职责、实际字体与回退、字重、典型尺度、行距/段距、断行规则和允许变化。只记录会影响复用的决定，不建立无人使用的庞大字级表。

字体应匹配品牌、内容、文化和媒介。个性若损害辨识度就是成本；新增字体必须承担现有字体无法合理承担的角色。

## 中文 / CJK 重点

- 按语义单位断行，避免拆分专名、术语、强关联词及数字/单位。
- 检查标点避头避尾、孤字尾行和多行标题轮廓；标题轮廓应帮助理解，不追求机械等长。
- 中文、拉丁字母、数字、数学符号与单位的字面高度、基线和视觉重量不同，名义字号一致不代表视觉一致。
- 不无差别拉开中文正文字距。标题字距结合字号、字体、字形密度和文本长度判断。
- 高密度页面先重组内容、分层和栏宽；不能为了整齐隐藏来源、单位、限定条件或脚注。
- 竖排和混合方向只在语言、文化和媒介合适时采用，并核实标点方向、字形和阅读顺序。

### 断行示例

标题“生成式 AI 基础设施正在进入回报验证期”不应把“生成式 AI”或“回报验证”拆到两行。优先按“生成式 AI 基础设施 / 正在进入回报验证期”组织语义；若实际字体和栏宽导致溢出，先调整文本块或精简文案，不靠任意断词解决。

## 拉丁文与多语言混排

拉丁文字需检查词距、连字、引号、破折号和断词；RTL 文字需检查方向、标点与双向混排；复杂脚本需确认字体塑形和组合符号正确。

混排先保证语言正确，再校准各脚本的视觉重量、基线、大小和间距。不要用伪文字装饰；精确标签、数字和图表文字应由排版工具生成。

多语言版本不能假定译文长度相近。使用真实文案检查扩张、收缩、换行、字体覆盖和容器变化，而不是只验证源语言。

## 数字、表格与注释

- 统一小数精度、单位、千分位、正负号和缺失值表达。
- 比较数字时检查位数和小数点对齐；需要时采用等宽数字，但先验证实际字体支持。
- 表头、单位、来源和注释应与数据建立明确关系，不能因缩小而失去可读性。
- 上标、脚注和交叉引用在最终格式中仍需可读、可定位。

## 常见故障与优先处理

| 故障 | 先查 | 优先动作 |
|---|---|---|
| 标题不突出 | 文案是否明确、占幅是否足够、位置是否有效 | 精简主张并调整文本块与位置，再调字号和字重 |
| 标题像一堵墙 | 语义是否过长、断行是否任意 | 改写或拆分文案，设计断行和文本块轮廓 |
| 正文难读 | 行长、密度、对比、行距、阅读距离 | 重分组、调栏宽与文本块，再微调字级 |
| 中文标题断行生硬 | 语义单位、专名、标点及标题形状 | 先改文案或栏宽，再控制断行 |
| 中西文混排参差 | 字面高度、基线、字体回退和字重映射 | 在实际渲染环境校准，不只看字体名称 |
| 数字列不齐或难比较 | 位数、小数精度、单位位置和数字宽度 | 统一格式、精度、单位与对齐方式 |
| 页面充满近似字号 | 文字角色是否真的不同 | 合并无实质差异的层级，用空间与位置建立关系 |

## 媒介与验证

屏幕界面检查断点、缩放、文本扩张与可访问性；PPT 考虑投影距离和演示节奏；长文档检查连续阅读、分页和注释系统；海报按真实观看距离检查标题与关键信息。

重要作品应在目标环境渲染，检查字体加载、字符覆盖、字重映射与回退。源文件正常不代表 PDF、其他系统或浏览器中正常；没有实际检查时明确标注未验证。
