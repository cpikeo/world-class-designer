# 字体系统与排印执行

本文件拥有：字体性格判断与选择、文字角色、层级编码手段、尺度关系、行长行距、断行与文本块轮廓、中西文混排、数字与注释、排印肌理、编辑性排印元素。版面结构与层次分工见 `02`。

排印要把语义、字形性格、文本块轮廓、层级、行长、断行、字重、间距、位置与色彩组织成可读、有辨识度的系统。

## 一、修正顺序

**内容与语义 → 信息层级 → 文本块与版心 → 字体角色与字形 → 断行与行长 → 行距/段距/字距 → 字号与细节。**

字号缩小、字距拉开、整段加粗都不应成为默认补救。先判断问题出在文案、层级、容器还是字形执行。**一页文字读不顺，八成原因不在字体。**

## 二、怎么读一款字体

不要用形容词选字体（“优雅”“大气”“高级”无法执行）。看六个可观察变量：

| 变量 | 观察什么 | 意味着什么 |
|---|---|---|
| 骨架与中宫 | 笔画是否向中心聚；字面周围留白多少 | 中宫紧 → 内敛、正式、小字耐读；中宫松 → 开阔、有力、适合远读 |
| 字面与字重分布 | 字面积占字身比例；笔画粗细是否均匀 | 字面大 + 均匀 → 密度高，适合信息型；字面小 + 有对比 → 从容，适合文学型 |
| 横竖对比 | 横画与竖画的粗细差 | 对比明显（宋/明朝）→ 有书写血缘、庄重、静态；等粗（黑体/无衬线）→ 中性、当代、不抢内容 |
| 笔形起收 | 顿笔、挑、钩、切角、圆头 | 锐利起收 → 传统、有工具痕迹；平切圆头 → 工业化、当代 |
| 重心高低 | 字的视觉中心在字身中的位置 | 重心高 → 轻、上升，适合标题；重心低 → 稳、沉，适合正文 |
| 整段灰度 | 排成整段后是均匀的灰，还是有斑驳、亮点、暗块 | 决定它在长文里的表现；很多有个性的字体在小字号会碎 |

**首要判据不是性格，是灰度。** 在目标尺寸和目标观看距离下排一段真实文案，看它是否均匀。碎掉的字体，性格再好也不能用于正文。

## 三、字体性格与失效场景

不是禁令，是“何时要付什么代价”。选择时必须能说出代价。

| 字体类型 | 语言倾向 | 失效场景 |
|---|---|---|
| 宋 / 明朝 | 庄重、时间感、文学、权威、文化厚度 | 极小字号横画消失；低分辨率投影变灰；需要强冲击的标题过于静态 |
| 黑体（现代无衬线） | 中性、当代、效率、系统感、不抢内容 | 需要文化厚度或手工感时显得平淡；过细字重在投影上直接消失 |
| 仿宋 / 楷 | 手写血缘、东亚传统、公文气质、亲切 | 与几何无衬线混用会割裂；字重档位少，做不出三级层级 |
| 圆体 | 柔性、消费、亲和、轻 | 严肃议题、需要权威的证据页会失重 |
| 拉丁 Garalde / Transitional | 温和、可读、书籍长文 | 需要强当代感时显得旧 |
| 拉丁 Didone | 高对比、时尚、奢侈品 | 小字号横线消失；屏幕渲染易断 |
| 拉丁 Grotesque（Helvetica 类） | 中立、系统、瑞士式 | 极易平淡；默认选择，往往是没选择 |
| 拉丁 Humanist（Frutiger 类） | 更易读、柔和、导视友好 | 需要锐利感时不够有力 |
| 拉丁 Geometric | 现代、纯粹、建筑感 | 小字辨识差（a/g、i/l 相近） |

**数量纪律**：字体不追求丰富。一套系统通常一到两款家族足够；新增字体必须承担现有字体无法合理承担的角色，否则是噪音。多字体带来的“丰富”，读者感知到的通常是“不统一”。

## 四、文字角色与层级编码

先定角色，再定字号。角色由职责定义，不由大小定义。

常见角色：**主张（标题）｜导语（deck）｜正文｜引文｜证据/数据｜标签｜注释｜导航（页眉页脚页码）**。

为每个角色记录：语义职责、实际字体与回退、字重、典型尺度、行距/段距、断行规则、允许变化。只记录影响复用的决定，不建立无人使用的庞大字级表。

**四种编码手段及其代价**：

| 手段 | 优点 | 代价 |
|---|---|---|
| 字号 | 最直接，跨越观看距离仍成立 | 最耗空间；层级多时把版面拖散 |
| 字重 | 不占空间，可密集使用 | 字重档位少的字体只能做两级，第三级失效 |
| 空间（前后距、缩进、分栏、位置） | 最优雅，视觉噪音最低 | 需要读者自己发现分组，太微妙就失效 |
| 颜色/明度 | 最省空间 | 超过主/次两级就沦为装饰，且损对比度 |

**用法**：主张与正文之间用两种手段（常见为尺度 + 空间）；同级之间只用一种（通常空间）。所有层级都用同一种手段，读者只会看到“一串差不多大的字”。

本表处理**文字内部**的层级编码；元素之间该在哪里花视觉重量（面积、位置、明度、尺度……的优先序），见 `02` 第八节。先由版面决定重量，再由本表决定实现方式。

## 五、尺度关系

不存在通用比例。尺度由三个变量决定：**观看距离 × 文本长度 × 与主体的关系**。

- **可辨识台阶**：两段文字的字号差低于约 1.15–1.2 倍时，读者不会读成两个层级，只会读成“排得不整齐”。这是感知阈值，不是审美比例——所以“标题比正文大一点”是最常见的层级失效原因。要建立层级，就得让差距明显到不需要比较。
- **标题的三项决定**：观看距离（投影/手机/印刷的距离差数倍）、标题字数（字数越多，可用字号越小）、与主体的关系（标题是否要盖过图像）。
- **大标题的成本**：字号越大，断行越难、字距越需要收紧、轮廓越容易暴露问题。超过三行的标题，读者开始跳过——此时改文案，不是改字号。
- **极小字号**：注释与元数据可以很小，但必须在目标距离可读。投影与远距离场景里的极小字号是无效设计，不是精致。

## 六、行长、行距、段距

- **行长按字数判断，不按毫米。** 中文连续正文的单行长度有回扫极限：超过一定字数，眼睛回到下一行开头时会错行或重读。栏越宽，回扫成本越高。移动端必须更短。判断方法：读一段，看眼睛有没有在同一行停顿两次。
- **行距与行长联动。** 行长增加，行距必须增加，否则回扫会错行。行距同时是密度旋钮：信息型收紧、文学型放松，但行距不能补偿坏断行——断行错了，加行距只会让错误更明显。
- **段距与首行缩进二选一，不要同时用。** 缩进是传统中文的段落标记，段距是现代的做法；混用会让读者数不清段落起止。同一作品内不切换。
- **密度的真实来源**是行长 × 行距 × 字号的组合，不是行距单项。想变密，先缩短行长，再收行距；想变疏，先放宽行长（在可读范围内），再放行距。
- **栏宽与栏距**：栏距必须明显小于行距的视觉重量才会被读成“同一块”，明显大于才会被读成“两栏”。介于两者之间最危险——读者不知道是否该跨栏读。

## 七、断行与文本块轮廓

**断行是设计动作，不是排版软件的默认结果。**

- 中文按语义单位断：专名、术语、数量+单位、否定词与被否定内容、介词短语与宾语、连词与从句，都不能被拆开。断在语义接缝处，读者不觉；断在词内，读者会重读一次。
- 避免：**孤字**（一行只剩一两个字）、**孤行**（段末只剩很短的一行）、标题最后一行比第一行更长。
- **标题轮廓**是四种可设计的形式：

| 轮廓 | 效果 | 何时用 |
|---|---|---|
| 满宽齐左 | 稳重、信息型，靠内容本身的力量 | 标题短、版面需要一个稳定的顶边 |
| 阶梯／跌级（逐行渐短） | 形成一条向下的坡，把视线送到正文 | 标题较长，需要垂直推进 |
| 短行悬置（末词单独成行并拉开） | 制造停顿与强调 | 标题极短、且有一个词值得被单独看 |
| 齐右／居中 | 仪式感、对称、碑刻感 | 标题短、版面本身对称，或封面/章节页 |

- **悬挂标点与光学边距**：中文的引号、括号、句号在行首行尾会造成视觉凹口。专业排印会让标点外挂，使“字”的边缘看起来齐。检查方法：眯眼看左边缘，是否有节奏性的小缺口。这属于最高一档的工艺，收益在近看时才显现。
- **标题断行后的形状本身在说话**：一个倒三角、一个方块、一条单行，传达的语气完全不同。选定轮廓后再调整字数。

### 断行示例

标题“生成式 AI 基础设施正在进入回报验证期”不应把“生成式 AI”或“回报验证”拆到两行。优先按“生成式 AI 基础设施 / 正在进入回报验证期”组织语义，形成两行等重的块；若实际字体与栏宽导致溢出，先调整文本块或精简文案，不靠任意断词解决。若改成“基础设施进入回报验证期”，则可用单行满宽，把“生成式 AI”降为导语——改文案常常比调字号更有效。

## 八、中西文混排

- **字号匹配的实质**：CJK 字面约等于 1em，拉丁大写高约 0.7em、小写 x-height 约 0.5em。同字号并排时，中文看起来比西文“大一号”。所以要判断的是**视觉字面高度**是否一致，而不是名义字号是否相同。常见做法是让西文略大于中文名义字号，或选用 x-height 较大的西文字体。
- **字体回退顺序**：西文字体在前、中文字体在后，让拉丁字符用西文字形、CJK 用中文字形。顺序反了会出现“用中文字体排的西文”，宽度、字形、标点全都不对。
- **西文与中文之间的间隙**：不是一个空格的问题，而是一个视觉间隙。太小会粘连，太大像断句。按字体与字号判断，不写死是否插入空格。
- **标点**：中文用全角标点，西文用半角；不要出现“中文句子里的英文句点”。数字用半角。
- **斜体**：中文没有真正的斜体，伪斜体是机械倾斜，会让字形失真。强调优先用字重、着重号、位置或颜色，而不是斜体。

## 九、数字、表格与注释

- **等宽数字（tabular）**用于需要纵向对齐的表格与多行数据；**比例数字**用于正文与标题（字距更匀）。先验证字体是否真的提供两套。
- 小数点、千分位、正负号、百分号、单位位置必须全篇一致。比较数字时检查位数与小数点是否对齐。
- **大数字的排版**：用单位解决数量级（亿/万/×10⁹），不在正文里堆零。一个被放大的数字，其单位应显著小于数字本身，且紧邻。
- 对齐优先级（数字）：小数点对齐 > 右对齐 > 左对齐。
- 表头、单位、来源、注释必须与数据建立明确关系，不能因缩小而失去可读性。来源与口径属于正文的组成部分，不是可省略的装饰。
- 上标、脚注、交叉引用在最终格式中仍需可读、可定位；注释编号系统全篇一致。

## 十、排印肌理

排一页文字，眯眼看应当是**均匀的灰**。出现以下现象说明断行或对齐有问题：

- **白斑**：多行短行叠加形成的亮块。
- **暗斑**：某些行被挤压，或字重不一致形成的深块。
- **河流**（rivers）：词间距连成的白色竖向通道，多见于两端对齐的窄栏。
- **斜线纹理**：连续多行以连字符结尾，形成一条可见斜线。

**两端对齐的策略**：中文两端对齐相对安全（字距可微调），但需控制标点挤压；拉丁窄栏 + 长词 + 无连字符会产生河流，此时改用左对齐或允许连字符。连字符是拉丁文的必要工具，但需限制连续连字符行数。

## 十一、编辑性排印元素

这些元素决定作品“像不像出版物”，而不是“像不像幻灯片”。

| 元素 | 职责 | 使用条件 |
|---|---|---|
| 首字（drop cap / raised cap） | 标记文章的起点、建立入口 | 版面留得出空间，且确有一个明确的“开始”；缩进段落不用 |
| 引文（pull quote） | 让快速翻阅的人抓到论点 | 必须真的出自正文；同一跨页不超过一处；尺度放大 + 位置偏置，不是加引号加粗 |
| 图注 | 说明图像是什么、谁拍的、何时、有何限制 | 与图同宽或略窄，字号小于正文，位置全篇统一，不能离图太远 |
| 旁注（marginalia） | 提供不打断主线的补充 | 外边距真的够宽；不够宽时它只是挤压 |
| 页眉 / 页脚 / 页码 | 导航与定位 | 位置、字号、对齐全篇一致；不与内容争注意力 |
| 目录 | 信息架构的自我说明 | 编号、引导线、页码对齐是基本功；条目文字应反映真实章节职责 |
| 分栏标题（running head） | 让读者知道自己处在哪一节 | 需要真实的章节结构，不能为装饰而设 |

## 十二、故障与优先处理

| 故障 | 先查 | 优先动作 | 不要先做 |
|---|---|---|---|
| 标题不突出 | 文案是否明确、占幅是否足够、位置是否有效 | 精简主张，调整文本块与位置，再调字号字重 | 加粗、加下划线、加色块 |
| 标题像一堵墙 | 语义是否过长、断行是否任意 | 改写或拆分文案，设计断行与轮廓 | 缩小字号塞进一行 |
| 正文难读 | 行长、密度、对比、行距、阅读距离 | 重分组，调栏宽与文本块，再微调字级 | 换一款“更好看”的字体 |
| 中文标题断行生硬 | 语义单位、专名、标点、标题形状 | 先改文案或栏宽，再控制断行 | 手动插入空格撑开 |
| 中西文混排参差 | 字面高度、基线、字体回退、字重映射 | 在实际渲染环境校准视觉字面高度 | 只按名义字号对齐 |
| 数字列不齐或难比较 | 位数、精度、单位位置、数字宽度 | 统一格式、精度、单位与对齐方式 | 手动加空格凑齐 |
| 页面充满近似字号 | 文字角色是否真的不同 | 合并无实质差异的层级，用空间与位置建立关系 | 再发明两个新字号 |
| 整页读起来“毛” | 断行、词距、行距是否互相冲突 | 先修断行，再调词距，最后动行距 | 全篇拉开字距 |
| 文字在图上读不清 | 图像最亮/最暗区域的实际对比 | 改裁切、改文字位置、局部压暗或提亮 | 给文字加半透明底板 |

## 十三、媒介与验证

屏幕界面检查断点、缩放、文本扩张与可访问性；PPT 考虑投影距离与演示节奏；长文档检查连续阅读、分页与注释系统；海报按真实观看距离检查标题与关键信息；出版物检查订口、出血、字重在实际纸张与油墨下的表现。

重要作品必须在目标环境渲染，检查字体加载、字符覆盖、字重映射与回退。源文件正常不代表 PDF、其他系统或浏览器中正常。没有实际检查时明确标注未验证——**字体是最容易“本地好看、交付崩坏”的一环。**
