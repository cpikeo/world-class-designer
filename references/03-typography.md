# 排印与文字系统

排印不是选择字体后调字号，而是把字形声音、尺度、字重、行距、字距、行长、段距、对齐、基线、色阶、位置和文本块轮廓组织成层级。

## 优先顺序

**内容能否重组 → 层级是否合理 → 版心与栏宽 → 字体与字形 → 行距/段距/字距 → 字号微调。** 缩小字号是后手，不是首选修复。

## 可观察故障与修正

| 故障 | 先检查 | 优先处理 |
|---|---|---|
| 标题显得弱 | 是否承担主张；与正文的尺度/位置差异是否足够 | 先精简文案、调整占幅与位置，再改字重/字号 |
| 标题像一堵墙 | 文案是否写成完整段落；断行是否有意图 | 精简或拆分主张，调节文本宽度与断行，最后才缩小 |
| 正文难读 | 行长、字面密度、对比、行距和实际观看距离 | 先调版心与分组，再调整字距/行距/字号 |
| 中文标题断行生硬 | 语义单位、专名、关联词、标点位置与标题轮廓 | 先改文案或栏宽，明确控制断行；不要只靠字距补救 |
| 字体看起来不一致 | 回退字体、不同字种的字面高度/基线、字重映射 | 在真实环境确认字体加载；校准中西文、数字和符号的视觉重量 |
| 数字列参差 | 数字宽度、单位位置、小数精度和对齐方式 | 使用合适的数字特性、统一格式；数值按可比性对齐 |
| 页面有很多近似字号 | 是否存在真实层级区别 | 合并没有作用差异的字号档位；用尺度、空间和位置形成层级 |

## 中文/CJK

- 按语义单位断行，避免拆开专有名词、固定术语、强关联词组、数字与单位。
- 检查标点避头/避尾、括号和引号方向、孤字尾行、长短行轮廓及行首行尾的视觉重量。
- 中文、拉丁字母、数字、数学符号与单位的实际字面高度、基线和粗细不同；不能只按 CSS/软件中的名义字号判断。
- 不要无差别拉开中文正文的字距。标题字距需结合字形、字号与字体判断。
- 高密度内容优先重组信息、层级、栏宽与分组；不能为了整齐隐藏来源、口径、限定条件或脚注。
- 竖排只在语言、文化与媒介合适时采用，并检查标点、字形方向和阅读顺序。

## 拉丁文与复杂文字系统

拉丁文字检查词距、连字、大小写字距、引号、撇号、破折号与语言对应的断词规则。阿拉伯文等 RTL 文字检查阅读方向、连接字形、标点和双向混排；印度文字等复杂脚本需确认组合符号与字形塑形得到支持。多语言同屏需尊重各自的视觉纹理与阅读习惯，不使用伪文字装饰。

## 字体系统

一至两套字体家族通常足够，但不是强制限制。每套字体应有明确职责；字体选择需匹配内容、文化、品牌、显示环境和可访问性。重要作品必须在目标环境渲染，确认字体实际加载、字形覆盖与回退情况。不得仅凭源文件外观声称排印已验证。
