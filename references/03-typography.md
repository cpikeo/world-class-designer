# 字体系统与排印执行

本文件拥有：字体性格判断、文字角色与层级编码、尺度与大字排版、行长行距、断行与文本块轮廓、CJK 禁则与标点、中西文混排、数字与表格排印、排印肌理、编辑性元素、屏幕与移动端排印、渲染验证与文字压力测试。版面层级分工见 `02`「层次反差：从最省到最贵」。

排印要把语义、字形性格、文本块轮廓、层级、行长、断行、字重、间距、位置与色彩组织成可读、有辨识度的系统。

## 一、修正顺序与决策链

排印按一条链推进，也按同一条链倒查故障：

**内容与语义 → 文字角色 → 排印关系（字体、真实字重、字号、行长、行距、段距、层级编码）→ 真实渲染 → 异常定位 → 最小修正。**

| 层 | 要定的事 | 跳过它会出现什么 | 常见故障与优先动作 |
|---|---|---|---|
| 内容与语义 | 这段文字是主张、证据、解释还是注释；文案是否定稿 | 文案还在改，字体已锁死，返工从字形开始 | 标题像一堵墙 → 改写或拆分文案，设计断行，不缩小字号硬塞 |
| 文字角色 | 角色与相邻角色的关系：谁补谁、谁让谁、谁不许争 | 出现三个几乎相同的字号级差 | 标题不突出 → 先查文案与占幅，再调字号字重，不加粗加底 |
| 排印关系 | 字体、真实字重、字号、行长、行距、段距与层级编码的组合 | 行长与行距互相补偿，越调越糟 | 正文难读 → 先重分组、调栏宽与文本块，最后微调字级；不换字体 |
| 真实渲染 | 目标引擎的断行、加载/回退、数字、标点与禁则 | 设计稿成立，导出后替换、断行崩、标点错位 | 混排参差 → 在实际渲染环境校准视觉字面高度与基线，不按名义字号对齐 |
| 异常定位 | 问题属于文案、层级、容器、字形还是渲染 | 把所有问题当字形问题，反复换字体 | 文字在图上读不清 → 改裁切或位置，不加半透明底板 |
| 最小修正 | 只动根因层，说明预期变化与保持项 | 一处问题引发全篇重排 | 一次只动一项：先文案或容器，再断行，最后字号字距 |

字号缩小、字距拉开、整段加粗都不是默认补救。**一页文字读不顺，多数原因不在字体。**

## 二、怎么读一款字体

不要用“优雅、大气、高级”代替观察，也不要由单个字形直接推出用途。把候选排成同一组真实文本，在相同名义字号、字重、栏宽与输出环境中比较：

| 观察维度 | 中文与西文分别看什么 | 对决策的实际影响 |
|---|---|---|
| 骨架、中宫与字腔 | 中文字画收放、内外白；西文 aperture、字腔开放度与字宽 | 影响小字辨识度、标题轮廓与文本块密度；不直接等于“正式/亲和” |
| 字面率与视觉高度 | 中文字面占字身比例；西文 x-height、大写高、升降部；混排比实际墨迹高度 | 同字号并不同大；决定视觉级差、行距与混排补偿 |
| 笔画对比与最细处 | 横竖/主副笔画对比、连接处、最细横画与衬线 | 决定低 DPI、投影、吸墨与反白时的风险 |
| 字重与宽度轴 | 真实字重是否成体系；可变字轴是否被软件支持；窄体是否牺牲字腔 | 决定层级手段与空间成本，不看宣传的档数 |
| 笔形、重心与方向 | 起收笔、切角、曲线张力、视觉重心、倾斜是否专门设计 | 形成语气与动势；需结合整段效果判断 |
| 数字与符号 | 0/O、1/I/l、6/8、小数点、货币、上下标、箭头；表格/比例、lining/old-style | 决定数据识别、对齐与混排一致性 |
| 整段灰度与节奏 | 均匀度、暗块、白斑、字间节奏、回扫、标点凹凸 | 判断长文与窄栏；单字漂亮不能证明整段成立 |

这些观察只产生候选与风险假设，不生成“中宫紧就适合正文”“无衬线就中性”的定律。字体语义还受内容、字号、字距、媒介与文化经验影响。

**输入—决策—失败信号**：先确定文字角色、真实文案、目标尺寸和渲染环境，再比较候选；若整段斑驳、小字粘连、细画消失、混排跳动或远距层级消失，应换字重/字体或调整文本块，而不是继续加装饰。

### 名称之外的五项核验

1. **真实字重与实例**：输出是否调用了目标字体文件与字重实例。合成加粗、伪斜体或可变字轴被静态化时，改用真实实例或其他层级手段。
2. **字符覆盖与 shaping**：生僻字、异体字、组合字符、emoji、箭头、上下标、货币；复杂文字依赖 shaping 引擎，不能只查码位存在。
3. **字体度量与回退**：比较目标与回退字体的 advance width、x-height、大写高、升降部与默认行框。同名不同版本、不同系统的 hinting 都会改变字宽、基线与断行。
4. **打开的开关**：真正改变结果的常常不是字体名，而是这些默认值——`kern` 字偶距、`liga`／`dlig` 连字、`lnum`／`onum`／`tnum`（正文与表格分开）、`ss01…`、`locl` 语言变体、`palt`／`halt` 西文标点挤压、中文标点的挤压与避头尾、光学尺寸与 tracking。逐项确认设计画布、导出文件与目标引擎里是同一套：网页的 `font-feature-settings`／`font-variant-numeric`、Office 的字距与字距调整、桌面出版软件的段落样式互不相通。
5. **最终引擎行为**：标点挤压、两端对齐、连字、禁则、字距与文本缩放都会改变结果。设计画布、浏览器、Office、PDF 阅读器与印前 RIP 不是同一个排版引擎。

## 三、字体性格与失效场景

选字同时满足四个条件，缺一项都会在后期返工：**内容语义**、**品牌个性**、**媒介环境**（屏幕、投影、印刷、开本与纸张）、**阅读任务**（扫读、连续阅读、逐项比对）。两项说不清时先不选字体，回到「修正顺序与决策链」补判断。类别只帮助提出假设，不能替代具体家族与真实输出的判断。

| 字体类型 | 可探索的语言倾向〔境〕 | 优先检查的风险 |
|---|---|---|
| 宋 / 明朝、拉丁 Garalde / Transitional | 书写血缘、编辑感、时间感、庄重感 | 最细笔画、横画灰度、低分辨率与吸墨；并非天然适合长文 |
| 黑体、拉丁 Grotesque | 中性、系统、当代、信息效率 | 字面与字重可能同样强势；“默认无衬线”若无内容依据，容易趋同 |
| 仿宋 / 楷、Humanist | 手写血缘、人文、亲切、导视友好 | 字重档位、混排骨架、不同字号下的灰度与识别 |
| Didone、高对比展示字体 | 精细、时尚、戏剧性 | 小字与反白断画、屏幕渲染、印刷增益 |
| 圆体、Geometric | 柔性、几何秩序、建构感 | 小字符号区分、字腔、过强图形感；严肃场景不必然失效 |

**数量纪律**〔验〕：新增家族应承担现有家族无法合理承担的语言、角色或识别职责，不以“两款”为上限。多文种、档案复刻或品牌系统可能需要更多家族，但每款的职责、混排关系与回退都应明确。字体不能替空洞内容补性格。

## 四、文字角色与层级编码

先定角色及其相互关系，再定字体参数。角色由职责定义，不由大小定义。

| 角色 | 必须完成的事 | 与相邻角色的关系 | 典型失败信号 |
|---|---|---|---|
| 标题 / 主张 | 给出本页可复述的核心或入口 | 导语补足语境；正文兑现承诺 | 只有主题名；长标题断坏语义；与导语同重 |
| 导语 / 摘要 | 交代范围、利害或阅读前提 | 承接标题并导向正文，不变成第二标题 | 逐字复述标题；篇幅大到拖延正文 |
| 正文 | 连续解释、论证或叙述 | 段落节奏稳定；引文、数据、注释可回到主线 | 灰度斑驳、回扫错行、层级过密 |
| 引文 | 提供原声、证据或停顿 | 与正文可区分，来源与语境可追 | 只靠大引号；摘编后改变原意 |
| 数据 / 证据 | 支持比较、核验与结论 | 单位、期间、来源紧邻 | 数字醒目但口径缺席；小数与单位断开 |
| 标签 / 导航 | 标识类别、位置、入口和状态 | 稳定可预测，不与内容争焦点 | 样式比正文更响；同层命名不一致 |
| 注释 / 图注 / 来源 | 提供限定、出处和补充 | 靠近所注释对象，可定位且可读 | 过远、过淡或因“次要”而不可读 |

复杂项目只记录会复用的角色契约：**语义职责、字体与真实字重、回退、目标媒介下的尺度、行距/段距、断行规则、允许变化与验收样例**。角色之间可用相同字号而不同位置，也可用不同字号而同字体；关键是关系可辨，不是维护一张庞大字级表。

**层级编码及代价**：

| 手段 | 适用收益 | 失效与副作用 |
|---|---|---|
| 字号 / 尺度 | 远距与跨媒介较直接 | 耗空间；长标题更易溢出和坏断行 |
| 字重 / 字形 | 密集环境有效，可保持文本块尺度 | 依赖真实字重与渲染；过粗粘连、过细消失 |
| 空间 / 位置 / 缩进 | 建立分组与阅读秩序，噪音低 | 过微妙则不可辨；窄屏重排后关系可能丢失 |
| 颜色 / 明度 | 可编码状态和强调 | 受对比、色觉与输出影响；关键层级不得只依赖它 |

远距或低质量输出优先空间、位置和尺度；密集界面可先用分组与位置；一种编码已清楚时不继续叠加。

## 五、尺度关系

不存在通用比例。尺度由三个变量决定：**观看距离 × 文本长度 × 与主体的关系**。

- **可辨台阶**（定义与判据见 `02`「尺度与占幅」）：字体上的变量是字面率——同字号下字面大的字体看起来更大，投影距离下同样的差值会消失。**验证方法**：把候选字号并排渲染，缩到目标尺寸（投影按后排视角、手机按实机宽度），眯眼判断能否一眼分出两级。
- **标题的三项决定**：观看距离、标题字数（字数越多可用字号越小）、与主体的关系（是否要盖过图像）。
- **大标题的成本**：字号越大，断行越难、字距越需要收紧、轮廓越容易暴露问题。标题行数增加会推迟读者进入正文的时点——需要快速进入内容的页面，先用文案解决，不靠缩小字号硬塞。
- **极小字号**：注释与元数据可以很小，但必须在目标距离可读〔硬〕。投影与远距离场景里的极小字号是无效设计，不是精致。

### 大字排版

字号跨过某一档之后，文字从“读”变成“看”：它同时是句子和形。判断标准因此从可读性扩展到轮廓、墨量与光学边距。

- **轮廓**：大字的字面率差异被放大，跨族标题按墨迹高度对齐，不按名义字号。行距要随字号收紧，否则两行读成两个标题；收多紧由字面率、字重与是否反白决定，收到上下行开始互相干扰为止，不以某个倍率为准。
- **墨量**：中文大字的细横画在反白、低 DPI 与投影下最先消失，笔画交叉处最容易糊成一块。深底大字优先换横竖对比更小的字重，或改浅底——这是能不能看清，不是风格偏好。
- **光学边距**：标点、引号、括号在大字号下会顶出明显的白口。齐左标题要吃掉首字标点的空白，齐右同理；能不能做取决于引擎能力。
- **断行即构图**：先定每行说哪一层意思，再看轮廓是否成立；冲突时改文案或改栏宽。末行只剩一个孤字时，要么是有意的悬置且值得，要么是没检查。
- **一处为止**：同一屏只有一处大字最有效，第二处大字等于取消第一处。需要两个强调时，用尺度、位置或留白区分。
- **验证**：在目标宽度的 1x 与 2x 各看一次；投影场景按后排距离看一次。缩放后的截图不能代替。

## 六、行长、行距、段距

- **行长同时按实际宽度、可见字符与阅读行为判断。** 字数便于比较，毫米/像素便于落地，但都不是通用标准。中文连续正文行长增加时，回到下一行开头的搜索成本上升；西文还受词长、空格与连字符影响。用真实文本检查错行、重读、回扫与理解，不拿“每行固定字数”替代测试。
- 字体字面、标点密度、语言熟练度、行距、观看距离与媒介都会移动舒适范围。移动端不必然更短：大屏手机、横屏与分栏仍需按实际版心重判。
- **行距与行长联动。** 行长增加，行距通常要跟着增加，否则回扫会错行。行距同时是密度旋钮：信息型收紧、文学型放松。但行距不能补偿坏断行。
- **段距与首行缩进通常二选一。** 选择依据是**出版类型与阅读传统**：书籍正文、古籍整理、部分文学类用缩进；报告、网页、演示、产品文档用段距。同一层级内不混用，否则读者数不清段落起止。两者同时出现要各自承担不同职责：缩进标记段落，段距标记区块（原文/译文并列、正文与例证）——职责一旦重叠，段落信号就失效。
- **密度由行长、行距、字号、字重、段距与文本块位置共同形成。** 调整前先明确要改善的是查找、连续阅读还是对照。
- **栏宽与栏距**：栏距明显小于行距的视觉重量时，读者读成“同一块”；明显大于时读成“两栏”。介于两者之间最危险——读者不知道是否该跨栏读。

## 七、断行与文本块轮廓

**断行是设计动作，不是排版软件的默认结果。**

- **中文按语义单位断**〔验〕：先标出专名、术语、否定结构、谓宾关系、数量与单位，再在语法接缝处选断点。长标题优先决定“每行说哪一层意思”，再追求轮廓；无法兼顾时先改文案或文本块。手动换行只适用于受控输出，响应式网页用容器、短语分组与换行控制共同处理。
- **多行标题检查**：逐行能否独立读出语义、行尾是否留下弱词或开括号、行首是否出现闭标点、各行视觉重量是否支持阅读顺序、末行是否只剩无意的孤字。末行长于首行、短词独行或居中都不是天然错误，语义与轮廓无依据时才失败。
- **避头尾（禁则）**〔硬〕：按目标语言与出版规范保持标点及数量单位的合法关系。中文通常避免闭标点、闭引号/括号、百分号与紧密关联的单位落到行首，避免开引号/括号留在行尾；具体字符集与例外由所用中文排印规范决定。不同引擎支持不同，必须检查最终产物。
- **文本块轮廓**〔验〕：检查孤字、意外短末行、连续不良断点与边缘凹凸，不为追求几何整齐牺牲语义。正文更重视连续阅读，标题更重视语义分组与远距轮廓。

| 常见标题轮廓 | 效果 | 何时用 |
|---|---|---|
| 满宽齐左 | 稳重、信息型，靠内容本身的力量 | 标题短，版面需要稳定的顶边 |
| 阶梯／跌级（逐行渐短） | 形成向下的坡，把视线送到正文 | 标题较长，需要垂直推进 |
| 短行悬置（末词单独成行并拉开） | 制造停顿与强调 | 标题极短，且有一个词值得被单独看 |
| 齐右／居中 | 仪式感、对称、碑刻感 | 标题短，版面本身对称，或封面/章节页 |

- **悬挂标点与光学边距**〔境〕：引号、括号、句号与连字符可能在齐行边缘造成视觉凹口。是否外挂取决于语言规范、字体标点宽度、对齐方式与媒介；浏览器、Office 与出版软件能力不同，不能用伪元素造成复制/朗读顺序错误。
- **标题轮廓服务语义**：先用真实标题决定语义分组，再调整字数、栏宽或轮廓；不能只靠负字距把长标题挤进预定形状。

### 断行示例

标题“生成式 AI 基础设施正在进入回报验证期”不应把“生成式 AI”或“回报验证”拆到两行。优先按“生成式 AI 基础设施 / 正在进入回报验证期”组织语义，形成两行等重的块；若字体与栏宽导致溢出，先调整文本块或精简文案。若改成“基础设施进入回报验证期”，则可用单行满宽，把“生成式 AI”降为导语——改文案常常比调字号更有效。

## 八、中西文混排

- **字号匹配的实质**：CJK 与拉丁的字面率、x-height、大写高、升降部和字身框差异很大，同字号不一定视觉等大。比较实际墨迹高度、整行灰度与笔画重量，不套固定 em 比例；可微调西文名义字号，或换用更匹配的家族。
- **基线与行框分开校准**：CJK 表意字框、拉丁基线与软件行框不是同一概念。先检查中文中心与拉丁 x-height/大写高是否协调，再看共同基线、上下标和行内图标；最后用含最深升降部的真实混排段落检查行距。
- **字体回退顺序**：CSS 等按字符回退时，字体列表顺序决定谁接管拉丁、数字、标点与符号，不只是“西文在前”。逐类核验覆盖和字形来源；设计软件则检查显式混排设置与导出后的实际嵌入。
- **西文与中文之间的间隙**：不是空格问题，是视觉间隙。太小会粘连，太大像断句。按字体与字号判断，不写死是否插入空格。
- **标点与数字**：按语言上下文、出版规范与字符语义选择全角/半角，不在中文句子里误用英文句点，也不为“统一”改掉西文原文。全角标点可能被两端对齐挤压；最终以真实输出为准。
- **斜体**：多数中文字族没有独立设计的斜体，机械倾斜会破坏笔画与字腔。强调优先用字重、着重号、位置或颜色；有专门设计的斜体时可验证后使用。

## 九、数字、表格与注释

- **等宽数字（tabular）**用于需要纵向对齐的表格与多行数据；**比例数字**用于正文与标题。先验证字体是否真的提供两套——不少字体把小写数字写死为一种。
- 小数点、千分位、正负号、百分号、单位位置应全篇一致。数值与单位作为语义组处理，用目标引擎认可的不断开机制防止孤单位、孤百分号或负号与数值分离。
- **大数字的排版**：在不改变精度的前提下用单位解决数量级。被放大的数字应让单位、期间、样本与口径可辨；单位通常退居次级并紧邻数值，具体尺度由远距识别与整体层级决定。
- 数字对齐按任务选：比较大小通常右对齐或按小数点；编号、代码与标识符可对齐字符位置或左对齐。不为小数点对齐破坏位数、单位和精度的语义。
- 表头、单位、来源、注释应与数据建立明确关系，不能因缩小而失去可读性。来源与口径属于正文，不是可省略的装饰。上标、脚注、交叉引用在最终格式中仍需可读、可定位，编号系统全篇一致。

### 表格

表格是排印对象，不是数据容器。一张表读不动，多数时候不是字号小，是线、列宽与对齐没有承担比较关系。

- **线系统**：通常只需要三条——表头上方、表头下方、表体末尾。行间用留白或极浅的分组线，不用满格网格；每多一条线，都在跟数字争注意力。
- **列宽由内容与比较轴定**：等宽列只对等量内容成立。数字列比文字列窄；长文本列要能换行，不靠缩字号塞进去。定列宽前先按最长合理内容量一遍字宽。
- **数字列**：同列统一精度与单位，单位进表头——逐格重复单位会挤掉有效位。比较大小右对齐或按小数点对齐，编号与代码左对齐。缺值、零、无数据是三种语义，不能都写成“—”。
- **行距与基线**：表内行距小于正文，但仍对齐同一条基线；多行单元格统一顶对齐或垂直居中，全表一致。
- **跨页**：重复表头（含单位行），表头与表体不得分居两页，跨页处不断开一行。印刷另查表线出血与叠印，屏幕另查横向滚动时列标签是否固定。
- **读不动时改编码，不是改字号**：列太多、类别太密、要表达趋势，改图或拆表——判据见 `04`「图表与信息图」。

## 十、排印肌理

排一页文字，眯眼看应当是**均匀的灰**。出现以下现象说明断行或对齐有问题：**白斑**（多行短行叠加）、**暗斑**（某行被挤压或字重不一致）、**河流**（词间距连成竖向白色通道，多见于两端对齐的窄栏）、**斜线纹理**（连续多行以连字符结尾）。

**两端对齐的策略**：中文两端对齐相对安全，但需控制标点挤压与字距累计——一味拉字距会让行内疏密不匀。拉丁窄栏 + 长词 + 无连字符会产生河流，此时改用左对齐或允许连字符，并限制连续连字符行数。

## 十一、编辑性排印元素

这些元素决定作品“像不像出版物”，而不是“像不像幻灯片”。

| 元素 | 职责 | 使用条件 |
|---|---|---|
| 首字（drop / raised cap） | 标记文章起点、建立入口 | 有明确文章开端且值得强调；与首行缩进、段距和后续行对齐共同校准，不因“出版感”强加 |
| 引文（pull quote） | 让快速翻阅的人抓到论点或原声 | 忠于原文与语境；与标题、正文争夺同一入口时删减或降级 |
| 图注 | 说明图像是什么、谁拍的、何时、有何限制 | 与图绑定且可定位；退居正文之后但仍须可读 |
| 旁注 | 提供不打断主线的补充 | 外边距真的够宽；不够宽时它只是挤压 |
| 页眉 / 页脚 / 页码 / 分栏标题 | 导航与定位 | 位置、字号、对齐全篇一致；需要真实章节结构，不为装饰而设 |
| 目录 | 信息架构的自我说明 | 编号、引导线、页码对齐是基本功；条目文字应反映真实章节职责 |

## 十二、屏幕与移动端排印

屏幕排印的失败不在纸上，在**字体加载、布局重排和像素渲染**这三个环节。

- **加载与回退是一件事**：按目标网络与设备检查 FOIT、FOUT、阻塞时间与替换后的重排，在未加载、慢加载、已加载三种状态各看一次。关键文案不得因 Web 字体未加载而消失〔硬〕；选择 `font-display`、预加载与子集化时，同时检查缓存、跨域、字符覆盖与布局位移。回退字体的字宽、x-height、升降部与默认行框会改变断行与容器高度，度量覆盖或尺寸调整只能减少跳变——数值匹配不等于灰度匹配。
- **文本扩张与替换**：不同语言、系统字体、版本与用户翻译会改变长度。布局必须容纳实际交付中最长的合理文案〔硬〕；无法预知上限时，定义换行、截断、展开或滚动策略及其信息损失。
- **用户字号与缩放**：系统字号、浏览器文字缩放和页面缩放是不同条件。固定高度、固定行数与绝对定位最容易截断。不得为守住设计稿禁止用户缩放〔硬〕。
- **像素与极性**：细画、hinting、抗锯齿、像素密度、暗底亮字的光晕感都会改变视觉字重。按实际设备和输出比例检查，不假定 1x/2x 截图能代表所有屏幕。
- **动态尺度与重排**：流式字号只改变尺度，不解决行长、断行与触控布局。检查最短/最长标题、窄屏、横屏与回退后的语义分组，不拿缩小的桌面画布代替真实宽度。

文字压图时的对比判定与取样方法，见 `04`「裁切与文字避让」与 `07`「证据口径」。

## 十三、渲染验证

字体名称、源文件正常与工具导出成功都不能证明最终排印成立〔硬〕。先导出真实产物，再按目标尺寸、距离与环境查看，最后回源文件修正。

| 环境 | 必看的排印差异 | 合格证据 |
|---|---|---|
| 桌面 / 移动浏览器 | 字体加载前后、回退度量、最长文案、文字缩放、系统字号、排版引擎 | 目标浏览器与宽度的加载状态及最终状态；异常截图或检查记录 |
| PPT / Office | 是否缺字、真实字重映射、文本框 autofit、行距与标点禁则变化 | 在实际播放环境渲染，检查完整文稿与长文案页 |
| PDF / 电子书 | 字体嵌入/子集、复制与检索、字符编码、分页、阅读器重排 | 导出后预检并在目标阅读器查看；印刷 PDF 另做印前检查 |
| 印刷 | 最细笔画、反白、油墨增益、纸张与 RIP | 印前报告加必要的数码样/上机样；源文件截图不算 |

通用崩坏：字体未嵌入或被替换、字重合成、生僻字与符号回退、避头尾失效、两端对齐挤压不同、文本框重排、字体加载跳动、复制乱码。

### 文字压力测试

排印崩在边界上，不崩在平均长度上。用交付物里的真实字符串跑六项：

| 测试项 | 用什么 | 暴露什么 |
|---|---|---|
| **最长标题** | 最长的那条真标题，不缩短不换词 | 溢出、坏断行、末行孤字、行数超出轮廓 |
| **最短标题** | 两三个字的真标题 | 层级若只靠字号，短标题会失重，需位置或留白补 |
| **最长正文段** | 最长一段连续正文，含标点密集句 | 回扫错行、灰度斑驳、河流、段距与缩进失效 |
| **密集数据** | 最长的数值、单位、负号、百分号同场 | 数字与单位断开、列不齐、小数点错位 |
| **混排与特殊字符** | 中英混排＋生僻字＋引号括号＋上下标 | 基线跳动、字面不等、回退字形突兀、禁则失效 |
| **最窄容器** | 目标宽度下最窄的卡片、表格列、按钮 | 截断、强制换行、文字压边、触控目标过小 |

在目标引擎与目标尺寸里看，不看设计画布。修的时候一次只动一项：先改文案或容器，再改断行，最后才动字号与字距。六项过之前，不要用“平均长度看起来还行”宣布排印成立。

没有实际检查时，明确写出未验证的环境与风险；不得用字体选单、设计画布或文件可打开代替渲染结果。
