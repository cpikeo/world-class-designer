# 设计判断、编辑智能与视觉概念

本文件拥有：任务障碍与判断依据、设计取舍、主张提炼、内容关系与价值判断、阅读负担、删/并/压/转译/重组、视觉元素必要性、概念提炼与跨域落地、候选探索与收敛、辨识度压力测试。内容如何转化为空间职责见 `02`，多页论证见 `05`。

## 一、判断任务，而不是套用风格

先识别受众不理解、不相信、无法比较的内容，或需要采取的行动。围绕这一障碍设计，不要把主题、行业或审美偏好当成目标。

按需识别：**受众与场景**（已有知识、可投入注意力、观看距离与使用环境）、**目标**（理解、记忆、信任、选择、行动、体验，哪一个最重要）、**主张**、**证据与边界**、**障碍**（焦点不可辨、关系不可见、证据不足、密度过高，还是缺少记忆锚点）、**验收证据**。

这些是内部线索，不是必填表格。若“主张”只是主题名，继续追问：**受众看完后应能说出哪一句不同于之前的话？**

### 判断依据：把四类来源分开

主入口的三级规则决定“可以说得多绝对”；这里的四类来源决定“为什么这样选”。两者不要混用。

| 来源 | 可以支持什么 | 不能冒充什么 |
|---|---|---|
| **任务事实** | 受众、内容、品牌资产、使用场景、交付要求 | 未核实的行业惯例、设想中的用户行为 |
| **客观约束** | 媒介物理条件、技术标准、材料工艺、真实渲染结果 | 审美优劣；技术标准也不自动等于好设计 |
| **专业经验** | 候选方向、常见风险、较稳定的阅读倾向 | 无条件成立的公式；须保留适用条件与反例 |
| **审美偏好** | 在多个同样有效的方案中作风格选择 | 事实、可读性证据或“唯一高级答案” |

### 取舍：知道何时突破，何时克制

关键决定用最短四句检查：**获得了什么 → 牺牲了什么 → 必须保护什么 → 何时重审。** 突破常规的理由应是默认方式阻碍了理解、识别或体验，而不是“需要更有创意”；保持克制的理由应是新增表达不再增加意义，只会增加阅读、制作或维护成本。二者都可以是成熟判断。

## 二、推导链：从受众到视觉概念

七个环节应能相互解释，但允许在获得新事实后回溯。任何一环只能用形容词填充时，链在这里断了。

| 环节 | 要回答 | 断链的症状 |
|---|---|---|
| **受众** | 他们已知什么、关心什么、凭什么相信 | “面向所有人” → 等于没有受众 |
| **场景** | 在什么设备、距离、时长、注意力条件下被接触 | 说不清观看条件 → 后面所有尺度决定都是猜的 |
| **目标** | 看完之后发生什么变化：理解？相信？选择？行动？ | 目标是“介绍”“展示” → 那是动作，不是结果 |
| **主张** | 一句可被复述的话 | 主张是主题名（“关于 AI 的现状”） |
| **证据** | 哪几项事实让它成立，边界在哪 | 证据是观点、是趋势、是“业内普遍认为” |
| **概念** | 用哪个视觉关系承载这个主张 | 概念是形容词（“科技感”“东方美学”） |
| **表达动作** | 概念改变了哪些构图、尺度、字体、色彩或图像决定 | 说不出具体改变 → 概念还停在口头 |

**三个检查**：

1. **反向可推**：从表达动作能否倒推回主张？不能，说明形式与内容是两件事，只是碰巧排在一起。
2. **主张类型匹配**：论证型主张应可被质疑、核验，避免“未来充满机遇”式空话；诗性或品牌语言可以承担感受与记忆，但不能伪装成事实，也不能代替必要的核心信息。
3. **证据强度匹配**：证据只支持相关性时，主张不能写成因果。结论强度不得超过证据强度的完整推理见 `05`「论证链的完整性」。

## 三、编辑判断：先识别关系，再决定去留

排版前先做内容编辑。把原始材料分成**核心主张、关键证据、必要解释、必要限定、次要补充**，再标明单元之间的关系；不要把作者提供的顺序直接当成读者的理解顺序。

| 内容关系 | 编辑问题 | 常见处理 |
|---|---|---|
| **因果** | 条件、机制、结果是否都在？是否只有相关性？ | 补齐机制或降低结论强度；按依赖排序，不用箭头制造假因果 |
| **递进** | 后一步是否必须建立在前一步之上？ | 删除重复前提，保留真正的认识台阶 |
| **对照** | 是否在同一维度、口径与尺度上比较？ | 对齐比较条件，删掉不参与比较的重复介绍 |
| **并列** | 是否同层、可独立理解，又共同服务一个主张？ | 合并重复项；若并不同层，改为从属而非机械并排 |
| **从属** | 哪条是结论，哪条只是例证、定义或补充？ | 主从分层；例证只保留最能改变理解的部分 |
| **冲突** | 是事实矛盾、观点分歧，还是口径不同？ | 不得为版面顺畅抹平；保留来源、条件与未解决差异 |

### 内容价值判断

| 测试 | 做法 | 结论 |
|---|---|---|
| 删除测试 | 拿掉它，理解、可信度、行动或必要体验是否受损 | 均不受损 → 删除或降级；只“仍说得通”不够，证据可能仍不可删 |
| 替换测试 | 换成更短更准的话，事实、语气与限定是否损失 | 无损失 → 改写，不靠版面容纳原文 |
| 重复测试 | 标题、正文、图像、数据是否重复承担同一职责 | 合并或重新分工，保留更强的表达 |
| 来源测试 | 是否有出处、口径、时间；结论是否超出证据 | 补足、限定或标为待核，不伪装为事实 |
| 层级测试 | 它服务受众任务，还是只服务作者的自证 | 后者删除或压到附录 |

标题若只重复章节名、图像若只复述图注、数据若不支持当前主张，都应重写、改职责或删除。每个元素的信息职责最终要能在版面中被看见，而不是只写在策划文档里。

### 阅读场景与认知负担

先判断读者是在**扫读找重点、连续阅读、逐项比较，还是据此决策**。负担不只来自字数，还来自同时出现的竞争焦点、层级嵌套、频繁跨区回看、术语切换和缺失前提。密度高但比较轴稳定，可能比低密度却到处跳转更省力。

过载时按根因组合使用：**删除 → 合并 → 压缩 → 转译 → 重组 → 分层**。需要先后理解的拆步，需要同时比较的保留同场；最后才考虑缩字号。反过来，内容过少时先补关键证据或缩小媒介，不用装饰填空。

**不能删的东西**：影响结论的单位、期间、基线、样本、口径、限制、反例、必要限定、不确定性。它们的正确待遇是**变小、变近、变清楚**，而不是消失。删掉结论依赖的数据时，结论必须同步限定，或把数据移入注释/附录；删内容不等于删责任。

## 四、什么时候转成图形

内容是否应该变成图，取决于它的结构是否本身是空间性的。

| 内容结构 | 适合的转译 | 不该转译的情况 |
|---|---|---|
| 数量比较、排位 | 条形、位置编码 | 数字彼此接近且精确值更重要 → 用表格 |
| 随时间变化 | 折线、时间轴 | 时点太少，或变化无趋势 → 用文字点明 |
| 部分与整体 | 构成图（类别少时） | 类别多、差异小 → 用排序条形或表格 |
| 流程、因果、依赖 | 序列图、节点关系 | 关系简单且文字已足够清楚 → 用一句话；步骤少但空间关系难懂时仍可画图 |
| 结构、剖面、层级 | 剖面图、剖析、分解 | 结构不可核验 → 用真实图像加标注 |
| 空间、位置、路径 | 图、平面、地图 | 需合规数据源时须用合规来源，不得臆造 |
| 对照、张力、尺度差 | 并置、尺度同框 | 对照需长篇解释才成立 → 说明文字更有效 |

**判据**：把这段内容画成图后，读者是否**少读了一些字就多懂了一件事**？如果只是把文字换成方框，那是装饰。

## 五、从项目事实提炼概念

四步推进：

1. **盘点独有材料**：对象形态、运行机制、行为、地点、材料、工艺、使用仪式、数字、限制、冲突或反例。
2. **选择关键发现**：哪个事实最能解释主张，而不是哪个最容易做成装饰。
3. **转成视觉关系**：把发现表达为尺度、位置、方向、层级、对照、序列、材料或时间关系。
4. **形成变奏语法**：规定这一关系如何进入不同页面或媒介，以及什么变化会破坏它。

用一句内部假设表达：**“把 [项目特有的事实/对象/矛盾] 转化为 [视觉关系]，帮助受众理解或记住 [主张]。”** 随后必须回答：这种表达为什么比直接陈述更有效，受众会因此多看懂或多记住什么？

### 从抽象主题到可感知隐喻

隐喻不是找一个相似图标，而是完成这条转译：**项目事实 → 可感知经验 → 形式规则 → 受众收益。** 例如“修复让历史可见”可借“不同时间层同时存在”的经验，转成新旧材料保留接缝、局部透叠与并置标注的规则；它帮助读者辨认变化，而不是只得到“历史感”。若隐喻需要长篇解释才成立，改用更直接的机制或证据表达。

### 概念落地矩阵

概念不必控制每个变量，但至少改变一个**结构决定**，并由其他系统协同；只换颜色、字体或纹理的是皮肤。

| 系统 | 概念要给出的具体指令 |
|---|---|
| 构图与空间 | 谁主导、在哪里进入、怎样对峙/连续/中断，负空间承担什么 |
| 尺度与序列 | 哪一差异被放大，什么保持可比，变化按什么秩序展开 |
| 字体与排印 | 哪种字形骨架、文本块轮廓和阅读节奏呼应概念，而非只指定字体名 |
| 色彩与材料 | 色彩来自哪项事实，明度与面积如何分配注意，材料是否可真实实现 |
| 图像与证据 | 必须看见什么主体、机制或细节，什么不能用生成图替代 |
| 动态与交互 | 哪个变化揭示因果或状态，静止时是否仍能理解 |

概念不等于流行风格、孤立符号或主题的字面插图。有效概念应相关、具体、可读、可展开、可实现，并能在真实媒介和预算内制作。

## 六、每个元素的存在理由

版面里不该有“因为空着”的东西。每个视觉元素要能通过以下任一测试，否则删掉：

| 测试 | 通过标准 |
|---|---|
| **替代测试** | 它替代了哪句话或哪个认知动作？说出具体那一句。 |
| **信息增量** | 去掉它，读者是否少知道或少相信一件事？ |
| **关系揭示** | 它让某个关系变得可见（尺度、层级、顺序、对照）？ |
| **感知定向** | 任务确需体验或情绪时，它是否以具体材料、尺度或节奏产生预期感受？泛泛“更有气氛”不通过。 |
| **定位职责** | 它帮助读者知道自己在哪、往哪去？ |

**常见无意义装饰**（默认视为不通过，除非能说明职责）：

- 为“丰富版面”加的细线、点阵、网格纹理、渐变底。
- 与内容无关的图标、英文占位词、装饰性引号。
- 只为了“统一”而给每块内容加的相同容器的边框与圆角。
- 从参考作品搬来、但与本项目事实无关的视觉母题。
- 每页都重复出现的 Logo、口号或色块。

**机械套用风格的症状**：把同一套样式（同样的卡片、同样的留白率、同样的字重对比）套到不同内容上，得到“一致”但读不出判断的作品。一致性应由**语法**承担（锚线、角色、尺度级），不由**样式**承担。

## 七、高创意任务：先扩大真实差异，再收敛

商业主视觉、品牌形象、电影级画面或核心概念不清的任务，先形成少量候选，不直接爱上第一个可执行方案。微任务和方向已明确的项目不强制探索。

1. 从项目事实清单中选择不同来源——机制、对象、行为、材料、时间或矛盾；让候选来自不同事实，而非同一事实换风格。
2. 每个候选用最短卡片记录：**事实来源、服务主张、主导视觉关系、首个关键画面、变奏方式、最大风险**。
3. **差异审计**：只改变配色、字体、器材形容词或轻微布局的候选合并。真正不同的候选应让受众注意到不同关系。
4. 若拿不准表达强度，可同时检验一个更强调尺度、裁切或空间的候选与一个更克制的候选；比较它们对理解、记忆和必要信息的实际影响，不预设“大胆”更好。
5. **停止条件**：新候选只是重复已有关系；或继续探索只剩事实不成立、成本明显不可行的方案。**候选数量不是质量指标。**

**差异的层次**，从低到高：

| 层次 | 表现 | 是否算真差异 |
|---|---|---|
| 属性层 | 换色相、换字体、换圆角、换背景纹理 | 不算 |
| 排布层 | 换栏数、换对齐、换图文位置 | 弱，通常不算 |
| 关系层 | 换主导视觉关系（尺度对照 → 时间序列）、换阅读方向、换焦点归属 | 算 |
| 论点层 | 换承载主张的那一项事实 | 算，且最强 |

只在属性层做三个方案，是同一个方案换了三次皮。评审时若三个方案能被一句话概括成“都是大图加标题”，说明探索没有发生。

## 八、概念与辨识度压力测试

- **替换主题**：换成无关项目后几乎不变，说明概念太通用。
- **去风格词**：删掉“高级、电影感、极简、未来感”，仍能描述主体与关系才成立。
- **去装饰**：拿掉标识、特效与流行样式，核心关系仍可读才成立。
- **理解成本**：隐喻的解释成本高于记忆价值时，改用更清楚的表达。
- **识别来源**：辨识度是否来自项目自身的对象、结构或行为，而非随机奇异。
- **变奏能力**：若概念要用于系列或跨媒介，它能否支持不同任务的表达，而不只是重复同一画面；单次作品不强制系统化。

先准确表达，再寻找不能被轻易替代的表达方式。辨识度不是刻意奇异，也不是每页制造新花样。

## 九、从障碍推导设计动作

本表处理**内容与主张层**的障碍；构图、空间与阅读路径的故障诊断见 `02`「构图故障诊断」。

| 可观察障碍 | 先判断 | 优先尝试 | 不要先做 |
|---|---|---|---|
| 受众不觉得这跟自己有关 | 场景与利害是否缺席 | 给出具体处境、代价或收益 | 加口号、加情绪化配图 |
| 受众理解了但不相信 | 证据类型是否匹配主张强度 | 补证据、降结论强度、交代限定 | 加大视觉冲击、加强断言语气 |
| 受众记住了但不行动 | 下一步是否明确 | 指明动作、主体、时机、成本 | 加行动口号按钮 |
| 内容很多但主张不明 | 是否在做“全面介绍”而非“一个结论” | 选一个主张，其余降级 | 把内容排得更紧 |
| 机制难懂 | 哪个步骤、部件或因果不可见 | 剖面、分步揭示、局部放大、关系图 | 用抽象图形替代机制 |
| 画面好看却记不住 | 缺少独有锚点或强调不足 | 选择项目特有的对象/关系并做变奏 | 随机符号、重复 Logo |
| 图像与文字重复表达 | 两者是否提供不同信息 | 图呈现形态/变化，文解释/限定/论证 | 删除必要说明或堆口号 |
| 有冲击但不可信 | 视觉暗示超出证据或物理逻辑 | 修正事实、比例、素材、因果 | 加强效果掩盖问题 |

## 十、何时比较方向

只在核心概念、叙事或信息关系有真实不确定性时比较少量方向。使用同一内容、媒介与验收标准，比较不同的设计假设，而不是只换字体、颜色或背景；出现清楚胜负即停止扩案。

取舍顺序：目标与事实 → 理解效率 → 辨识度与记忆价值 → 媒介适配与成本。选定后深化；除非新证据出现，不重新发明方向。

保留未选方向的关键差异记录——记录的是**它为什么被放弃**，不是它的外观。否则同一场讨论会在每次评审时重演。

## 十一、决策说明的边界

只记录影响后续制作、跨页一致性或维护的决定：问题、依据、主要取舍、重审条件。简单任务不生成决策日志；向用户说明结论与必要理由即可。

## 十二、短案例：让候选与概念都进入表达

任务：解释工业传感器的预测维护价值。

- **通用方向**：“未来科技、蓝色光效、智能工厂”——换成任何科技项目仍成立，不能解释产品价值。
- **候选 A｜机制**：把“故障前的微小持续偏差”转成稳定基准与细线偏移，突出早期预警。
- **候选 B｜行为**：把“信号到维护决定”转成连续证据链，突出何时以及为何介入。
- **候选 C｜后果**：把“非计划停机打断连续生产”转成节奏中断与恢复，突出业务损失；缺少停机证据则不采用。
- **选择与展开**：若首要目标是理解早期预警，选 A。首屏建立基准与偏移，机制页解释偏差捕捉，证据页保留正常区间与异常时间点。
- **落到表达系统**：焦点＝基准线上的偏离点；尺度＝基准极细、偏移极短但唯一饱和；阅读方向＝沿时间轴单向；后续证据页沿用同一时间轴，只有在解释另一机制时才改变结构。
- **验收重点**：受众能否区分正常波动与异常趋势，而不是是否觉得“科技感强”。
