# J2 · Editorial Space & Grid — 编辑空间与网格

> 高级感来自秩序：版心、网格、轴线、留白与对齐——不来自容器与装饰。
> 空间是判断出来的，不是剩下来的。参数是区间 + 理由，不是唯一答案（J1 §3.3）。
> 排印（字号、基线、字距、数字）归 J4；本模块只管空间与结构。

---

## 0. 空间判断（Spatial Judgment —— 画网格之前的构图智力）

留白与占幅由六个变量**共同**判出：**内容量 · 信息权重 · 视觉焦点 · 画布比例 · 视觉重量 · 阅读路径**。
"大留白 = 高级感"与"填满 = 丰富"是同一种懒惰的两个方向。**版心先于网格，网格先于元素。**

### 0.1 版心与占幅（先定版心，再画网格）

- **版心从内容体量推出**：先估这一页的视觉体量（字数、字段数、媒体数 × 各自权重与焦点强度），
  再决定版心占画布多少——不是先摆元素、再把剩余当留白。
- **比例贯穿三级**：画布 → 版心（占幅）· 版心 → 栏（分栏比）· 栏 → 字（行长）。
  每一级都是比例判断，不是默认值。
- 占幅参考（区间 + 理由，可偏离但要能说出为什么）：

| 画幅 | 版心横向占幅 | 理由 |
|:---|:---|:---|
| 16:9 幻灯 / 宽屏 | 76-90% | 宽画幅横向余量天然大；占幅低于 ~70% 时两侧形成无效空白，主体被挤成"中央孤岛"，内部反而拥挤 |
| A4 / 纵向文档 | 70-82%（含侧注可更宽） | 纵向阅读靠行长约束（J4 §2），外白承担持读与翻阅缓冲 |
| 海报 / 封面 | 由焦点策略决定 | 仪式感可以极空，但空的是"被指挥的空"——每寸空白都指向焦点，而非没想清楚的剩余 |

- **满版也是版心判断**：整页出血图/整页色底的"版心 = 画布"，其上的文字区自成子版心——
  出血不是免除空间判断的理由。
- **有效留白 vs 无效空白**：有效留白有方向、有归属——为某个焦点蓄势、为某次停顿呼吸、
  为某个分组划界。无效空白无人认领，最常见形态是内容居中收窄后两侧漏出的"对称边条"。
  判断法：把每块留白当元素问一句"**它在为哪个内容工作？**"答不出 = 无效 = 版心误判。
- **边距是比例不是余数**：外边距 > 组间距 > 组内距，约 2-3 倍级差成体系；边距体系应让人
  一眼读出"什么和什么是一伙的"。边距过压（元素贴边）与边距失控（版心龟缩）是同一个错误的两端。

### 0.2 视觉重量与重心

- 每个元素都有重量：**面积 × 深浅 × 密度 × 饱和度**。大字重、图像、深色块重；浅灰、细线、留白轻。
- **重心略高于几何中心**（光学中心）：主焦点落在画布上部 1/3 与 1/2 之间的地带最稳。
  重心过低 = 下坠，过高 = 漂浮。
- **非对称靠配重，不靠对称**：一侧的大图用另一侧的文字块 + 留白平衡——是力矩平衡，
  不是镜像摆放。留白本身可以是配重。
- 诊断直觉——三个失败形态（见到即回 0.1 重判版心，加减元素救不了）：
  1. **中央孤岛**：内容龟缩画布中央、两侧无效空白、内部拥挤——版心太窄，先放宽版心再谈留白；
  2. **顶格窒息**：边距被压到消失、元素贴边——外白不是可侵占的余量；
  3. **均匀撒豆**：元素等距平铺全画布、无重心无层级——密度均匀 = 判断缺席。

### 0.3 阅读路径（构图跟着眼睛走）

- **先判路径，再定构图**：幻灯/首屏默认 Z 形，长文 F 形，报告单轴向下，海报为焦点引导
  （眼睛先被焦点抓住，再被轴线送走）。
- 路径上每一站都该有内容接住；路径之外的角落可以安静——**不需要四角均衡**。
- 焦点到第二站的距离与方向制造张力：顺路径 = 流畅，逆路径 = 刻意停顿（全案至多一次）。

### 0.4 舒展的验收标准（四句同时成立）

**有呼吸但不松散 · 内容充足但不拥挤 · 版心舒展但不空洞 · 密度丰富但不失高级。**
任何一句不成立，回 0.1 重判版心与占幅——不是靠加元素或删元素打补丁。

## 1. 网格性格（先判性格，再画网格）

| 性格 | 骨架 | 适用 | 理由 |
|:---|:---|:---|:---|
| **Swiss 瑞士** | 严格网格、齐左不齐右、非对称、无装饰 | 品牌文档、海报、信息页 | 客观清晰来自对齐与层级本身 |
| **Broadsheet 报纸** | 多栏 + 细线分隔、密排、眉题脚注齐备 | 长文、研究、编辑页 | 密度是编辑力，细线是栏的边界 |
| **Report 报告** | 单栏宽正文 + 侧注/边栏、章节大留白 | 白皮书、咨询报告 | 阅读动线单一，论证连贯 |
| **Deck 汇报** | 16:9 画幅、大主张区 + 证据区、字段行化 | 演示文稿、提案 | 远看读主张，近看读证据 |
| **Gallery 展陈** | 等距陈列、大留白、图主导 | 作品集、展板 | 公平陈列，让内容对话 |
| **Museum 仪式** | 居中或极端悬挂、极大留白 | 海报、封面、宣言 | 肃穆来自空旷与克制 |
| **Data 数据新闻** | 图表主导 + 标注层 + 旁注轨道、直接标注无图例 | 信息图、数据专题 | 让标注与图形同层说话；需要图例 = 表达没做完 |

- **混合有主次**（80:20 量级）：主格定骨架，辅格出一处变奏。
- **页边距**：参考 `max(6vw, 48px)` 量级的外白边；版心先定（§0.1），元素后进。
- **栏**：幻灯/海报 2-6 栏；编辑页 6-12 栏；每栏行长见 J4 §2。
- **网格是看不见的**：读者看到秩序，看不到格子。把网格画成可见线框 = 失败。

## 2. 版心经典（印刷与长文档的锚点）

- **Van de Graaf / Tschichold 版心**：9×9 网格推出的经典书页几何，内/上/外/下边距约成
  1:1.5:2:3，纵向落在画幅对角线上——不是规则，是"被验证数百年"的起点；偏离须有理由。
- 密档取其紧凑变体（边距整体降一档），舒档取其舒展变体；数据与图表密集的报告页，
  版心可比正文页更宽。
- 幻灯/屏幕不受此约束（16:9 的版心判断见 §0.1）。

## 3. 轴线系统（Axis System —— 秩序的骨架）

- 全页元素挂在 **2-4 条命名轴**上：**左轴**（左缘线）· **栏轴**（分栏线）·
  **重心轴**（焦点的悬挂线）· **右轴**。每个新元素必须回答"我挂在哪条轴上"。
- **对齐即归属**：读者用对齐线读出"什么和什么是一伙的"——比任何容器都诚实。
- **断轴即变奏**：有意的悬挂缩进、跨栏、出血是层级与节奏；无意的错位是事故。
- **光学对齐**：圆、图标、粗字与细字并置时按视觉中心校准，不按外框机械对齐（执行细节见 J4 §6）。

---

## 4. 线性构图语法（Composition = 线与留白）

**原则：秩序优先用线性手段建立。卡片是最后手段，不是第一手段。**

| 装置 | 用法 | 理由 |
|:---|:---|:---|
| **纵轴** | 全页元素挂在 2-3 条竖轴上（左轴、栏轴、右轴） | 对齐即秩序，轴是隐形骨架 |
| **横线（细）** | 0.5-1px 分隔线划分层级（眉题下、页脚上、字段间） | 线比框轻，比留白明确 |
| **局部贯穿线** | 一根线只穿过局部宽度，连接标题与内容、图与注 | 视觉连接不靠包裹 |
| **错位** | 有意的纵向错落（缩进、悬挂、图文咬合） | 秩序中的活力；有基线纪律的错位 ≠ 随手错位 |
| **字段结构** | 标签-值-注成行，细分隔线断行（J4 §4.2） | 信息以行与轴存在，不以卡片存在 |
| **留白** | 大面积留白作为结构（分组靠空隙，不靠边框） | 呼吸即层级 |
| **编号** | 01 / 02 / 03 悬挂编号建立序列 | 序列感不靠项目符号 |

**反卡片墙**（一票否决级直觉）：
- 连续 ≥3 个同尺寸圆角容器 = 卡片墙 = 判断缺席。
- 每次想加容器，先试：一根线 + 留白 + 对齐能不能解决？几乎总是能。
- 容器只在"内容确实是对象"（可点的项、独立引用）时使用，且全案 ≤2 种容器样式。

## 5. 错位与张力（秩序中的活力）

- 错位三式：**悬挂**（缩进成层）· **咬合**（图文边缘互相切入）· **错列**（基线纪律下的纵向错落）。
- 张力来自不均：非对称配重（§0.2）、尺度对比（特大 × 特小）、密度对比（一侧密一侧疏）——
  **每页至多两处张力源**。
- 全部均匀 = 无张力；处处错位 = 无秩序。**张力是编排出来的，不是撒出来的。**

---

## 6. 空间物理底线（执行时）

- 边距级差：外 > 组间 > 组内，约 2-3 倍；间距取 4 的倍数（基线系统见 J4 §2）。
- 版心内不留"无人认领"的空白（§0.1 判断法）。
- 分组优先用空隙，其次用线，最后才用容器（层级信号阶梯见 J4 §5）。
