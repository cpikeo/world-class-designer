# J1 · Design Judgment — 设计判断（一切设计之前的智力）

> 这份文档是整个 Skill 的大脑。它不规定唯一视觉答案，只训练取舍。
> 规则回答"为什么"，判断回答"这一次选哪个"。**一次强判断 > 十次弱检查。**

---

## 0. 唯一主链（Everything Lives Here）

```
理解 → 判断 → 编排 → 构图 → 执行 → 校验
```

阶段映射：理解 = §1 策略五问 + §2.1；判断 = §2.2-2.4；编排 = §2.5-2.6；
构图 = §2.7-2.10（排印 · 色彩 · 媒体 · 节奏）；执行 = §2.11；校验 = §6。

判断链全序（全案一条）：
**内容 → 主张 → 信息权重 → 焦点 → 空间结构 → 构图骨架 → 排印 → 色彩 → 媒体 → 节奏 → 执行**。

判断做对了，执行只是手工艺；校验只是确认而非重来。

**补丁禁令**：发现问题时先定位"错误发生在判断链哪一步"→ 回那一步重判 →
下游随之重推。在执行层打局部补丁 = 把判断错误埋进成品。
若校验频繁推翻执行，说明判断没做完——回"理解/判断"补课，而不是加检查。

---

## 1. 策略推导（理解阶段 · Creative Strategy Director）

设计决策从这五问流出：

1. **Audience 受众**：谁在什么场合看？带着什么状态与疑虑？（说不清就问，不脑补画像）
2. **Objective 目标**：这一次接触要改变受众的什么？（知道/理解/信任/行动——只选一个首要）
3. **Message 主张**：他只会记住的那句话是什么？（≤20 字，会被转述的话，不是口号）
4. **Insight 洞察**：**为什么这个主张对他成立？**——关于他处境的那个锐利真相
   （如："农人被概念伤过，只信地里的证据"；"董事只关心现金流与风险"）。
5. **Visual Concept 视觉概念**：主张 × 洞察的视觉化方向，一句话
   （如："把数据写在田埂上"；"让风险一页可见"）。

**产出**：策略五联（写进判断卡）。
**常见失败**：没有 Insight——主张悬空，设计再美也打不中；Insight 是自己的感慨
而非受众的处境；或 Visual Concept 是风格词（"高级极简"）而非概念——
**Visual Concept > Styling**：概念回答"为什么这样看世界"，风格只是"长什么样"。

## 2. 判断链 11 步（判断 → 构图 → 执行）

按顺序回答。**每个问题只判一次，写下来，不再回头改。**
中途改判 = 链失效，整链重判，不允许局部打补丁。

### 2.1 内容 [理解]
- **问什么**：内容全貌是什么？媒介与开本？数据、论点、故事各有多少？
- **产出**：媒介+场合一句话、内容清单（全部素材过目）。
- **常见失败**：没读完内容就开始找"参考风格"。

### 2.2 主张 [判断]
- **问什么**：这一页的**主张**是什么？（是主张，不是话题）
- **依据**：§1 策略五联。多页作品：每页一句主张 + 全案一条主线。
- **产出**：The Message（≤20 字）。
- **常见失败**：写"话题"（市场概况）而非"主张"（市场在向 X 收敛）。

### 2.3 信息权重 [判断]
- **问什么**：字段、数字、关键词、证据、脚注——各自的真实权重？
- **依据**：对主张的贡献度，不是内容顺序或字数。
- **产出**：三级权重（主角 1 / 证据 2-4 / 其余可删）+ 密度档位
  （**低** 仪式/海报 · **中** 汇报/编辑 · **高** 报告/文档，J7 §1.3）。
- **常见失败**：所有信息均匀排列，每个都想被看见。

### 2.4 视觉焦点 [判断]
- **问什么**：什么必须突出？**什么必须消失？**
- **依据**：主张的视觉化只有一个重心。
- **产出**：每页一个焦点（元素级）+ **消隐清单**（降级、去色、缩号、删除）。
- **常见失败**：只决定突出什么，从不决定消失什么。

### 2.5 空间结构 [编排]
- **问什么**：画幅多大？内容的视觉体量多大？**版心占幅多少、留白归谁？** 栏怎么分？
- **依据**：媒介规范（幻灯 16:9 / 报告 A4 / 海报任意）+ 密度档位 + 空间判断（J2 §0-2）：
  版心由**内容量、信息权重、画布比例、视觉重量、阅读路径**共同判出——
  不是默认对称留白，也不是元素摆完剩下的。
- **产出**：空间决定（版心占幅 + 边距级差 + 阅读路径）+ 网格决定（网格性格、栏数、基线）。
- **常见失败**：先画框再想内容；把"大留白"当高级感的默认答案——内容压成中央孤岛、
  两侧漏出无效空白；或反向为填满画布堆元素、把边距压到窒息。

### 2.6 构图骨架 [编排]
- **问什么**：视觉秩序用什么建立——轴线、对齐、细分隔线、留白、错位、字段结构？重心落在哪？
- **依据**：J2 §3-5 线性构图语法。**优先线与留白，减少厚重容器与卡片墙。**
  允许非对称配重、尺度对比与密度对比形成张力（每页至多两处张力源）。
- **产出**：一页构图草案（元素挂在哪条轴上、哪里断线、哪里错位、重心位置与配重方式）。
- **常见失败**：用卡片/边框给每个元素盖房子——秩序没建立，容器先堆满。

### 2.7 排印 [构图]
- **问什么**：排印声音、字号阶、层级信号、数字与字段结构怎么成立？
- **依据**：J4 一案一声 + 比例系统 + 层级信号阶梯。
- **产出**：声音锁定 + 字号阶（含比例）+ 层级方案（空隙/字重/色阶/线/字号如何分工）。
- **常见失败**：随手字号；加粗当唯一强调；中西文机械同号。

### 2.8 色彩 [构图]
- **问什么**：主色 / 中性色 / 强调色如何分工？强调色只有一个吗？
- **依据**：J3 色彩推导链与三角色模型；灰度先行。
- **产出**：色彩骨架（三角色 + 职责），强调色全案唯一；注意力预算——一页只有一个最高彩度点。
- **常见失败**：为"不单调"加第二强调色或渐变——单调不是色彩的问题，是排版的问题。

### 2.9 媒体 [构图]
- **问什么**：这个设计**真的**需要图像、图表或图标吗？
- **依据**（三句判断，参数表归 J5）：
  - 图像给感受与情绪，图表给关系证明，图标给指引——用错即装饰；
  - 一个数用大数字排印（J4 §4.1），2-5 个数用字段行（J4 §4.2），有关系才画图（J5 §2）；
  - 要"高级感"不需要新素材——需要减法与更好的排印。
- **媒体晚于排印与色彩进入**：图调并入色彩骨架、图标并入线与排印语言——
  媒体服务于已成立的骨架，而非先于骨架存在。
- **产出**：媒体清单，每项标注"为什么不能没有它"。答不出的，不出现。
- **常见失败**：图标凑满一行、为一个数画图表、配图三张成墙。

### 2.10 节奏 [构图]
- **问什么**：这一页内部与前后页之间，密度、尺度、冷热如何起伏？
- **依据**：多页 → J7 §2（冷热拍交替、每 5-8 页一个视觉高潮且全案 ≤2 个、
  母题同构出现 ≥2 次）；单页 → 页内张力（J2 §5）。
- **产出**：节奏方案（本页在节奏曲线上的位置）+ 母题与变奏计划。
- **常见失败**：连续同构区块 = 节奏失败；十页十个亮点 = 零个亮点。

### 2.11 执行 [执行]
- **问什么**：构图定案变成成品时，字号阶、基线、线宽、间距是否成体系？
- **依据**：J2 §6 + J4 §6 物理底线 + J8 §1 硬底线。
- **产出**：成品 + 一次校验（§6）。
- **常见失败**：执行时"随手微调"破坏判断卡的系统性。

## 3. 取舍语法（Trade-off Grammar）

### 3.1 优先级栈（冲突时自上而下裁决）

```
主张清晰（So-What） > 信息完整 > 审美 > 工艺 > 装饰
```

**低层为高层让路**——这是唯一的"一票否决"。

### 3.2 七组反复出现的取舍

| 取舍对 | 两难 | 判断依据 | 常见错误 |
|:---|:---|:---|:---|
| **密度 vs 呼吸** | 信息全 vs 高级感 | 看 2.3 密度档位：报告页选密度，海报页选呼吸 | 所有页同一留白率 |
| **舒展 vs 空洞** | 版心大气 vs 两侧漏空 | 留白必须有归属（J2 §0.1）：为焦点、停顿或分组工作；无人认领的空白 = 版心误判，不是高级感 | 居中收窄冒充留白，中央拥挤两侧空 |
| **清晰 vs 丰富** | 一眼懂 vs 元素多 | 主张 3 秒可得才算清晰 | 用装饰填版面 |
| **工艺 vs 稳定** | 细节精致 vs 节奏稳定 | 全案一处 95 分工艺 > 处处 60 分 | 每页都有"小亮点" |
| **新奇 vs 熟悉** | 差异化 vs 可读性 | 只在一个维度新奇，其余继承心智 | 全面求新 |
| **表达 vs 静默** | 张力 vs 克制 | 二八律：70-90% 静默，10-30% 表达 | 50:50 均分 |
| **统一 vs 重复** | 一体感 vs 单调 | 继承骨架与语言，变奏构图/权重/强调色用法——每次只变一个维度 | 每页换装饰花样的假统一 |

### 3.3 参数的正确用法

J2-J8 中所有数字（字距、线宽、比例、面积比）都是**参考区间 + 形成理由**：
偏离可以，必须能说出为什么；说不出理由的偏离 = 失控；不敢偏离的执行 = 抄规范。

## 4. 选择性智能（Selective Intelligence）

### 4.1 路由与休眠
媒介→模块矩阵在 [SKILL.md §5](../SKILL.md)（唯一路由表）。两条补充原则：
- 一次任务激活 3-6 个模块为常态。**全量加载 = 判断力下降。**
- 反向检查：某模块加载后没留下任何决策痕迹，下次同类任务就不再加载。

### 4.2 一次判断原则
网格 · 版心策略 · 字号阶 · 色彩关系 · 图标语言 · 密度档位 · 线宽语言——**全案只判一次**，
后续页面继承并局部变奏（换构图、换权重、换强调色的一处用法，每次只变一个维度）。

### 4.3 跳过判断
- 改字/换数/微调 → 直接执行，仅过 J8 §1 底线。
- 系列页 → 只做 2.2-2.10 的页面级判断。
- **禁止**对微任务输出诊断块、评分卡——那是过程表演。

## 5. 反平庸减法（设计完成后，删一轮）

1. 有没有无功能的线、点、框、图标、渐变？（删到有理由为止）
2. 有没有第二重心在抢戏？（降级或删除）
3. 有没有"因为别人都有"而存在的元素？
4. 有没有审美反模式残留？（J6 §6）
5. 有没有 50:50 的妥协？（拉回 80:20）
6. 有没有无人认领的空白或被压缩的版心？（中央孤岛/均匀撒豆是空间误判——回 2.5 重判，不是删元素能解决的）

## 6. 校验 — 一次强审查（One Strong Critique）

生产后**只做一轮**：12 个决定性问题 + 底线清单，不过即改，改完即交付。
**本清单是全案唯一校验链**（模块内不设自查）。

**A. 主张与焦点（5 问）**
1. 3 秒模拟：我记住了什么？是否就是主张？
2. 每页是否只有一个主重心？第二重心在哪里、为什么还在？
3. 这一页给的是主张还是话题？
4. 信息权重可读出"主角-证据-其他"吗？
5. 消隐清单执行了吗？

**B. 空间与构图（3 问）**
6. 退后一步看整页剪影：内容自然占据画布吗？有无中央孤岛、顶格窒息或均匀撒豆（J2 §0.2）？
7. 每块留白都有归属吗（为焦点蓄势、为停顿呼吸、为分组划界）？有无无人认领的无效空白？
8. 重心稳吗？非对称有配重吗？张力（尺度/密度/错位）是否 ≤2 处且都有意图？阅读路径每一站都有内容接住吗？

**C. 排印与一致（4 问）**
9. 字号阶、字距、行距、基线是体系还是随手（J4）？数字对齐诚实吗？
10. 图标若存在：语言统一、且每个都不可删吗？图表直接回答主张吗（J5）？
11. 线、留白、轴建立了秩序，还是卡片在建立秩序？
12. 视觉概念（§1.5）贯穿全案了吗？多页：节奏有起伏、母题有变奏吗？
    全案四句——统一而不重复 · 精致而不堆砌 · 充实而不拥挤 · 克制而不单薄——成立吗（J7 §4）？

**D. 硬底线**：按 [J8 §1](J8-Production-Verify.md) 事实核对（对比度、信息诚实、一致性、可访问）——不过即改。

> **校验是确认，不是重来。** 若 A/B/C 中 ≥3 问不过，问题在判断——回 §1-2 重判。
> B 组任一问不过，多半是 2.5 的版心误判——回空间结构重判，加减元素救不了构图。

## 7. Learn — 一条教训

交付后记录**一条**（只一条）：
```
lesson: <判断链哪一步差点出错/出错了>
rule-of-thumb: <下次的一句话启发式>
```
启发式超过 ~30 条时，合并同类，删最弱的。技能的进化来自启发式累积，不来自规则堆叠。

