# 构图、空间与视觉张力

## 先确定视觉秩序

构图先确定五件事：第一焦点及其重要性、第二阅读关系、视线入口与落点、稳定支点与冲突位置、空间承担的职责。

视觉重量由面积、明暗、饱和度、细节密度、轮廓、方向、语义重要性和图像吸引力共同决定。面积最大的元素不一定最显眼；小面积高对比元素也可能夺走注意力。

## 以一个主导关系建立张力

先选一个与主张有关的主导关系，再决定是否需要辅助关系。可用关系包括：微观/宏观、内部/外部、承载/悬置、稳定/推进、密集/空旷、柔软/坚硬、规则/例外、主张/反证、瞬间/长期等。

有效张力包括可感知的**力量差异**、清楚的**方向与支点**，以及服务于主体/信息/情绪的**落点**。

若所有元素都倾斜、重叠、发光或运动，张力便失去层级。若每页都达到高潮，全案也会失去节奏。强烈构图不等于元素堆叠；克制构图也不等于把内容缩小并留出大量空白。

## 空间必须有职责

空间可用于分组、强调、呼吸、停顿、方向、尺度对照或文字保护。大片空白出现时，先判断它是有意的停顿，还是内容、主体或关系不足；不要自动填满，也不要自动保留。

网格用于建立关系，不要求所有元素同形。选择少量稳定锚线；偏离锚线必须产生强调、冲突或阅读路径，而非随意摆放。

避免普适性的固定留白比例、列数、边距和卡片规格。尺度与密度要匹配内容、输出尺寸、观看距离以及阅读时长。

## 故障诊断：先改根因

| 可观察故障 | 可能根因 | 优先修正 |
|---|---|---|
| 缩略图上所有元素同等重要 | 焦点未建立或对比点过多 | 降级次要焦点，重新分配主体尺度、位置和对比 |
| 主体像贴在页面中央 | 主体规模和画幅不匹配，空间缺少另一项职责 | 放大或偏置主体；让证据、文字或第二视觉承担剩余空间 |
| 空白很大但画面无力量 | 空间没有形成对照，主体/内容规模不足 | 重设主体尺度、关系或信息结构，而不是加装饰填空 |
| 页面拥挤、内容相互粘连 | 分组层级不明，栏宽或行长不合理 | 先重组内容和分组，再调版心、栏宽与文字尺度 |
| 页面散乱、左边缘不断变化 | 缺乏稳定锚点，或有意偏移没有目的 | 建立少量锚线；只有有意义的元素才偏离 |
| 图像抢占文字的注意力 | 对比、细节或裁切与信息层级冲突 | 调整裁切和位置、简化背景或保护文字区域 |
| 有冲击但没有方向 | 多种张力互相抵消 | 只保留一个主导方向，删去抵消它的效果 |
| 多页布局机械重复 | 页面角色没有变化，复用退化为复制 | 改变页面功能、焦点、尺度、密度或媒介，保留底层识别逻辑 |

## 让动势可读

动势可由斜向构图、尺度递进、重叠、裁切、方向线、主体朝向、重复间距或真实运动形成。仅使用能帮助受众理解力量、顺序或时间的手段。确定入口、推进方向、阻力和落点；避免多个视觉方向竞争。

静态页面用视线和形态关系表达动势；动画/视频还需交代动作起因、速度、重量、时序与停稳方式。“高级动势”不等于强制倾斜或动态模糊。

## 两次尺度检查

- **缩小检查**：在目标缩略图或观看距离下，主焦点、层级和核心关系是否仍然成立？
- **放大检查**：文字、边缘、裁切、材质、细节和间距是否暴露执行问题？
