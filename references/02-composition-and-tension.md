# 构图、空间与视觉张力

## 先建立视觉秩序

构图不是摆放元素，而是安排注意力。先确定：
1. 第一焦点及其承担的主张。
2. 第二阅读关系及证据顺序。
3. 视线入口、推进方向与落点。
4. 稳定支点与有意冲突的位置。
5. 每块空间承担的职责。

视觉重量由面积、明暗、饱和度、细节密度、轮廓、方向、语义重要性和图像吸引力共同决定。面积最大的元素不一定最显眼；小面积高对比元素也可能夺走注意力。

## 从内容关系到画面关系

- 先给内容分组和排序，再决定位置；不要先选版式再塞内容。
- 用少量稳定锚线建立关系。偏离锚线必须产生强调、冲突或阅读路径。
- 让主张、证据、注释和导航具有不同视觉权重；不要仅靠字号微差区分。
- 主体尺度由观看距离、信息职责和周围对照共同决定，不由“必须大气”决定。
- 多页作品保留底层锚点，同时让页面功能、焦点、密度或媒介产生必要变化。

网格用于建立关系，不要求所有元素同形。避免无任务依据的固定留白比例、列数、边距和卡片规格。

## 高创意任务：做构图研究，不做表面变体

关键主视觉或构图存在真实不确定性时，保持内容、字体、色彩和主要素材不变，先做少量结构研究。每次只改变一个主导构图假设，避免样式变化掩盖结构差异。

| 研究轴 | 要作出的决定 | 必须保护 |
|---|---|---|
| 尺度冲突 | 哪个对象或细节需要反常放大/缩小，形成什么认知 | 真实比例关系不被误读，关键结构可辨 |
| 偏置与裁切 | 主体为何离开中心，裁切把视线推向哪里 | 必要信息、主体识别和文字安全区 |
| 方向与支点 | 力量从哪里进入，被什么阻挡，最终落在哪里 | 阅读顺序和唯一主导方向 |
| 密度与空旷 | 哪组信息形成压力，哪块空间形成停顿或对照 | 分组、注释和实际观看距离 |

这些是探索轴，不是每次都要完成的模板。每个研究先写一句“通过 [结构变化] 强化 [主张/关系]”，无法填写就不值得制作。

大胆方案必须通过四道门：**语义不失真、焦点仍清楚、必要信息仍可读、目标媒介可实现。** 需要依靠长篇解释才能成立的构图，优先简化或放弃。选定结构后再进入色彩、材质和细节；新研究只重复视觉重量关系或制造装饰差异时停止。

## 以一个主导关系建立张力

先选一个与主张有关的主导关系，再决定是否需要辅助关系。可用关系包括：微观/宏观、内部/外部、承载/悬置、稳定/推进、密集/空旷、柔软/坚硬、规则/例外、主张/反证、瞬间/长期。

有效张力包括可感知的**力量差异**、清楚的**方向与支点**，以及服务主体、信息或情绪的**落点**。若所有元素都倾斜、重叠、发光或运动，张力便失去层级；若每页都达到高潮，全案也会失去节奏。

强烈构图不等于元素堆叠；克制构图也不等于把内容缩小并留出大量空白。

## 空间必须有职责

空间可用于分组、强调、呼吸、停顿、方向、尺度对照或文字保护。大片空白出现时，判断它是有意的停顿，还是内容、主体或关系不足；不要自动填满，也不要自动保留。

文字保护区不是机械留一块空白：还需检查图像细节、局部对比、视线竞争和实际断行。空间调整后必须复查信息分组是否仍然成立。

## 短案例：先修关系，再修样式

问题：一页有一项核心结论和四项证据，缩略图上五个区域同等显眼。

- **根因**：结论与证据被处理成五个并列单元，主次关系没有进入构图。
- **最小改动**：让结论成为第一焦点，将四项证据组织成同一阅读序列；保留必要限定条件，不通过整体缩小制造留白。
- **预期证据**：缩小时先读到结论，放大后能按顺序核查证据；没有新增溢出或脚注丢失。
- **不应先做**：给五块区域分别换色、加阴影或增加装饰图标。

## 故障诊断：先改根因

| 可观察故障 | 可能根因 | 优先修正 |
|---|---|---|
| 缩略图上所有元素同等重要 | 焦点未建立或对比点过多 | 降级次要焦点，重新分配尺度、位置和对比 |
| 主体像贴在页面中央 | 主体规模和画幅不匹配，空间缺少职责 | 放大或偏置主体，让证据或第二视觉承担剩余空间 |
| 空白很大但画面无力量 | 空间没有形成对照，主体/内容规模不足 | 重设主体尺度或关系，而不是加装饰填空 |
| 页面拥挤、内容粘连 | 分组层级不明，栏宽或行长不合理 | 先重组内容和分组，再调版心与文字尺度 |
| 页面散乱、左边缘不断变化 | 缺乏稳定锚点，或偏移没有目的 | 建立少量锚线，只让有意义的元素偏离 |
| 图像抢占文字注意力 | 对比、细节或裁切与层级冲突 | 调整裁切和位置、简化背景或保护文字区域 |
| 有冲击但没有方向 | 多种张力互相抵消 | 保留一个主导方向，删去抵消它的效果 |
| 多页布局机械重复 | 页面角色没有变化，复用退化为复制 | 改变页面功能、焦点、尺度、密度或媒介 |

## 让动势可读

动势可由斜向构图、尺度递进、重叠、裁切、方向线、主体朝向、重复间距或真实运动形成。确定入口、推进方向、阻力和落点；避免多个视觉方向竞争。

静态页面用视线和形态关系表达动势；动画/视频还需交代动作起因、速度、重量、时序与停稳方式。“高级动势”不等于强制倾斜或动态模糊。

## 两次尺度检查

- **缩小检查**：在目标缩略图或观看距离下，主焦点、层级和核心关系是否仍成立？
- **放大检查**：文字、边缘、裁切、材质、细节和间距是否暴露执行问题？
