# 版面结构、构图与视觉张力

本文件拥有：信息架构到版面的推导、版面原型、平衡与重心、网格与自由版式、尺度与占幅、边缘与裁切、空间职责、层次反差、跨页构图节奏。字体执行见 `03`，品牌与叙事推进见 `05`。

## 一、版面推导：从内容到结构

版面不是选出来的，是推出来的。五步顺序不可颠倒，任何一步跳过都会得到“排得整齐但没说完”的页面。

**1｜量。** 清点内容单元：字数、类型（主张句/证据/数据/引文/图像/注释/导航）、阅读成本。目的不是计数，而是找出可以删除、合并、压缩、改成图形或降为注释的部分。**内容过载的第一反应必须是删，不是缩。**

**2｜责。** 给每个单元定职责：

| 职责 | 判断标准 | 版面待遇 |
|---|---|---|
| 主张 | 删掉它，页面就没有存在理由 | 占据第一焦点，允许唯一的大尺度 |
| 证据 | 主张必须有它才成立 | 可比较的重复结构，稳定锚线 |
| 解释 | 说明机制、因果、条件 | 依附于主张或证据，不与主争焦点 |
| 限定 | 约束结论的适用范围 | 小、近、清楚，不隐藏 |
| 补充 | 有则更好，无则不损 | 可删；保留时压到边缘层 |
| 导航 | 帮助定位与回看 | 恒定的位置与格式，不参与竞争 |

判据：如果两个单元获得相同的版面待遇，它们必须具有相同的职责。职责不同而待遇相近，页面就读不出主次。

**3｜序。** 排出阅读顺序与依赖关系：谁必须先被看到，前一个不成立时后一个是否失效。有依赖的单元可以相邻、嵌套或共用一条锚线；无依赖的单元才可以并列。**并列是给真正等权的内容用的，不是默认排版方式。**

**4｜场。** 给每块分配空间职责：主导、支撑、对照、停顿、边界。这一步的产物是“哪一块占据画面的大部分面积”，而不是“分成几栏”。栏数是场的产物。

**5｜形。** 前四步确定后，结构几乎是唯一解。此时才决定栏数、边距、焦点坐标、图版比例。

反向检验：拿到成品页面，遮住内容只看灰块分布，能否说出这页的主次与顺序？说不出，说明第 4 步没做。

## 二、版面原型：按内容关系命名

下面不是模板库，是**内容关系的结构对应**。必须先能说出内容关系，才能选；说不出时，任何结构都是装饰。

| 内容关系 | 结构倾向 | 成立条件 | 失效条件 |
|---|---|---|---|
| 一个主张压倒其余 | **单点主导**：一个巨大元素 + 一条极窄的支撑带 | 主张足够短、足够硬；支撑信息可压缩成一列 | 支撑信息必须被逐条读到，且无法压缩 |
| 两种力量对峙、对比、前后 | **双极对峙**：两块体量相当，中间留出可读负空间，靠明度或尺度之一裁决 | 两极内容量接近；对峙关系真实存在 | 两极内容量差到数倍，会读成主次而非对峙 |
| 过程、时间、因果 | **序列递进**：沿单一方向递进，间距编码节奏，断点编码条件变化 | 段数可控，可分组成层 | 段数过多且无分组，退化为流程图 |
| 对象本身即证据 | **满幅沉浸**（含近裁）：对象占据画面，文字退到边缘作标注 | 对象细节密度足以支撑近看 | 细节不足，放大后是空 |
| 多单元等权且需比较 | **模块并列**：等距单元 + 统一内部结构，差异只出现在被比较的维度 | 单元内部内容长度接近 | 长度差异大，等距会制造假对齐 |
| 论点需要一个证据场 | **层叠深度**：主体在前、证据在后，用缩放、错位、透明建立深度 | 层数不多，前后景对比足够 | 层数过多，或对比不足导致粘连 |
| 内容极少但需仪式感 | **极端留白**：一个元素、一条边界、一个落点 | 存在一个真正值得放大的对象 | 缺对象时只剩空 |

同一作品中允许并用多种原型，但**一页只用一种主导原型**。混用两种以上会让读者无法判断该从哪里开始。

## 三、平衡：力矩，不是对称

视觉重量 ≈ 面积 × 对比度 × 细节密度 × 语义权重。平衡不是两侧重量相等，而是**力矩相等**：重的一侧靠近轴线，轻的一侧离轴线更远。

- **重心落点**：眯眼或缩到缩略图，看视觉重心落在哪里。落在正中容易呆板，落到画幅外会失衡。
- **允许失衡，但要有回收**：倾斜、下沉、向一角堆积可以表达失控、紧迫、失重，前提是另有元素把视线拉回主张。没有回收的失衡只是没排好。
- **三个动作**：**锚线**（少数几条贯穿的边、基线、轴线）建立秩序；**偏离**（有理由的偏移）产生强调；**回位**（偏离之后必须有一个元素把视线带回主张）。只有偏离没有回位，页面会散。
- **不对称的实质**：不是左边大右边小，而是让读者感到“这里有一个决定”。等分、居中、完全对称通常意味着没有做决定——除非仪式感、类型本身（如碑刻、通栏标题、目录）要求对称。

## 四、网格与自由版式

网格的职责不是填格子，而是**让读者在第二页就能预测位置**，从而把注意力全部留给内容。栏宽决定行长，栏距决定分组强度，基线决定文字跨栏时的呼吸。

判断网格是否有效：翻到下一页，读者是否不需要重新学习版面？如果需要，网格没建立；如果每页都能预测且毫无意外，网格过度了。

自由版式不是没有网格，而是**临时放弃某一条规则并说明理由**。每一次破格都要付出补偿：

| 破格动作 | 它建立什么 | 必须补偿什么 |
|---|---|---|
| 元素跨栏 | 该内容比栏重要，或需要更长的行长 | 跨栏后的行长要在可读范围内；跨栏处不能正好断句 |
| 越出边距 / 出血 | 世界比这一页更大 | 同类元素不能同时内缩；文字绝不进裁切区 |
| 打破基线 | 制造节奏断点或强调 | 同一视区内不超过一处；断点后要有明确的回到基线 |
| 图像侵入文字区 | 图文互文，而非分区 | 文字必须落在可预测位置，且通过最坏区域对比检查 |
| 文字压图 | 让文字成为画面的一部分 | 图必须让出足够暗或足够亮的一块；不得切断一句话 |

**图文穿插的许可条件**：文字位置可预测、对比在图像最坏区域仍成立、图不切断语义单位。三条缺一，就退回分区。

**重叠**建立深度与因果，但两层都必须可辨。重叠区的可读性按最坏情况判断（文字若跨过图像最亮处与最暗处，两处都要过），不能按平均对比判断。

## 五、尺度、占幅与比例

- **主体尺度由职责决定**：证明型图像要看清细节（近），营造型要看关系（远），标识型要看清轮廓（中）。不要为了“大气”缩小主体，也不要为了“冲击”放大到失去信息。
- **占幅是权力**：给某元素更大面积，等于宣布它更重要。若它并不更重要，读者会被误导。
- **比例判断**：画幅形状应与内容形状匹配。横向过程进竖幅会挤压，纵向对象进横幅会两侧空。改画幅常常比改内容更省事。
- **尺度的对照才有意义**：一个物体显得大，是因为旁边有小的参照。孤立放大只得到“大”，不得到“重要”。
- **极端尺度是有效工具**：远小于常规的注释、远大于常规的单个数字、只占一角的图像，都能建立层级。前提是它服务主张，而不是为了显得特别。

## 六、边缘、裁切与延伸

边缘是版面最有力也最容易被忽略的工具。

- **贴边 vs 内缩**：贴边表示“延续到画外”，内缩表示“这是一个被展示的对象”。同一页不要对同类元素同时使用两种待遇。
- **裁切是构图**：裁掉的部分必须暗示存在的部分。裁掉人脸的下巴要有理由；为一个细节裁掉整体，必须让读者仍能识别整体是什么。
- **安全区**：印刷的裁切位、装订的订口、投影的边框、手机的圆角与刘海，都是真实的减法。文字进裁切区不是勇敢，是没检查。
- **视觉延伸**：让元素被画面边缘切断，比完整容纳更能产生尺度和运动。但每页只留一条“出口”，多条会让视线泄漏。
- **页边不是空白**：页边距的宽窄本身就是语气。窄页边紧张、密集、商业；宽页边从容、昂贵、文学。这是关系，不是标准值。

## 七、空间的职责

留白必须承担以下之一，否则它就是内容不足：

| 职责 | 表现 |
|---|---|
| 隔离 | 两块内容之间的空白明显大于块内间距 |
| 停顿 | 在连续高密度之后留出一整块无事发生的区域 |
| 尺度参照 | 用大片空衬托一个小元素，让它显得精确或孤独 |
| 权力 | 敢浪费空间，暗示成本与从容 |
| 文字保护 | 为压在图像上的文字留出可读区 |

**留白率不是质量指标。** 高留白只有在主体尺度、位置与对照同时成立时才成立；否则只是把内容缩小。反过来，高密度也不等于专业，密度必须由分组和锚线支撑，否则是拥挤。

判断方法：如果这块空白被填上任意内容，版面会更好还是更差？更好说明留白没尽责，更差说明它在工作。

## 八、层次反差：从最省到最贵

建立层级的可用手段，按“空间成本”排序：

**面积/占幅 → 位置（阅读入口）→ 明度对比 → 尺度 → 字重 → 颜色 → 装饰/容器**

越靠前越省，越靠后越贵（占视觉噪音、损对比度、易流于装饰）。先动前面的。

这条阶梯判的是**元素之间**该在哪里花视觉重量。文字内部的层级编码（字号、字重、空间、颜色各担什么）是另一条轴，见 `03` 第四节——两者不冲突：先由本阶梯决定“这块文字该有多重”，再由字体系统决定“这个重量用什么手段实现”。

- 主张与正文之间通常用**两种**手段（如尺度 + 空间），保证在不同观看距离下都成立。
- 同级元素之间用**一种**手段（通常空间），多用会让同级读出层级。
- **一处主导反差优于五处次要反差**。全页所有元素都在强调，等于没有强调。
- 只用字号区分一切，是排印偷懒；只用颜色区分一切，在灰度、色觉差异、低质量投影下会全盘失效。

## 九、跨页与多页的构图节奏

页面角色决定空间策略。节奏不是每页变花样，而是让不同职责的页面获得不同的空间待遇。

| 页面角色 | 空间策略 |
|---|---|
| 封面／开场 | 低信息密度、大尺度、单一强入口、允许仪式性对称 |
| 目录／导航 | 结构可见、重复格式、密而不挤 |
| 论证／正文 | 稳定锚线、可预测位置、密度较高 |
| 证据／数据 | 克制容器、一个被放大的关系、可比较的重复结构 |
| 图像页 | 图像占主导，文字退为标注，与前一页形成尺度对比 |
| 转折 | 主动破坏前一页的锚线（改边距、改方向、改尺度），用一页的不规则换取注意力 |
| 收束 | 回到开场出现过的一个元素，改变它的状态（尺度、位置、明度） |

**节奏检查**：把全案缩略图排成一行看。出现“三页相似”不可怕，可怕的是相似的页面承担着不同职责。反之，如果每页都换结构，读者每页都要重新学习，注意力被消耗在适应版面上。

**转折页的使用限额**：一个短篇作品通常只需要一到两个真正的断裂。所有页都断裂，等于没有断裂。

## 十、动势

动势由斜向构图、尺度递进、重叠、裁切、方向线、主体朝向、重复间距或真实运动形成。必须先确定：**入口在哪、往哪个方向推进、被什么阻挡、最后落在哪。**

- 一个画面只能有一个主导方向。多个方向竞争会互相抵消，得到“有冲击但不知道看哪”。
- 张力来自**力量差异**，不是元素数量。所有元素都倾斜、重叠、发光，张力失去层级。
- 静态页面用视线、形态与方向关系表达动势；动态媒介还需交代动作起因、速度、重量、时序与停稳方式。
- “高级动势”不等于强制倾斜或动态模糊。轻微的偏置、一处不对称的裁切、一条不完全水平的线，往往比整体倾斜更有效。

## 十一、故障诊断：先改根因

| 可观察故障 | 可能根因 | 优先修正 | 不要先做 |
|---|---|---|---|
| 缩略图上所有元素同等重要 | 职责未分级，或反差点过多 | 重定职责与阅读顺序，只保留一处主导反差 | 全部变大、变亮、加框 |
| 主体像贴在页面中央 | 主体尺度与画幅不匹配，空间无职责 | 放大或偏置主体，让证据或第二视觉承担剩余空间 | 加装饰填空 |
| 空白很大但画面无力量 | 空间没有形成对照，主体规模不足 | 重设主体尺度或对照关系 | 填充背景纹理 |
| 页面拥挤、内容粘连 | 分组层级不明，栏宽或行长不合理 | 先重组内容与分组，再调版心 | 缩小所有文字 |
| 页面散乱、左边缘不断变化 | 缺锚线，或偏离没有目的 | 建立少量锚线，只让有意义的元素偏离 | 把所有元素强行左对齐 |
| 图像抢占文字注意力 | 对比、细节或裁切与层级冲突 | 调整裁切与位置、简化背景、保护文字区 | 给文字加底板 |
| 有冲击但没有方向 | 多种张力互相抵消 | 保留一个主导方向，删去抵消它的效果 | 继续加强效果 |
| 多页布局机械重复 | 页面角色没有变化，复用退化为复制 | 改变页面功能、焦点、尺度、密度或媒介 | 只换颜色和背景图 |
| 版面整齐但没有说服力 | 结构未由内容关系推导，只是填满了格子 | 回到“量/责/序/场”，重推结构 | 微调间距与对齐 |

## 十二、两次尺度检查

- **缩小检查**：在目标缩略图或实际观看距离下，主焦点、层级、分组与核心关系是否仍成立？
- **放大检查**：文字、边缘、裁切、材质、细节与间距是否暴露执行问题？贴边是否精确？虚线是否真的对齐？

截图里的构图通过，不代表投影、印刷、手机或视频完整播放时成立。按实际媒介与真实距离验收，不用编辑器画布代替现场。

## 十三、短案例：先修关系，再修样式

问题：一页有一项核心结论和四项证据，缩略图上五个区域同等显眼。

- **量**：结论 1 句，证据 4 条，限定 1 条，来源 1 行。
- **责**：结论（主张）、四条（证据）、限定（限定）、来源（导航）。
- **序**：结论必须先被读到；证据按强度而非按原顺序排列；限定紧跟结论，不能被推到角落。
- **场**：结论占据上部主要面积并成为唯一大尺度；四条压缩为同一列的可比较结构；限定放在结论下方紧邻处；来源压到边缘。
- **根因**：结论与证据被处理成五个并列单元，职责没有进入构图。
- **最小改动**：建立结论焦点与证据阅读序列，保留全部限定与来源，不通过整体缩小制造留白。
- **预期证据**：缩小时先读到结论；放大后证据完整可读、限定未被丢失、无新增溢出。
- **不应先做**：给五块区域分别换色、加阴影或配图标。
