# J7 · Information & Narrative — 信息设计与叙事

> 每一页是一个**论证单元**，不是一块版面。先问"这页证明什么"，再问"怎么排"。
> Content > Template：版式因内容而生，禁止把内容塞进固定模板。
> 认知效率优先于装饰——数据、关系、证据都为主张服务。

---

## 1. 信息设计（一页 = 一个论证单元）

### 1.1 So-What 纪律（信息设计的第一原则）
- 每页给**主张**，不给话题：标题写主张句（市场在向 X 收敛），不写话题词（市场概况）。
- 标题层级 = 论证链：读者只读标题应能复述完整论证（"电梯测试"）。
- 页面元素分工：眉题（语境）→ 标题（主张）→ 副标（证据预告）→ 字段/图/正文（证据）→ 来源（可信）。

### 1.2 页面功能类型（判断词汇，非模板）
| 功能 | 结构直觉 | 注意 |
|:---|:---|:---|
| **论点页** | 主张标题 + 2-4 条证据字段行 | 证据 ≤4 条，多了是两页 |
| **数据页** | 大数字 / 图表 + 口径 + 来源 | 图表直接回答主张（J5 §2） |
| **对比页** | 对齐矩阵：行=维度，列=对象，细线分隔 | 无竖线表格；高亮行/列只一处 |
| **流程/序列页** | 编号轴线（01→02→03），线连步骤 | 步骤 ≤5；用轴不用卡片链 |
| **时间线页** | 单轴 + 悬挂注记 | 节点密度均匀 = 无节奏 |
| **引用页** | 大字引文 + 署名小字 + 极大留白 | 引文 ≤2 行最佳 |

### 1.3 密度与读者姿态
- **低密度**（仪式/海报）：留白 60%+，一个重心，三个元素以内。
- **中密度**（汇报/编辑）：留白 40-55%，字段行与细线组织信息。
- **高密度**（报告/文档）：留白 25-40%，多栏+眉题+脚注是尽责不是拥挤。
- 密度与场合匹配：向董事会塞海报式留白 = 失职；向展厅塞咨询密度 = 事故。
- **留白率是版心判断的结果，不是风格目标**（J2 §0）：同一档位内，
  版心占幅仍由该页内容体量与焦点强度推出。

### 1.4 多页作品的"记忆点"
全案一个视觉母题（一根贯穿线 / 一个强调色用法 / 一处特定裁切）同构出现 ≥2 次。
**变奏规则**：每次变奏只动一个维度——尺度 / 位置 / 密度 / 强调色用法，四选一。
十页十个亮点 = 零个亮点。

## 2. 叙事（Narrative）——多页的节奏

### 2.1 主线与结构
- **一条主线**（≤20 字）贯穿全案；每页主张串起来就是主线的复述。
- 常用骨架：**问题 → 证据 → 主张 → 行动**（论证型）；**总 → 分 → 总**（报告型）；
  **序 → 渐显 → 撞击 → 余韵**（展示型）。骨架是骨，不是模子——按内容取舍章节。
- 开场页立立场，收束页回响开场（首尾同构，母题二次出现）。

### 2.2 节奏曲线（Rhythm）
- **节奏曲线**：开场立势（1 页定世界观）→ 论证展开（冷热交替）→
  视觉高潮（大数字、整页图、大主张页）→ 收束回响（首尾同构）。
- **冷热拍交替**：数据页（冷）与概念/图像页（热）交替；连续三页同质 = 读者走神。
- **起伏**：每 5-8 页安排一个视觉高潮，全案高潮 ≤2 个。
- **停顿**：章节间留白页/分隔页是呼吸，不是浪费——长文档尤其需要。
- 翻页节奏：每页停留 30-90 秒的信息量为准，超出即拆页。

## 3. 说服层次（按需，转化型作品）

信息说服的顺序：**立场（为什么关心）→ 证据（为什么信）→ 行动（现在做什么）**。
- 证据前置：可信的细节（口径、来源、样本）比形容词有效。
- 行动明确且唯一：全案一个主动作，给读者的下一步越少越好。
- 不勒索：不制造焦虑、不堆感叹号、不假稀缺——高级感来自克制的自信。

---

## 4. 全案终审（Experience Director 的验收）

四句同时成立才收工，任何一句不成立 → 回 J1 §2 对应步骤重判，不打补丁：

- **统一而不重复**——骨架与语言全案继承，构图与密度逐页变奏（变奏规则 §1.4）。
- **精致而不堆砌**——工艺集中在 ≤2 处 95 分，其余让路；无一处"因为别人都有"。
- **充实而不拥挤**——版心舒展、每块留白有归属（J2 §0.1）、密度与档位匹配。
- **克制而不单薄**——静默占 70-90%，但每页都有说清主张的分量。

（反模式归属：话题页 = §1.1 违例；卡片墙 = J2 §4；图表自嗨 = J5 §2；通则 = J6 §6。）
