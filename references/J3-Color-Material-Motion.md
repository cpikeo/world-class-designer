# J3 · Color · Material · Motion — 色彩、材质、光与动效

> 色彩不从色卡产生——**先有材质与世界观，后有色值**。动效是聚光灯，不是背景噪音。
> 所有数字是参考锚点：可偏离，须能说出为什么（J1 §3.3）。

---

## 1. 色彩推导链（唯一取色路径）

```
品牌哲学 → 文化语境 → 实体材质 → 材质色谱 → 注意力分配 → 界面落地
```

锚点示例：**Aesop** 药剂学理智 → 熏黑琥珀玻璃 + 混凝土 → 琥珀棕 `#2E2722` / 实验室灰 `#D5D7D8`；
**Muji**「空」→ 原浆纸 + 白蜡木 → 纸板白 `#F5F2EB` / 淡炭黑 `#1E1F22`。
**理由**：材质色自带真实世界的明度/饱和关系，天然协调；色卡拼贴天然冲突。

**灰度先行**：定色前先在灰阶里排层级——灰度不成立的层级，上色也救不回来；
灰度成立的层级，色彩只做两件事：**归位材质**（哪里是什么材料）与**分配注意力**（看哪里）。

## 2. 三角色面积纪律（主色/中性色/强调色的唯一模型）

| 角色 | 面积 | 职责 | 理由 |
|:---|:---|:---|:---|
| **Base 基底** | 70-95% | 低饱和中性/材质色，承载一切 | 高级感来自大面积的"静" |
| **Support 支撑** | 4-25% | 分区、层次、次级文本、线框 | 过渡带，避免基底与强调对撞 |
| **Accent 强调** | 1-8% | **全案唯一**的记忆/行动色 | 一处高饱和 = 心智定格点；两处 = 互抢 |

档位随品牌性格浮动：极简/科技近 95/4/1，暗调近 92/6/2，静奢近 75/20/5（谱系锚点见 J6 §2）。
**三种色彩职责，一色一职**：注意力色（引视线）/ 记忆色（品牌烙印，全案唯一）/ 
动作色（可交互专属）；其余一切 = 中性/材质色，高饱和绝不出现在非职责处。

- **注意力预算**：一个视口/一页只有一个最高彩度点 = 该页记忆点；非职责处高饱和 = 违规支出。
- **色阶工程**：中性色 3-4 阶成阶（不是随手灰）；同亮度梯度用感知均匀色彩空间
  （OKLCH 一类）推导，避免"看起来不一样亮"的假对齐。

## 3. 材质（Material First）

先选材料，后有色彩/光影/触感。核心材质 **≤2 种**——三种以上 = 无材质语言。
颜色必须能回答"它是什么材料"：纸的暖白、混凝土的冷灰、皮革的琥珀褐。

| 材质类 | 物理锚点（BRDF 直觉） | 情绪 · 记忆机制 |
|:---|:---|:---|
| 石 / 混凝土 | 高粗糙 0.8+、吸光、硬边影 | 肃穆恒久 · 尺度与沉默 |
| 金属（黄铜/钛/铝） | `metalness 0.9, roughness 0.15`、方向性拉丝 | 精密冷峻 · 高光轨迹 |
| 皮革 / 织物 | `roughness 0.45, clearcoat 0.6, anisotropy 0.1` | 温度手作 · 触觉回忆 |
| 纸 / 木 | 纤维、吸墨、`shadow_absorption 0.88-0.95` | 本真人文 · 老化与使用痕 |
| 玻璃 / 晶体 | `ior 1.45-1.52, roughness 0.01-0.15`；磨砂 blur 须与厚度匹配 | 纯净科技 · 透明的秩序 |

- **老化系统**：氧化、磨损、包浆——**真实的旧 > 假装的新**（奢侈品级真实感的来源）。
- **材质交互**：指针移动 → 光影微偏（非发光描边）；聚焦 → 反射微变（非 scale 弹跳）；
  深度 → Z 轴微视差（非 3D 翻转）。

## 4. 光与大气

- **五种叙事光**（选一种定基调，全案物理一致）：窗光（柔和方向性）/ 投影光（戏剧硬边）/
  街光（冷暖对撞）/ 博物馆光（顶光焦点）/ 火光（暖调低色温）。
- **光影一致性**：全案光源方向统一（左上主光为默认心智）；接触影是"真实"的第一证据；
  **禁止无光源依据的 Generic Soft Glow**（AI 味第一特征）。
- 大气参数（做空间深度时）：空气色、雾浓度、漫射率——"远处变浅变灰"是廉价渐变的合法替代。
- **色彩随叙事时间**：滚动/分幕中色彩显著变化一次即可；每视口只有一个最高彩度点 = 该视口记忆点。

## 5. 动态聚光灯（Spotlight Motion）

- **唯一运动体**：同一时刻只允许一个元素明显位移/形变；其余静止。背景装饰永不自发动画。
- 时间预算：入场 ≤500ms · 微交互 120-250ms · 场景切换 300-400ms · 黄金停顿拍 180-320ms。
- 缓动（禁用默认 `linear`/`ease`）：主动交互 `cubic-bezier(0.16,1,0.3,1)`；
  重物落位 `cubic-bezier(0.23,1,0.32,1)`；弹簧 `stiffness 70-170, damping 18-35`——
  Luxury 重阻尼无回弹，Tech 高刚度微弹一次，禁止反复弹跳。
- 性能纪律：只动 `transform`/`opacity`，永不触发布局；60fps 底线；
  `prefers-reduced-motion` 可关，关闭后信息不丢失。

---

## 6. 滚动即运镜（屏幕媒介按需）

滚动是相机运动，不是"元素飞入"：**Push In**（聚焦）/ **Pull Out**（收束）/ 
**Orbit**（仪式）/ **Tracking**（旅程）——每次运镜映射一个心理意图，禁止无理由视差；
高潮前有静默拍，匀速到底 = 无叙事。画幅比与景别见 J5 §1.3。

---

## 7. 专属反模式（通则见 J6 §6）

多强调色互抢 · 色彩与材质脱节（皮革配赛博蓝）· 全案无记忆色（"高级灰"一片）·
灰度阶段不成立的层级靠彩色硬撑 · 多元素同时动 · 动画驱动布局（CLS）·
3D/WebGL 无叙事目标（有目标时 3D 极好——先答"它讲什么"）。
