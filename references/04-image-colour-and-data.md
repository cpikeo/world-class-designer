# 图像策划、摄影指导、色彩与数据图形

本文件拥有：图片决策链、图片职责与必要性、图像编排、主体取景、光线材质、摄影与生成指令、素材真实性边界、裁切与文字避让、色彩判断、调色板构建、图像故障、动效、图表与信息图。版面关系见 `02`，品牌语义见 `05`。

## 一、图片决策链

图片不是“找一张合适的配图”，是一串有先后、每一环都可以叫停的判断。

| # | 闸门 | 要回答的问题 | 卡住时的处理 |
|---|---|---|---|
| 1 | **内容职责** | 这张图替哪一句话干活？它承担解释、证明、展示、营造还是叙事？ | 说不出就删图，把文字排好 |
| 2 | **必要性** | 没有它，理解、信任、识别或任务所需的体验是否受损？ | 不能说明服务哪个目标 → 不加；纯氛围图也须有明确体验职责 |
| 3 | **主体与关系** | 必须被认出的主体是什么？若是群像或对照，谁主导、谁从属？ | 多个主体没有主次或比较关系 → 回到第 4 步重定关系 |
| 4 | **视觉概念** | 用什么关系承载主张：尺度、方向、序列、材质、时间、对照？ | 只有形容词（“高级”“科技感”）→ 概念没成立 |
| 5 | **构图与视角** | 景别、机位高度、透视、画面重心、文字预留区 | 说不清为什么这个视角 → 换成能说清的视角 |
| 6 | **光线与材质** | 光源类型/方向/面积、接触关系、纹理尺度、磨损 | 缺接触阴影或光源无来源 → 图会“一眼假” |
| 7 | **色彩关系** | 它与版面色场是什么关系：同调、对位还是被压住？ | 与版面色冲突 → 先改裁切，不要先加罩层 |
| 8 | **裁切与避让** | 文字区在哪、最坏区域对比是否成立 | 文字无处安放 → 回到第 5 步重取景 |
| 9 | **输出检查** | 在目标尺寸与真实输出里是否仍成立 | 缩小后主体不可辨 → 重裁或换图 |

**链条可以反向使用**：拿到一张已有素材，从第 9 步倒查回第 1 步，通常能快速定位它为什么“看着不错但用不上”。

## 二、图片的职责与必要性

每张图要能回答“它在这页干什么”，说不出就删。

| 职责 | 图像要提供什么 | 常见误用 |
|---|---|---|
| 解释 | 让机制、结构、因果变得可见 | 用抽象图形替代真实机制 |
| 证明 | 这是真的：实物、现场、档案、过程 | 用生成图冒充真实记录 |
| 展示 | 它长什么样：形态、材质、细节 | 用远景代替细节，看了仍不知道是什么 |
| 营造 | 气质、时代、环境、情绪 | 氛围与语义冲突，靠风格词掩盖 |
| 叙事 | 发生了什么：动作、时刻、关系 | 静态摆拍却声称是事件 |

- 事实性表达优先真实对象、自有素材或可核验档案〔硬〕。生成图不能冒充真实产品、人物、场所或实验。
- 图库图应忠实代表实际内容；没有合适图像时，准确图解或纯排印优于无关照片。
- 区分概念示意、艺术化重建与真实记录；误认会造成影响时必须标注〔硬〕。

**拒绝填充**：为填满页面而添加的图像会稀释整页的信息权重，读者会把“有图”当成“有信息”。宁可让版面留空，或把文字排好。

## 三、图像编排

这是编排的第一决定，比拍摄风格更早。

| 编排形式 | 何时用 | 必须统一什么 |
|---|---|---|
| 单图主导 | 一张图能独立承载主张 | 给它大面积；文字退让为标注，不与图争 |
| 多图序列 | 需要展示变化、多样、过程、并可比较 | 光向、色温、景别、视角高度、镜头族、背景处理——**任一不统一，读者读成拼贴而不是序列** |
| 网格／档案式 | 需要目录感、档案感、可比性 | 裁切比例、主体位置、留白量完全一致，差异只留在内容本身 |
| 图文互文 | 图与文各自说不同但互补的部分 | 文字位置可预测，图像让出可读区 |

**连续性的两个正当例外**〔验〕：制造转折，或强调差异。除此之外的不一致都是失误。

**序列必须看接触表。** 单张好看不等于一组成立。把候选图缩成小图排成一行（或用缩略图墙）再看：阴影方向是否一致、色温是否跳、景别是否忽远忽近、主体是否在同一相对位置、背景明度是否有节奏。在单张大图上永远发现不了这些问题。

**图像与正文的分工**：图呈现形态、变化、现场；文解释原因、限制、推论。两者说同一件事是浪费版面。如果图已经说清楚了，文字就该说别的。

## 四、主体与取景

**主体占幅由职责决定**：证明型要看清细节（近、大）；营造型要看清关系（远、含环境）；标识型要看清轮廓（中、完整）。不要为了“大气”缩小主体，也不要为了“冲击”放大到信息消失。

- **景别是承诺**：承诺了“看得清”，就要给到能辨认结构、部件、工艺细节的程度；承诺了“看得见关系”，就必须包含足够的环境信息。
- **机位高度**决定权力关系与空间判断：平视中性、仰视抬高主体、俯视展示秩序与全貌、鸟瞰交出平面关系。选机位不是选角度，是选谁在被观看。
- **透视**是信息工具：广角近拍拉伸空间、强化纵深；长焦压缩、把前后景拉近、削弱深度；微距显示纹理与材质尺度。透视失真是取舍，不是错误——但要能说出它服务什么。
- **画面重心**与文字区争夺同一块地。若图的重心落在将放文字的位置，两者会打架：先移重心（改取景或裁切），再考虑压暗。
- **尺度需要参照**：没有参照物的大，读者读不出大。人手、门框、工具、硬币、熟悉的建筑构件都是尺度锚点。

## 五、光线、材质与接触

机位、透视与景深应服务形体与叙事。光线必须保持空间逻辑〔硬〕：主光方向、形体塑造、阴影、环境反射、背景衰减，四者一致。

材质可信度取决于：反射、粗糙度、透明度、厚度、纹理尺度、磨损、重量、**接触关系**。接触关系最容易被忽略，也最能暴露假——物体与地面的接触阴影、边缘的贴合、堆积的重力方向、相邻表面的相互投影。

柔光呈现形体与细节；硬光强调结构；掠射光显示肌理；逆光分离轮廓或呈现半透明。**选择光线，等于选择这一页要让读者看见什么。**

雾、泛光、眩光、粒子、光斑需要有光源、材质或叙事依据。“8K、超写实、电影级”不能替代具体判断。

## 六、摄影与生成指令

先定义主导视觉关系，只写会实质影响画面的信息。字段可选，不必填满。

1. **目标与语义**：主体必须准确表达什么。
2. **主体与关系**：身份、关键结构、动作、尺度、与环境的关系。
3. **构图与空间**：占幅、重心、视角、透视、裁切、前中后景、视线方向、必要的文字预留。
4. **摄影语言**：只指定改变结果的视点、距离、透视、景深、曝光或运动模糊；不堆器材名。
5. **光线与材质**：见「物理条件」。
6. **色彩与环境**：色彩职责、背景复杂度、环境反射、整体色调。
7. **关键排除项**：只写当前真实风险——结构错误、伪文字、错误部件、水印、无关道具。

**用物理条件替代形容词。** “电影感”“高级感”“氛围感”不可执行；可执行的是：

- **光源**：类型（窗光/单灯/顶光/逆光/实用光源）、方向（几点钟方向、高度）、相对面积（决定软硬）、距离。
- **时间与天气**：决定色温与对比的物理来源。
- **镜头与景别**：广角近拍（透视夸张、空间拉伸）、长焦（压缩、背景拉近）、微距（质感与纹理）；全篇景别线是否统一。
- **材质与磨损**：新旧、使用痕迹、表面处理、厚度与重量感。
- **空间关系**：主体与背景的距离、背景是否失焦、是否有第二层可读信息。
- **色彩条件**：环境色、反射色、白平衡倾向。

**“一眼假”信号**（生成图的默认失败模式）：完美对称、毫无磨损、缺接触阴影、光源方向不一致、背景过于干净、材质没有尺度参照、所有物体同一景深、光线没有来源、纹理重复可辨。

准确文字、标签、数字与图表优先在生成后用排版工具添加。提示词不能保证正确；未看到实际输出时，只能评价提示词或方案。

## 七、真实摄影、生成图与档案的边界

三者的可宣称范围不同，混用会造成信任损伤〔硬〕：

| 来源 | 可以宣称 | 不可以宣称 | 必须标注的情形 |
|---|---|---|---|
| 真实摄影 | 这是被拍摄对象在某一时刻的样子 | — | 后期合成、拼接、删除元素改变了事实 |
| 生成图 | 这是一种视觉构想 | 这是产品、人物、场所、实验的真实记录 | 会被误认为真实记录时；用于产品说明时 |
| 档案素材 | 这是当时留下的材料 | 这是当前状态 | 年代、出处、裁切改动会影响理解时 |
| 概念重建 | 这是基于事实的合理还原 | 这是实测结果 | 与真实比例的偏差会影响判断时 |

艺术化处理可以服务表达，但不能改变事实的读法。一张“示意”被当成“证据”，比一张难看的图危害更大。

## 八、裁切与文字避让

- **先定文字区，再定裁切**。不要先裁好图再把文字塞进空隙——那是把排版交给运气。
- 裁切优先于缩放：换一个更紧的取景往往比缩小整张图更有效。
- **文字压图时，检查图像最亮与最暗区域上的实际对比**，不是平均对比。文字若跨过亮暗交界，两处都要过。取样方法见 `07`「证据口径」——按元素实际框落位、合成保护层、只取文字真正占据的区域。
- 裁切不得切断语义单位：人脸的下半、产品型号、关键结构、方向性动作的落点。
- 出血裁切要考虑印刷裁切位与装订订口；屏幕要考虑圆角、刘海、状态栏。

## 九、色彩判断

色彩不是配色方案，是**分配注意力与意义**。

**先明度，后色相。** 人眼对明度的敏感度远高于色相，且明度在灰度打印、色觉差异、低质量投影下都保留。先决定“场面上最亮与最暗分别是谁”，再决定用什么颜色。

**灰度验证**〔硬〕：把稿件完全去饱和，看重音是否还在。层级若在去色后全部塌掉，说明它只靠色相承载——换到灰度打印、单色投影或色觉差异读者那里会失效。

更要紧的一种失效是**方向反转**：当强调色比正文更浅时，去饱和后它会从“突出”变成“退隐”。实测例：绢本底 `#F2EFE6`、正文 `#1F2126`（对比 14.0:1）、强调色 `#6B8A85`（3.3:1）——灰度下强调色成为整行最浅的字，读者读成“被淡化”，与意图相反。彩色强调只能承担大字号，且必须同时有字重、位置或尺度上的第二种手段兜底。

**色相关系的三种张力**：

| 关系 | 效果 | 风险 |
|---|---|---|
| 邻近（同类/邻近色） | 秩序、克制、专业、统一 | 缺焦点；必须靠明度或面积制造层级 |
| 对照（互补/分裂互补） | 张力、注意、活力 | 高饱和纯互补极易廉价；需降低一方饱和度或面积 |
| 冲突（三色以上、跨色温） | 多元、拼贴、当代 | 只有内容本身是冲突的才成立，否则读成没有判断 |

**冷暖与重量**：暖色前进、冷色后退；同明度下暖色显得更近、更重。这一点直接决定“谁是主体”。

**饱和度是权力分配**：高饱和应当属于页面上最重要的那一小块面积。大面积高饱和会压过文字，也会在小屏与投影上刺眼。降低饱和度是让颜色退位的手段，不是“变高级”的手段。

**面积决定语气**：同一个红，极小面积是标点，中等面积是强调，大面积是宣言。**先决定面积，再决定选哪个色**——顺序反了，就会得到“选了很对的颜色但用错了量”。

**反对默认“高级”**：米白 + 灰 + 金、纯黑 + 白 + 一个霓虹、全套莫兰迪，都是没有判断时的默认值。判据不是审美，是来源——这个颜色是否来自内容（材料的本色、产地的光、品牌的既有资产、图像本身的主色）？如果不是，要能为它说出一个非审美的理由，否则换掉。

## 十、调色板的构建

不做“几种颜色”的规定，做**职责分配**：

| 职责 | 作用 | 约束 |
|---|---|---|
| 场（field） | 大面积背景或图像基调，决定气质 | 要让文字成立；换掉它会改变整页语气 |
| 字（ink） | 文字色 | 必须满足对比；深浅层级通常不超过两级 |
| 声（voice） | 强调色，只出现在焦点与关键数据 | 面积小、次数少；不承载长文本 |
| 信（signal） | 状态与编码色（涨跌、警示、分类、选中） | 需与“声”区分，不能混用；不能只靠颜色编码 |

**两个测试**：

1. **去掉“声”**：版面是否还有层级？如果立刻垮掉，说明所有层级都压在一个颜色上，是脆弱的。
2. **换掉“场”**：作品是否还成立？完全成立说明颜色没有承担语义，只是皮肤；立刻垮掉说明颜色与内容真正绑定——这是好事，但要能解释绑定的理由。

**色彩与图像协调**：图像与版面色冲突时，处理顺序是 **改裁切（去掉冲突色块）→ 整体调色（统一色温与黑位）→ 最后才用叠加/遮罩**。用大面积色彩叠加去“统一”，通常会把图像的材质一起毁掉。

**对比的实际检查**：背景是纯色时查色板；背景是图像时，必须检查文字真正占据的最坏区域，而不是色板。必要信息不能只靠颜色表达，并需考虑色觉差异与输出设备。

**媒介适配**：屏幕发光、高饱和更刺眼、暗底细字会晕；印刷吸光、深色更沉、纸张白度影响所有颜色、专色与四色有差异；投影对比低、环境光干扰、色域窄。同一套色不能照搬，需按媒介重新校准。

## 十一、图像故障：按缺陷范围修复

| 可观察问题 | 先检查 | 优先处理 | 何时考虑重生成 |
|---|---|---|---|
| 主体太小或缺乏力量 | 占幅、观看距离、拍摄距离 | 裁切、重取景或放大主体 | 放大后细节/透视无法补救 |
| 主体轮廓混入背景 | 明度、纹理、颜色、边缘竞争 | 简化背景、调整局部明度、轮廓分离 | 分离主体会破坏整体光照 |
| 重心分散 | 多个高对比点、道具、视线竞争 | 删除或弱化次要元素，调整裁切 | 原构图无法建立焦点 |
| 光向与阴影冲突 | 主光、环境反射、接触阴影 | 修正局部高光、阴影或色调 | 整体空间光照根本错误 |
| 材质像塑料或贴图 | 粗糙度、反射、厚度、纹理尺度、接触 | 局部调整材质与接触关系 | 核心材质或形体不可修复 |
| 文字乱码、重复结构、多余部件 | 错误范围及对主体的影响 | 裁切、后期排版、局部修复 | 错误损害主体辨识或整幅构图 |
| 图像与版面色彩打架 | 冲突色块位置、色温、黑位 | 先改裁切，再整体调色 | 图像气质与页面语义根本不符 |
| 单张都好，一组不像一套 | 光向、色温、景别、视角、背景 | 按接触表重排或重挑 | 素材来源本身不兼容 |

先判断缺陷位于局部、构图还是主体/场景层。局部问题不整图重做；主体、透视或主光根本错误时，不持续叠补丁。修后还需检查修复是否引入边缘、比例或光照的新问题。

## 十二、动效

仅在解释机制、显示因果或顺序、引导注意、反馈状态、推进叙事时使用。先确定动作的**起因、方向、速度、重量、时序、停止状态与注意力落点**，再选择缓动、路径、镜头运动或转场。

避免多个主焦点同步运动、无意义循环、所有镜头使用相同进入方式。**关闭动效或观看静帧时，关键信息仍应可理解**——这是判断动效是否成为依赖的唯一标准。

动效的取舍原则：动作要有物理依据（质量、受力、惯性），否则读者感到“飘”。缓慢不等于高级，快也不等于有力；速度应与实际体量匹配。

## 十三、图表与信息图

按顺序执行：**明确问题 → 核验数据与口径 → 选择编码 → 保留比较条件 → 标注来源与限制 → 在目标尺寸检查。**

| 要回答的问题 | 优先考虑 |
|---|---|
| 类别大小、排名或精确比较 | 位置/长度、条形图或表格 |
| 随时间变化 | 折线或合适的时间序列 |
| 两个变量关系 | 散点图 |
| 分布、离群与集中 | 分布图 |
| 精确查值与多属性核对 | 表格 |
| 构成与占比（单一总量） | 堆叠条或饼；类别多且差异小时改表格或条形 |

**不可删的比较条件**在图表里具体化为：单位、期间、基线、样本、口径、不确定性。它们与内容层的判据同源（见 `01`「内容价值判断」）；一旦丢失，图就从证据变成插图。

条形图通常从零基线开始；偏离需说明，非线性尺度需标示。不得用裁切、面积、排序、颜色或隐藏反例夸大结果；示例/估计数据必须标注。

**图表是版面元素，不是插图。** 尺寸、位置、图注、标题必须与正文建立关系：图表标题说结论，图注说口径，正文说推论。三者重复同一句话，是浪费。

**小幅度量的陷阱**：当数值变化幅度很小（如 34% → 38%），0 基线图表会把变化压平到看不出。此时不要改基线去夸大，而应换一个在该基线成立、且能说明同一结论的量（如绝对额、同比增量），或改用表格与直接标注。

双序列与多序列检查单位是否可比、图例是否必要、颜色之外是否还有区分手段（线型、标记、直接标注）。图标只用于识别动作、类别与状态；含义不明显时配文字，关键含义不只靠图标或颜色传达。
