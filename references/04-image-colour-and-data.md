# 图像、摄影、色彩、材质、光线、动效与数据图形

## 一、先明确视觉素材的职责

先决定图像要解释、证明、展示、营造还是叙事，再选择素材与风格。

- 事实性表达优先真实对象、自有素材或可核验档案。生成图不能冒充真实产品、人物、场所或实验。
- 图库图必须忠实代表实际内容；没有合适图像时，准确图解或排印优于无关照片。
- 区分概念示意、艺术化重建和真实记录，并在误认会造成影响时明确标注。
- 气氛与语义冲突时，先重判概念和素材，不要堆加风格词。

## 二、图像指导与生成提示词

先定义主导视觉关系，只写会实质影响画面的提示信息：

1. **目标与语义**：主体必须准确表达什么。
2. **主体与关系**：身份、关键结构、动作、尺度及环境关系。
3. **构图与空间**：占幅、重心、视角、透视、裁切、前中后景、视线方向及必要的文字预留。
4. **摄影或渲染语言**：只指定会改变结果的视点、距离、透视、景深、曝光或运动模糊，不堆砌器材名。
5. **光线与材质**：主光方向、光源大小、软硬、反射、接触阴影、粗糙度、透明度、厚度与纹理尺度。
6. **色彩与环境**：色彩职责、背景复杂度、环境反射和整体色调。
7. **关键排除项**：只写当前真实风险，如结构错误、伪文字、错误部件、水印或无关道具。

字段可选，不必填满。需要比较方向时，让样本在构图、视角或主体关系上产生真实差异，而不是只替换“高级、极致、电影感”等形容词。

准确文字、标签、数字与图表优先在生成后用排版工具添加。提示词不能保证正确；未看到实际输出时，只能评价提示词或方案。

## 三、摄影与材质可信度

机位、透视和景深应服务形体与叙事。光线需保持空间逻辑：主光方向、形体塑造、阴影、环境反射和背景衰减一致。

材质可信度取决于反射、粗糙度、透明度、厚度、纹理尺度、磨损、重量与接触关系。柔光呈现形体与细节；硬光强调结构；掠射光显示肌理；逆光分离轮廓或呈现半透明。

雾、泛光、炫光、粒子和光斑必须有光源、材质或叙事依据。“8K、超写实、电影级”不能替代具体判断。

## 四、图像故障：按缺陷范围修复

| 可观察问题 | 先检查 | 优先处理 | 何时考虑重生成 |
|---|---|---|---|
| 主体太小或缺乏力量 | 占幅、观看距离、拍摄距离 | 裁切、重取景或放大主体 | 放大后细节/透视无法补救 |
| 主体轮廓混入背景 | 明度、纹理、颜色和边缘竞争 | 简化背景、调整局部明度或轮廓分离 | 分离主体会破坏整体光照 |
| 重心分散 | 多个高对比点、道具和视线竞争 | 删除或弱化次要元素，调整裁切 | 原构图无法建立焦点 |
| 光向与阴影冲突 | 主光、环境反射、接触阴影 | 修正局部高光、阴影或色调 | 整体空间光照根本错误 |
| 材质像塑料或贴图 | 粗糙度、反射、厚度、纹理尺度和接触 | 局部调整材质与接触关系 | 核心材质或形体不可修复 |
| 文字乱码、重复结构、多余部件 | 错误范围及对主体的影响 | 裁切、后期排版、局部修复 | 错误损害主体辨识或整幅构图 |

先判断缺陷位于局部、构图还是主体/场景层。局部问题不整图重做；主体、透视或主光根本错误时，不持续叠补丁。修后还需检查修复是否引入边缘、比例或光照新问题。

## 五、色彩职责

先规定颜色承担什么工作：识别、焦点、信息编码、分组、状态、情绪、空间层次或图像协调，再决定背景/文字关系、强调色和图像干扰。

检查明度、饱和度、面积和局部对比。小面积高对比色可能夺走焦点；配色好看不代表层级正确。必要信息不能只靠颜色表达，并需考虑对比度、色觉差异和输出设备。

在文字、控件或数据承载信息时，按适用标准检查实际前景与背景对比；背景为图像时检查文字真正占据的最坏区域，而不是只检查色板。

## 六、动效

仅在解释机制、显示因果/顺序、引导注意、反馈状态或推进叙事时使用。先确定动作起因、方向、速度、重量、时序、停止状态和注意力落点，再选择缓动、路径、镜头运动或转场。

避免多个主焦点同步运动、无意义循环和所有镜头使用相同进入方式。关闭动效或观看静帧时，关键信息仍应可理解。

## 七、图表与信息图

按顺序执行：**明确问题 → 核验数据与口径 → 选择编码 → 保留比较条件 → 标注来源与限制 → 在目标尺寸检查。**

| 要回答的问题 | 优先考虑 |
|---|---|
| 类别大小、排名或精确比较 | 位置/长度、条形图或表格 |
| 随时间变化 | 折线或合适的时间序列 |
| 两个变量关系 | 散点图 |
| 分布、离群与集中 | 分布图 |
| 精确查值与多属性核对 | 表格 |

保留影响结论的单位、期间、基线、样本、口径、限制和不确定性。条形图通常从零基线开始；偏离需说明，非线性尺度需标示。不得用裁切、面积、排序、颜色或隐藏反例夸大结果；示例/估计数据必须标注。

双序列与多序列检查单位是否可比、图例是否必要、颜色之外是否还有区分。图标只用于识别动作、类别和状态；含义不明显时配文字，关键含义不只靠图标或颜色传达。
