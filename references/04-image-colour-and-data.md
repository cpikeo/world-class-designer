# 图像、色彩、材质、光线、动效与数据图形

## 图像首先要承担职责

先判断图像属于证据、产品/工艺、氛围、人物关系、概念象征或技术解释。项目自有素材和真实对象通常优先；生成图可用于真实素材无法满足的创意需求；档案/图库图只能诚实地代表其实际内容，不能伪装成客户的产品、团队或场所。没有合适图片时，可以用准确的图解、剖面或有意的排印构图，不要用无关图库图填版。

## 图像生成提示词的决策顺序

1. **语义真实性**：主体身份、必要结构、动作和证据含义。
2. **必要信息**：必须读懂的部件、标签或操作/安全信息。
3. **主体与构图**：主体占幅、视角、透视、空间层次、裁切与视线方向。
4. **物理可信度**：尺度、结构、重力、接触、材质响应与光照逻辑。
5. **摄影/渲染语言**：焦距感、曝光、景深、色调、材质细节和背景。
6. **排除项**：只写当前任务真实风险，如结构错误、伪文字、水印、无关道具、杂乱边缘。

默认按“目的与语义 → 主体与关系 → 场景/空间 → 视角与构图 → 光线 → 材质 → 色彩 → 影像特征 → 关键排除项”组织提示词。只填写会影响结果的字段，不为完整而填满。提示词应说明哪一个关系最重要，以及其它元素怎样支持它。

准确文字、数字、标签和图表优先在生成后用排版工具添加；除非任务确实要求模型在画面中生成文字且输出能被验证，不要依赖图像模型绘制精确文字。

## 图像故障诊断

| 可观察故障 | 可能根因 | 第一选择 | 升级为重生成的条件 |
|---|---|---|---|
| 主体太小、失去力量 | 主体占幅/拍摄距离不对 | 裁切、重新取景或放大主体 | 放大后透视/细节不足，且原图无法补救 |
| 主体轮廓混入背景 | 明度、颜色、纹理或边缘方向竞争 | 移动主体、简化背景、调整局部明度或轮廓光 | 分离主体会破坏可信光照或场景结构 |
| 画面有主体但重心散乱 | 多个高对比区域、道具或视线相互竞争 | 删除/压低次要元素，调整裁切或主体位置 | 原构图无法形成清晰焦点 |
| 光线像从多个互不相容的方向来 | 主光方向、阴影和反射不一致 | 局部修光、压低冲突高光、统一色调 | 主光和整体空间从根本上错误 |
| 材质像塑料或贴图 | 粗糙度、反射、厚度、纹理尺度或接触关系不符 | 先修局部材质/反射/接触阴影；减少过度锐化 | 核心材质特征不可修复，或主体形态也错误 |
| 文字乱码、结构重复或多余部件 | 生成模型不擅长精确文字/复杂结构 | 裁掉伪文字区域，使用真实排版覆盖；可独立修复时做局部修补 | 错误影响主体辨识或大部分构图 |
| 风格不错但与任务不符 | 语义、素材或视觉概念选择错误 | 换素材/重判概念，而不是加更多形容词 | 方向本身不支持主张 |

每次修图先确定缺陷范围。构图错用重构/裁切；局部伪影用局部修复；主体、透视或主光根本错误才考虑整图重生成。若无法实际查看输出，应明确说明未验证。

## 色彩

色彩可承担品牌识别、信息编码、焦点、情绪、结构、状态或空间关系。确定主导色、文字色、背景关系和强调色的职责，再检查明度、饱和度、面积比例、局部对比、图像色调与无障碍需求。小面积高对比色可能成为意外焦点；必要信息不得只靠颜色编码。灰度检查是辅助工具，不是所有任务的强制步骤。

## 材质与光线

材质可信度取决于反射、粗糙度、透明度、厚度、纹理尺度、磨损、重量和物理行为。光线要明确主要来源、方向、大小、软硬、环境反射、接触阴影、反差和背景衰减。同一场景应保持一致，除非冲突本身承担叙事作用。

柔光可呈现形体和细节；方向硬光可强调结构；掠射光可显示肌理；逆光可分离轮廓或揭示半透明。泛光、炫光、雾、粒子、镜头光斑等不能默认添加，必须有光源、材质或叙事依据。“8K、超写实、电影感”不能替代具体光线和材质决策。

## 动效

仅在解释机制、揭示顺序、引导注意、反馈状态或推进叙事时使用。明确起因、方向、速度、重量、时序、停稳方式和注意力落点。避免多个主焦点同步运动、无意义循环和一律相同的入场动画。核心内容必须在动效失败或用户减少动态效果时仍可理解。

## 图表

先确定需要回答的问题，再选择编码：精确比较优先位置/长度；时间变化可用折线；分布使用适当分布图；精确查值使用表格；变量关系使用散点等。量值条形图通常从零基线开始；有理由偏离时须明确标示。非线性刻度必须标明。保留会改变结论的单位、期间、基线、样本量、口径、限制和不确定性；不能通过视觉缩放、裁切或隐藏反例制造误导。

图标只用于识别动作、类别和状态；统一视觉重量与光学对齐。含义不明显时配文字，关键信息不能只靠图标表达。
