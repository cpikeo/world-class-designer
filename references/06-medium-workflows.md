# 跨媒介工作流与交付契约

先确认实际交付物，再选择媒介重点与验收方式。本文件定义最低交付边界，不要求所有任务都走完整流程。

## 通用交付契约

明确交付物、使用环境、关键约束、主要风险与实际检查范围。按需交付源文件、成品、预览、脚本或提示词；不要把计划或静态示意稿称为最终成品。

## 演示文稿 / PPT

**重点判断**：整体主张与页面角色、投影距离、页面节奏、证据层级、中文排印、图像裁切、数据口径及页面之间的一致与变化。

**最低验证**：按目标画幅渲染完整文稿；查看全稿缩略图、首屏、关键转折/高潮、高密度页、结尾和异常页。检查字体替换、溢出、遮挡、图表口径、脚注、页码与跨页节奏。只看单页或编辑画布不能证明整套演示可用。无法渲染时，明确标记未验证。

## 长文档 / 报告 / PDF

**重点判断**：连续阅读、层级导航、行长、段落节奏、脚注、表格跨页、目录/附录关系、分页孤行与页眉页脚。

**最低验证**：导出目标格式后，检查实际分页、目录/页码、表格断裂、字符编码、字体替换、打印边距和阅读连续性。无法检查字体嵌入或最终导出时，不声称通过对应检查。

## 网页 / 产品界面

**重点判断**：内容顺序、页面与应用界面的区别、导航/行动入口、真实断点、空/加载/错误/焦点/禁用状态，以及键盘访问和可访问性。

**最低验证**：在目标浏览器检查桌面、窄屏及必要的中间宽度；检查实际文字长度、水平溢出、遮挡、交互路径、焦点状态、图片加载和错误状态。静态 mockup 不能证明交互、响应式行为或性能已经可用。

## 海报 / 封面 / 展陈

**重点判断**：观看距离、停留时间、环境光、观看方向、主焦点、标题层级、图像占幅和最终裁切。

**最低验证**：按最终尺寸或对应观看距离检查；同时确认缩略图识别和近距离细节。适用时检查出血、裁切、安全区、分辨率、色彩模式和链接资源。

## 图像 / 摄影 / 3D 概念图

**重点判断**：主体语义、关键结构、主导视觉关系、视角和透视、光照逻辑、材质可信度、背景竞争与画面裁切。

**最低验证**：观察实际输出中的主体识别、比例/结构、透视、接触关系、光向、反射、材质、边缘伪影、文字伪影和目标尺寸表现。只给出提示词而没有生成图时，交付范围是“图像指导/生成提示词”，不是成品图质量承诺。

## 视频 / 动态视觉

**重点判断**：镜头叙事职责、景别与视角、动作起因、方向/速度/重量、主体连续性、视觉节奏、音画关系和字幕安全区。

**最低验证**：按实际帧率完整播放或检查时间线；观察镜头进入/离开、动作连续性、主体位置、闪烁/跳变、字幕可读性、音画同步和音量变化。只看关键帧不能证明运动连续性或声音质量。

## 数据图表 / 信息图

**重点判断**：问题和数据关系、合适的视觉编码、标签可读性、单位/基线/期间/样本和不确定性。

**最低验证**：复算关键值；核对标签、排序、单位、总和、基线和样本范围；缩至目标尺寸检查图例与注释。未提供或未核验的数据必须明确标记为示例或假设。

## 跨媒介项目

先保持同一主张、视觉概念和品牌语义，再让每种媒介使用最适合自己的表达手段。不要将一张海报机械拆成 PPT 页面，或将静态画面简单平移成视频。媒介之间共享的是设计逻辑，不是相同版式。
