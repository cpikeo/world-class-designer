# 媒介版面判断、交付契约与验收

本文件拥有：交付状态用语、各媒介的版面重点与不可省证据、跨媒介转译、最容易假通过的地方。修订协议与验证分级见 `07`，版面结构原理见 `02`。

先确认实际交付物，再选择媒介重点与验收方式。本文件定义最低边界，不要求所有任务都走完整流程。

## 一、通用交付契约

明确**交付物、使用环境、关键约束、主要风险与实际检查范围**。按需交付源文件、成品、预览、脚本或提示词；不把计划或静态示意稿称为最终成品。

状态用语（全包唯一出处，其他文件只引用、不重复定义）：

| 状态 | 含义 |
|---|---|
| **方案** | 已有方向、结构或执行计划，尚未形成目标媒介成品 |
| **提示词** | 只形成生成/生产指令；只能评价指令，不能评价其未来输出 |
| **未验证** | 已有方案或产物，但尚未执行能支持当前结论的必要检查 |
| **预览** | 已生成用于查看的非最终或有限保真结果，不等于目标环境通过 |
| **部分检查** | 已查看真实结果，但只覆盖明确列出的页面、状态、尺寸、环境或镜头 |
| **已检查** | 已在声明的环境、方法与范围内查看真实结果；范围之外不作推断 |
| **可交付** | 必要内容完整，交付所需硬门槛已在适用范围内处理，剩余风险与未检查项已披露 |

状态必须带对象、环境、范围和时间〔硬〕；“预览”与“部分检查”可组合使用。无范围的“已检查”不算证据，“可交付”也不等于所有环境均已测试。

生产成功后按 **真实产物 → 目标环境与尺寸 → 关键异常范围 → 必要修正 → 复查受影响部分** 推进。工具生成文件不等于完成验收。

### 整页与序列检查

单区块、单屏、单页检查只能证明局部。任何超过一屏、一页或一跨页的交付物，验收必须包含**整体视图**——它不是额外步骤，是这类交付物的必要证据。

| 视图 | 怎么做 | 能发现什么 | 不能替代 |
|---|---|---|---|
| **整页长截图**（网页）/ **全稿缩略图**（PPT、视频） | 按目标宽度滚完整页截取，或把全部页面缩成一屏 | 背景场断裂、独立色块、模块化容器、边界逻辑突变、误读为另一页 | 交互状态、真实滚动、字体加载 |
| **缩略图带 / 接触表** | 全部页面按顺序排成一行或一面 | 密度与尺度节奏、强调色出现频率、跨页继承 | 单页执行细节 |
| **去文字视图** | 模糊或缩到文字不可读 | 色块、边界、主体、尺度、空间是否仍像一个作品 | 语义与层级是否正确 |
| **相邻对照** | 只并排看相邻两页/两屏 | 继承项与变化点 | 全篇节奏 |

四项视图之后，按此顺序判断七件事：

1. 是否突然出现不属于当前视觉系统的色块？
2. 是否有内容块的边界与结构明显脱离全页？
3. 相邻区域是否像两个不同网站／两份不同文稿拼接？
4. 是否出现重复的卡片化、容器化处理，把不同职责的内容装进同一个壳？
5. 主要视觉关系（锚线、背景场、图文比例、字体角色）在滚动或翻页过程中是否保持可预测？
6. 品牌视觉母题是否被延续并改变状态，还是被原样复制，或彻底消失？
7. 全篇是否有可感的节奏、停顿与转折——还是从头到尾同一个密度？

发现问题，先回内容关系与结构层（`02`「页面连续性与视觉继承」），不先改圆角、阴影与颜色；归因与修正序见 `07`「整体视觉一致性诊断」。

**整体视图是必要证据，不是充分证据。** 它不能替代单页 100% 的排印、对比、裁切与状态检查；反过来，单页全部通过也不能推出整页成立。

## 二、杂志与出版物

**版面重点**：跨页构图见 `02`「跨页构图」。印刷语境下，订口与切口的可用空间由装订方式、页数、纸张与爬移决定，不能把内侧一律当成可牺牲区。栏系统由真实正文、图版、注释与目录任务共同决定；单栏、双栏或多栏都可承载长文，关键是实际行长、灰度、图版尺度和跨页节奏。

**图纸关系**：图注与图绑定，目录、页码与章节结构对应；图版越界或改变版心应有内容职责，并在全篇节奏中可读，不用机械“下一页补回来”的公式。

**交付物**：按用途提供包装完整的源文件与链接资源、符合印刷约定的 PDF、必要的低分辨率审阅稿、字体/图像许可与输出说明；印刷生产还需确认纸张、装订、色彩与打样责任。

**不可省证据**：按最终开本拼成跨页检查订口、爬移、出血、裁切、奇偶页、图注与连续阅读；把整册按顺序排成缩略图带，检查跨页之间的背景场、版心与图版尺度是否继承、章节切换是否有依据；印前检查字体嵌入、图像有效分辨率、透明、叠印、色彩模式与总墨量。正式印刷色彩和最细字画的认可需要相应数码样或上机样，屏幕预览不能替代。

**最容易假通过**：只看单页；把阅读 PDF 当作印刷生产 PDF；用屏幕软打样宣称纸张、油墨与装订效果已通过。

## 三、演示文稿 / PPT

**版面重点**：每页先明确一个主要职责——提出主张、呈现证据、比较数据、解释机制、转折、决策或停顿。职责内可有多个信息单元；比较页、目录页与工作坊页不必被压成“一句话一页”。焦点、关键标注与最低文字层级必须在目标观看距离成立，编辑器 100% 缩放不代表后排效果。

**全稿节奏**：区分关键页与连续支撑页，检查信息增量、论证依赖、密度变化和演讲者提示。停顿页只有在重定向或恢复注意时有价值；高密度页若用于现场讲解，可逐步揭示，但导出静态版仍需独立可读。

**交付物**：可编辑源文件、目标画幅的播放/导出成品、必要字体与媒体资源、演讲者备注或阅读版 PDF；说明现场播放、在线共享或独立阅读哪一种是用途。

**不可省证据**：在目标播放环境渲染完整文稿；查看全稿缩略图及开场、关键转折、高密度、数据、结尾和异常页；缩略图除节奏外还看跨页继承——同一章节内的背景场、锚线、字体角色与图文比例是否连续，新章节的切换是否有依据（见「整页与序列检查」）。检查字体替换、真实长文案、溢出遮挡、图表口径、媒体播放、动画后状态、页码和导出差异；关键页按实际投影设备、屏幕尺寸与观看距离检查，不能用等效缩小宣称现场已测。

**最容易假通过**：只看单页或编辑画布；只在本机检查；把静态 PDF 通过当作动画、视频和现场投影通过。

## 四、海报 / 封面 / 展陈

**版面重点**：先建立观看场景：最远需要识别什么、中距离理解什么、近距离核验什么。观看距离、方向、环境光、遮挡、停留时间与是否移动中共同决定主体占幅、标题形态和信息层级。中远距离通常先读到轮廓与少量关键词，但展览封面、阅读型海报可承载更多连续信息，不设统一字数。

**主体与标题**：主体轮廓、标题与必要行动信息应在各自距离可辨；二维码、日期、地点、票务或展签必须能在实际接近距离使用，不为远距冲击删掉必要信息。

**交付物**：最终尺寸成品、印刷/屏幕输出文件、必要源文件与链接资源、裁切和安装说明；多尺寸投放分别提供适配版本，而非一张图任意拉伸。

**不可省证据**：按最终尺寸或可信的等比例样张，在实际或模拟观看距离检查远、中、近层级；检查出血、裁切、安全区、有效分辨率、色彩模式、字体处理与链接资源。屏幕模拟距离只能支持层级判断，不能证明印刷清晰度、材料与现场光已验收。

**最容易假通过**：只在屏幕上缩小看“冲击力”；忽略最终输出锐度、安装高度、观看角度、环境光与近距必要信息。

## 五、网页 / 产品界面

**版面重点**：先区分品牌/内容阅读与产品任务。营销首屏需要让受众理解价值与下一步，但文档、搜索、仪表盘和工具首页可以从导航、数据或当前任务开始，不套“一个承诺加一个按钮”。内容页看连续阅读与定位，任务界面看目标可达、状态可见、反馈明确；混合产品分别标出两类区域。

### 信息架构与交互层级

信息架构同时处理**内容层级**（知道什么、谁包含谁）与**任务层级**（完成什么、步骤如何串）。二者可以不同构，用上下文链接、跨区入口或任务流连接，不硬塞成一棵树。

- 全局、局部与上下文导航按产品需要设置；位置、当前项、返回路径与下一步可辨，不预设必须三层。
- 深度与广度由任务频率、入口命名、用户心智模型和检索方式决定；高频入口通常更浅，但搜索型与专家型产品不应机械套用。
- 一个视图可有多个任务，关键是当前主任务、次任务和并行信息有清楚层级。并行任务可分区或分步；dashboard 的比较关系不应为“单一任务”被拆散。
- 可点、不可点、当前所在、焦点、下一步与结果不能仅靠文案解释；交互 affordance 与视觉层级应一致。

### 操作状态与反馈

按组件与任务列出**实际存在**的状态，不为每个元素机械凑齐同一张表。常见包括默认、hover（有指针时）、键盘焦点、按下、选中、禁用、加载、空、部分数据、成功、失败、离线与权限不足。

- 反馈靠近动作发生处；跨页面或延迟结果提供可找回的状态与通知。
- 破坏性操作按可逆性、影响范围与误操作成本选择确认、撤销、权限或二次核验；高风险操作不能因“可撤销”省略必要保护。
- 乐观更新必须处理服务器失败、冲突和回滚，并让用户理解最终状态。
- 加载说明在等什么；长时间或高成本任务提供真实进度、取消或恢复能力。进度未知时不要伪造百分比。
- 状态颜色、图标、文案与 ARIA/语义表达同一结果；空状态说明原因、下一步与是否可恢复。

### 长滚动与整页结构

营销页与品牌站常用一次长滚动承载一段叙事。此时“页”的边界由视口决定，单屏截图会系统性漏掉断裂，验收必须按整页推进：

- **整页截图按目标宽度滚完**，覆盖首屏、中段与尾段；断裂多出现在后两者。
- **逐段核对三项继承**：背景场是否延续、锚线在滚动中是否稳定、换场点是否有结构事件。判据与可用的结构手段见 `02`「长滚动页面」。
- **固定元素单独查**：sticky 导航、视差层、滚动动效经过文字时，按最坏帧检查对比；固定导航不得遮住锚点目标。
- **推进感可被描述**：读者能否说出自己在第几段、还剩多少。连续等大的色块会让长页失去定位，也让强调失效。
- **首屏不代全页**：首屏通常是投入最多的一屏，它不能代表中段与尾段的判断质量。

### 无障碍、触控与性能

- **标准与范围**：先声明目标 WCAG 版本、符合性（conformance）级别和适用页面/组件。文字与必需非文本元素的不同对比要求见 `04`「色彩职责、可读性与输出」；图像背景按最坏区域检查。
- **不只靠颜色**编码；结合色觉模拟与真实界面检查，去饱和只作辅助。
- **键盘与焦点**：所有功能可用键盘完成，焦点可见、顺序符合任务、无键盘陷阱。并非每个复合组件内部项都必须进入 Tab 序列，单选组、工具栏等可采用方向键与 roving tabindex。
- **语义与替代内容**：标题结构反映内容关系，表单有可访问名称与关联错误，图片按职责提供替代文本或标记装饰，状态变化能被辅助技术获知。
- **触控与文字扩张**：按目标平台和适用 WCAG 检查目标尺寸、间距、手势替代、系统字号与文字放大；不能只给桌面 hover 或要求精细拖拽。
- **系统与真实条件**：按需检查减少动效、高对比、深浅色、弱网、离线、旧设备、强光、单手与注意力中断。
- **性能是设计条件**：图像尺寸/格式、字体数量与加载、动画和脚本会影响可读与可操作时间。用真实目标设备与网络检查加载、布局位移和交互响应；不凭 Lighthouse 单次分数宣称真实用户体验通过。

### 桌面、平板与移动端的结构重构

响应式不是等比缩放，而是按宽度、输入方式与任务重排〔硬〕。在每个关键宽度检查：

| 问题 | 可选重构 | 必须保护的关系 |
|---|---|---|
| 导航与当前位置 | 横向导航、抽屉、底部标签、面包屑或返回栈 | 当前项、返回路径、主任务入口 |
| 并列与比较 | 多栏改少栏/单列、锚点跳转、逐项详情 | 同一比较轴、顺序、共享口径 |
| 表格与密集数据 | 减列、列优先级、记录卡、详情页或有提示的横向滚动 | 行列标签、单位、比较关系；复杂数据表可保留滚动并提供固定标签等辅助 |
| 图像与文字区 | 改裁切、改比例、重排图文、替换资源 | 主体识别、文字避让、必要细节 |
| 指针特有交互 | hover 改点击/聚焦，浮层改内联或整页 | 所有功能在触控与键盘下仍可达 |

**排印风险**：字体加载与回退、最长文案、系统字号、文字缩放、容器固定高度和标题断行，见 `03`「屏幕与移动端排印」。检查中间宽度，不能只验桌面与最窄屏两个漂亮断点。

**交付物**：可运行页面/产品、必要源文件、真实内容与资源、断点和组件状态说明、目标浏览器/设备清单；静态 mockup 只能作为方案或视觉预览。

**不可省证据**：在声明的浏览器与宽度检查重排、溢出、裁切和字体加载；用真实或最长合理文案；走查关键状态并用键盘完成主任务；在实际目标触控设备检查手势、目标尺寸和系统文字设置。另按「整页与序列检查」做整页长截图与缩略图带审阅，覆盖中段与尾段，不只首屏。模拟器可覆盖部分环境，报告须列明；未测实机不得宣称实机通过。另检查关键网络与性能条件。

**最容易假通过**：静态 mockup、单张全屏截图或一次自动化审计，被当成响应式、交互、键盘、屏幕阅读器和真实性能全部通过；或只看首屏与整页长截图，当作滚动、粘性导航与视差后的状态也已通过。

## 六、长文档 / 报告 / PDF

**版面重点**：连续阅读要控制同类页面的累积疲劳与位置感。章节开场可通过换页、尺度或密度变化建立边界，不机械增加留白页；同时避免另一极端——每章换一套版式，使长文档读成合集。目录、书签、页眉、编号与交叉引用帮助定位；跨页表格重复表头并保持行列语义，图表与正文互引，注释系统一致。

**交付物**：目标阅读/打印 PDF、必要可编辑源文件、目录与书签、链接资源或附件；有辅助技术使用需求时提供正确标签、阅读顺序、语言、替代文本与可导航结构，而非只有视觉 PDF。

**不可省证据**：导出后检查实际分页、目录/书签与页码、链接、表格断裂、孤行、图注跟随、字符复制与检索、字体嵌入/替换、图像质量和打印边距；把全篇按顺序排成缩略图带，检查章节之间的继承与转折依据（见「整页与序列检查」）；在声明的阅读器与设备查看。需无障碍或印刷生产时分别增加标签树/阅读顺序与印前检查。

**最容易假通过**：在写作软件里看排版；用文件可打开或首页正常，代替分页、字体、链接、复制、辅助技术与打印检查。

## 七、图像 / 摄影 / 3D 概念图

**版面重点**：主体语义、关键结构、视角与透视、光照、材质、背景竞争、裁切和文字预留。生成或拍摄前先写清图像职责、事实来源、必要细节、目标宽高比与替代裁切；详见 `04`。

**交付物**：实际图像文件及必要分层/源文件、真实来源与生成/重建属性、作者或许可信息、目标尺寸与色彩空间、输出格式和裁切版本。准确文字、标签与数据优先由排版工具后期加入。

**不可省证据**：查看实际输出的主体识别、比例结构、透视、接触、光向、反射、材质、边缘/文字伪影；按最终显示或印刷尺寸检查细节和有效分辨率，并核验来源、标注与许可。只有提示词时，交付状态是图像指导，不是成品图已检查。

**最容易假通过**：缩略图“氛围对了”便通过；把生成成功当作结构、事实、许可和输出规格通过。

**边界**：建模、绑定、材质节点、摄影现场与渲染属于专用工具和专业人员；本技能提供艺术指导与验收判据，不冒充制作记录。

## 八、视频 / 动态视觉

**版面重点**：每个镜头先明确职责：建立空间、呈现动作、提供证据、解释细节、转折或收束。镜头间通过因果、对位、递进、打断或时间跳跃连接；景别、视角与长度变化服务信息增量，不为“节奏”随意切镜。

开拍/制作前确定画幅、字幕与界面安全区、观看设备、是否无声播放及必要多版本。连续性检查动作方向、视线、轴线、主体位置、速度、光线与声音空间；有意的跳切应可辨且不损害任务理解。字幕检查出现时机、停留、断行、说话者与背景对比；关键信息不能只靠声音或瞬时画面。

**交付物**：目标编码/画幅/帧率成片、必要无字幕与多语言版本、字幕文件、封面/静帧、音频与素材授权、可编辑项目及字体/链接资源（按合同需要）。

**不可省证据**：在目标播放器按实际帧率完整观看，检查镜头入出、动作与方向连续、闪烁跳变、字幕时机和可读性、音画同步、响度与结尾；另做无声观看和减少动效/静态替代的必要检查。交付前复看编码后的文件，不只看时间线。

**最容易假通过**：只看关键帧、静帧拼图或编辑时间线；它们不能证明完整播放、编码、节奏、字幕或声音。

## 九、数据图表 / 信息图

**版面重点**：论证型信息图建立可辨的阅读入口与顺序；检索型 dashboard、对照矩阵可有多个有序入口，不强加单一路径。图呈现关系与规模，文解释口径、来源与推论；图表构造见 `04`「图表与信息图」。

**目标尺寸**：按手机、投影、栏宽或打印尺寸检查标签、图例、线型、数据点和注释。读不完先删单元、改编码、改表格或拆分，不靠缩小字号；交互图表还需提供键盘、触控和必要的文字/表格替代。

**交付物**：目标格式图表/信息图、可核验数据与口径、来源、必要可编辑源文件和替代文本/数据表；示例、估计与预测值明确标注。

**不可省证据**：复算关键值，核对标签、排序、单位、总和、基线、样本与不确定性；在目标尺寸和实际输出中检查视觉编码与注释，验证颜色之外的区分和替代内容。

**最容易假通过**：默认尺寸下看图；用渲染成功代替数据复算、目标尺寸可读性和无障碍检查。

## 十、跨媒介转译

跨媒介项目共享主张、核心概念与品牌语义，但应重新判断每种媒介的注意力、交互、时间与信息容量。

分别明确：

- **不变项**：主张、事实、关键识别关系、必要限定。
- **重构项**：信息顺序、密度、版式、镜头、交互、阅读时长。
- **媒介新增风险**：投影可读性、移动端断点、印刷裁切、视频连续性、加载与性能。

共享的是设计逻辑，不是版式。把一张海报机械拆成 PPT 页面，或把静态画面平移到视频，得到的是缩水版，不是转译。

短例：若展览概念是“修复痕迹让时间层可见”，展陈可用真实观看距离与材料层叠，出版物可用连续局部与注释，网页可用按需揭示层次。三者共享概念，但不应复制同一构图。

交付记录应分别列出各媒介的检查状态。不能用网页截图替代移动端检查，不能用 PPT 渲染替代视频完整播放，不能用单页检查替代全稿验收。各媒介的整页视图也不互相等价：网页长截图、全稿缩略图、跨页拼版、成片完整播放，各自只证明自己的媒介。

跨媒介转译最容易被忽略的一致性问题是**常量被版式绑架**：某个媒介里成立，是因为它依赖了那种版式的具体尺寸与顺序。判断方法是把同一套常量放进另一种媒介的信息容量里——如果它立刻失效，说明转译的其实是版式，不是品牌。
