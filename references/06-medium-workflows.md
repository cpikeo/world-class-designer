# 媒介版面判断、交付契约与验收

本文件拥有：交付状态用语、各媒介的版面重点与不可省证据、跨媒介转译、最容易假通过的地方。修订协议与验证分级见 `07`，版面结构原理见 `02`。

先确认实际交付物，再选择媒介重点与验收方式。本文件定义最低边界，不要求所有任务都走完整流程。

## 一、通用交付契约

明确**交付物、使用环境、关键约束、主要风险与实际检查范围**。按需交付源文件、成品、预览、脚本或提示词；不把计划或静态示意稿称为最终成品。

状态用语（全包唯一出处，其他文件只引用、不重复定义）：

| 状态 | 含义 |
|---|---|
| **方案 / 提示词** | 尚未形成目标媒介成品，只能评价方案本身 |
| **未验证** | 没有真实产物、渲染、数据核验或环境检查可供判断 |
| **预览 / 部分检查** | 已有产物，只检查了明确列出的页面、状态、尺寸或镜头 |
| **已检查** | 已在声明的环境和范围内查看真实结果 |
| **可交付** | 必要内容完整，主要交付阻断已处理，剩余风险已披露 |

状态必须带范围〔硬〕。无范围的“已检查”不算证据。

生产成功后按 **真实产物 → 目标环境与尺寸 → 关键异常范围 → 必要修正 → 复查受影响部分** 推进。工具生成文件不等于完成验收。

## 二、杂志与出版物

**版面重点**：跨页的构图关系（对页四种关系、中缝轴线、左右力矩）见 `02`「跨页构图」。印刷语境下另需注意：订口（内侧）与切口（外侧）承担不同职责——内侧放可牺牲的边缘内容，外侧放导航与旁注。栏系统决定图版的可能性：单栏给长文与满幅图，双栏给正文，三栏只给短栏内容（目录、注释、数据）。栏目节奏由开场大图页、正文页、引文页、图版页交替形成，不是每页同构。

**图纸关系**：图注应与图绑定，位置全篇统一；图版页允许图像越过一栏或整个版心，但需在下一跨页补偿回来。目录与页码是信息架构的自我说明，不是装饰。

**不可省证据**：按最终开本与装订检查跨页拼合（中缝是否吃掉内容或人物面部）、出血与裁切位、页码与页眉在奇偶页的位置、连续阅读时的行长与灰度是否稳定、字体在目标纸张与油墨下的字重表现。

**最容易假通过**：在单页视图里逐页看，看起来每页都好；拼成跨页后中缝压住字、左右页边距不等、图版页与正文页的版心对不上。

## 三、演示文稿 / PPT

**版面重点**：一页只承担一个主张。幻灯片不是文档的容器，把段落搬上屏是最常见的失效。焦点必须在**目标观看距离**下成立——**你在 100% 缩放下看到的两级字号差，在会议室后排往往消失**。页面角色需要区分：主张页、证据页、数据页、转折页、停顿页。停顿页（低信息密度、单一图像或一句话）是节奏工具，不是浪费。

**密度判断**：投影页的信息量上限远低于印刷页。判断标准是“在目标屏幕尺寸与观看距离下，主张是否需要寻找才能读到”，而不是“这页排得满不满”。验证方式是缩到目标视距下的等效大小，不是相信设计稿。

**不可省证据**：按目标画幅渲染完整文稿；查看全稿缩略图（节奏）、首屏、关键转折、高密度页、数据页、结尾与所有异常页。检查字体替换、溢出、遮挡、图表口径、脚注、页码、跨页一致与变化。

**最容易假通过**：只看单页或编辑画布；只看自己屏幕；模板里塞满占位文字时看起来整齐，填入真实长文案后全部溢出。

## 四、海报 / 封面 / 展陈

**版面重点**：观看距离决定一切。中远距离上，读者能带走的是**轮廓与很少的几个词**，不是句子——所以标题要短到能被一眼读完，并成为一个可辨认的形；次级信息在近距离才被读到。主视觉占幅、标题冲击与视觉识别是三个需要同时成立的指标。观看方向（贴墙、悬挂、平铺）、环境光、停留时间都会改变判断。

**信息量上限**：海报不是传单。主信息通常只有一句会被带走；需要交代更多，就换媒介或改用二维码/展签。

**不可省证据**：按最终尺寸或退到实际观看距离检查（打印缩小样，或退到实际距离看屏幕）；同时确认缩略图识别度与近距离细节；检查出血、裁切、安全区、分辨率、色彩模式、字体是否转曲、链接资源是否齐全。

**最容易假通过**：在屏幕上大幅缩小看，觉得“很有冲击”；实际印出来或贴到墙上后，标题边缘糊、细节全丢、远看只剩一块色。

## 五、网页 / 产品界面

**版面重点**：首屏是一个承诺加一个入口，不是一个轮播和一堆按钮。纵向阅读需要锚——固定导航、章节标记、进度指示，让人知道自己在哪里。

**内容与界面的区别**：内容页服务阅读（行长、层级、连续），应用界面服务操作（目标可达、状态可见、反馈明确）。把阅读页做成仪表盘，或把工具做成文章，都会失焦。两者的验收方式也不同：读页看“读完了吗”，界面看“做成了吗”。

### 信息架构与交互层级

信息架构要同时处理两类对象，它们常常不同构：**内容层级**（读者要知道什么，谁包含谁）与**任务层级**（用户要完成什么，步骤如何串）。硬把两者套进同一棵树，会出现“从内容看该在这里、从任务看该在别处”的页面。

- **导航分三层**：全局（跨站点，少而稳）、局部（当前区块内的兄弟页）、上下文（相关内容、下一步）。三层的视觉权重应当不同，否则用户不知道自己在哪一层。
- **深度与广度的取舍**由任务频率决定：高频入口放浅，低频长尾可以放深。层级越深，迷路成本越高；越宽，首层的认知负担越大。没有普适解，只有与该产品使用节奏匹配的解。
- **一个界面只承担一个主任务**。并行任务靠布局分区或流程分步解决，不能靠“都放首页”——首页塞满入口等于没有入口。
- **交互层级**要能被看见：可点、不可点、当前所在、下一步去向，四个状态在视觉上应可分，不能都靠文字说明。

### 操作状态与反馈

界面不是静态画面。每个可操作单元至少交代五种状态：**默认 / 悬停或聚焦 / 进行中 / 成功 / 失败**，另加**空**与**禁用**。

- 反馈位置靠近动作发生处；跨页面的结果需要持久通知。
- 破坏性操作，**确认**与**可撤销**至少具备一个。
- 乐观更新必须能回滚，且回滚时用户看得出发生了什么。
- 加载状态要说明在等什么，而不是只转圈；超出可感知等待时应有进度或可取消。
- 状态文案应与视觉同源：颜色说成功、图标说失败，比没有反馈更坏。
- 空状态是设计对象，不是缺失：它要说明为什么空、能做什么。

### 无障碍与真实使用场景

- **对比度**：正文与关键控件按 WCAG AA（正文 4.5:1，大字号 3:1）；图像上的文字按最坏区域测，方法见 `07`「证据口径」。
- **不只靠颜色**编码；色觉差异下仍要可辨（去饱和后重看，见 `04`「色彩判断」）。
- **键盘可达**：所有可操作元素可 Tab 到达、焦点可见、顺序与视觉顺序一致。
- **语义结构**：标题层级不跳级、表单有标签、图片有替代文本、错误提示与被控字段关联。
- **尊重系统设置**：字号放大、减少动效、高对比模式、深浅色。
- **真实场景**：单手操作、弱网、旧设备、强光下、屏幕有划痕、注意力被打断。设计稿里一切成立，往往是因为这些条件都不存在。

### 桌面、平板与移动端的结构重构

响应式不是缩放，是**重排**〔硬〕。每个断点要回答四个问题：

| 问题 | 常见重构 |
|---|---|
| 导航放哪 | 顶部横向 → 抽屉／底部标签；层级深时改面包屑或返回栈 |
| 并列关系怎么保 | 三栏 → 两栏 → 单列；多列对比改上下叠放，但要保留同一条比较轴 |
| 表格怎么办 | 减列 → 转卡片 → 改逐项详情。不能靠横向滚动解决信息密度 |
| 悬浮交互如何替代 | hover 展示 → 点击展开；浮层 → 内联展开或整页 |

**两个典型错误**：把桌面版等比缩小，得到一屏挤在一起的窄条，并置的对比关系被破坏；或把移动版直接拉伸，得到大片空白与超长行。判断标准是：**在目标宽度下，内容之间的相对关系是否还在**。

**排印的真实风险**：Web 字体加载失败、回退字体造成版式跳变、最长文案溢出、系统字号放大后截断。判断方法见 `03`「屏幕与移动端排印」。

**不可省证据**：在目标浏览器检查桌面、平板、窄屏与必要的中间宽度；用真实或最长文案检查溢出与遮挡；走查上列全部操作状态；用键盘完整走一遍主任务；在实机（非模拟器）上看 1x/2x 渲染与触控目标；检查图片加载与字体回退。

**最容易假通过**：单张静态 mockup 或全屏截图。它不能证明响应式行为、交互路径、状态变化、键盘可达性或性能。

## 六、长文档 / 报告 / PDF

**版面重点**：连续阅读的疲劳点不在某一页，而在**连续同类页面的累积**——章节开场通常需要呼吸（留白、换页、尺度变化），否则读者在几十页后会失去位置感。层级导航依靠目录、页眉、编号系统的稳定，而不是靠加大加粗。表格跨页应重复表头；图表与正文必须互引（“见图 3”而不只是放一张图）。注释系统一旦建立就应全篇一致。

**不可省证据**：导出目标格式后检查实际分页、目录与页码对应、表格断裂、字符编码、字体嵌入与替换、打印边距、孤行与页末孤字。

**最容易假通过**：在写作软件里看排版。导出 PDF 后分页改变、字体回退、表格被切断、目录页码错位。

## 七、图像 / 摄影 / 3D 概念图

**版面重点**：主体语义、关键结构、主导视觉关系、视角与透视、光照逻辑、材质可信度、背景竞争、画面裁切。若图像将进入版面，还需在拍摄/生成阶段就预留文字区与裁切余量。

**不可省证据**：观察实际输出中的主体识别、比例与结构、透视、接触关系、光向、反射、材质、边缘伪影、文字伪影，以及目标尺寸下的表现。只给出提示词时，交付范围是图像指导，不是成品图质量承诺。

**最容易假通过**：用缩略图看“氛围对了”。放大后结构错误、接触阴影缺失、材质是贴图、文字乱码。

**边界**：建模、绑定、材质节点、渲染与时间线属于专用工具与技能；本技能在此交付的是艺术指导、分镜意图与验收判据，不延伸为制作系统。

## 八、视频 / 动态视觉

**版面重点**：镜头承担叙事职责，不是素材串联。景别与视角的变化要有理由；视觉节奏由信息密度与情绪强度共同决定，不是每个镜头同样长度。字幕安全区与画幅比例在开拍前就要定。

动作的物理依据见 `04`「动效」；本文件只补充视频媒介特有的判断：镜头之间的**关系**（因果、对位、递进、打断）比单个镜头的好坏更能决定成片。

**不可省证据**：按实际帧率完整播放或检查时间线；观察镜头进入与离开、动作连续性、主体位置、闪烁与跳变、字幕可读性、音画同步、音量变化。

**最容易假通过**：只看关键帧或静帧拼图。它不能证明运动连续性、节奏或声音。

## 九、数据图表 / 信息图

**版面重点**：信息图要有一条**主导**阅读路径，而不是把图、数字、说明均匀铺开。多区并置可以成立，但进入顺序必须可辨（见 `02`「结构组合」）。图文协同的分工是：图说关系与规模，文说口径与推论。

**密度上限由目标尺寸决定**：把成稿缩到目标宽度（手机、投影、栏宽），看读者是否还能按预期顺序读完每个单元。读不完就删单元、改表格或拆页——不要靠缩小字号解决。

图表本身的构造规则见 `04`「图表与信息图」；版面层面需额外判断：图表在页面中的尺寸是否足以读出标签；图注是否与图绑定；图表标题是否说了结论而不是变量名。

**不可省证据**：复算关键值；核对标签、排序、单位、总和、基线与样本范围；缩至目标尺寸检查图例与注释是否仍可读。未提供或未核验的数据必须明确标记为示例或假设。

**最容易假通过**：在图表工具的默认尺寸下看。缩到幻灯片或手机宽度后，标签重叠、图例消失、数据点无法分辨。

## 十、跨媒介转译

跨媒介项目共享主张、核心概念与品牌语义，但应重新判断每种媒介的注意力、交互、时间与信息容量。

分别明确：

- **不变项**：主张、事实、关键识别关系、必要限定。
- **重构项**：信息顺序、密度、版式、镜头、交互、阅读时长。
- **媒介新增风险**：投影可读性、移动端断点、印刷裁切、视频连续性、加载与性能。

共享的是设计逻辑，不是版式。把一张海报机械拆成 PPT 页面，或把静态画面平移到视频，得到的是缩水版，不是转译。

短例：若展览概念是“修复痕迹让时间层可见”，展陈可用真实观看距离与材料层叠，出版物可用连续局部与注释，网页可用按需揭示层次。三者共享概念，但不应复制同一构图。

交付记录应分别列出各媒介的检查状态。不能用网页截图替代移动端检查，不能用 PPT 渲染替代视频完整播放，不能用单页检查替代全稿验收。
