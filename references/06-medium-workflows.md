# 跨媒介工作流与交付契约

先识别作品的真实使用环境，再调用该媒介的规则。以下是每类任务的最小交付契约；不是要求用户看到完整流程。

## 演示文稿 / PPT

**产物**：可编辑演示文件；复杂任务另附页面叙事大纲、关键视觉说明和预览 PDF/图片（取决于工具能力）。

**设计重点**：全案主张和页面角色、投影距离下的标题与关键数据、页面节奏、视觉系统的一致与变化、图表证据、中文排印、图像裁切和安全边界。

**验证**：按真实画幅渲染完整文稿；查看总览缩略图、首屏/高潮/高密度页/结尾和所有异常页面；检查字体替换、溢出、图层遮挡、图表口径、脚注、页码与跨页节奏。只看单页或 PPT 编辑画布不算完整检查。若不能渲染，明确标为未验证。

## 长文档 / 报告 / PDF

**产物**：可编辑源文件与目标格式成品（按请求），包含必要目录、标题层级、表格和引用。

**设计重点**：连续阅读、段落节奏、标题导航、行长、脚注、表格跨页、分页孤行/寡行、页眉页脚、目录与附录关系。内容密度应适合查阅和连续阅读，不能把 PPT 的大标题风格直接套到长文。

**验证**：导出 PDF 或目标格式，检查目录/页码跳转、分页、表格断裂、字体嵌入或替换、字符编码、打印边距与可读性。无法检查字体嵌入或最终导出时不要声称已验证。

## 网页 / 产品界面

**产物**：可运行页面或所需源代码；交互任务提供关键状态与操作路径。

**设计重点**：真实断点下的重排、内容顺序、页面/应用界面差异、导航和行动入口、加载/空/错误/焦点/禁用状态、键盘访问、图片加载、性能和可访问性。

**验证**：在真实浏览器检查桌面、窄屏和必要中间断点；检查实际文本长度、水平溢出、标题遮挡、控件与键盘路径、空状态和错误状态。只检查静态 mockup 不代表交互已验证。

## 海报 / 封面 / 展陈

**产物**：目标画幅的成品图及适用时的可编辑源文件。

**设计重点**：观看距离、停留时间、环境光、观看方向、主焦点、字级、图像占幅、裁切和阅读路径。海报可以极端、单焦点或高密度，但关键内容必须在实际观看距离可读。

**验证**：按最终尺寸查看；同时检查缩略图识别与近距离细节；确认出血、裁切、安全区、分辨率、色彩模式和字体/链接资源（适用时）。

## 图像 / 摄影 / 3D 概念图

**产物**：明确画幅、主体、构图、光线、材质和风格的生成指令；如有图像工具，再交付实际图像。提示词不等于已生成的成品。

**设计重点**：任务语义、主体身份、关键结构、一个主导视觉关系、视角与空间、光照和材质可信度。减少无效形容词；必要文字通常在生成后准确排版。

**验证**：检查主体与结构、透视、接触关系、光向、反射、材质、边缘伪影、文字伪影、裁切和目标尺寸表现。未看到图像时只能评价提示词，不能评价成品质量。

## 视频 / 动态视觉

**产物**：按任务交付脚本/分镜、镜头与运动说明、关键帧/资产、时间线或最终视频。须明确实际交付范围。

**设计重点**：每个镜头的叙事职责、景别与视角、动作起因、运动方向与速度、镜头间连续性、视觉节奏、音画关系、字幕可读性与信息安全边界。不要把静态海报直接逐帧平移，也不要让每个镜头都持续运动。

**验证**：按实际帧率完整播放或检查时间线；查看镜头进入/离开、动作连续性、主体位置、闪烁/跳变、字幕安全区、音画同步、音量变化及关键帧。只看静帧不能证明动态连续性或音画同步。

## 数据图表 / 信息图

**产物**：图表或信息图，必要时附数据口径、单位、来源和限制。

**设计重点**：先定义问题和数据关系，再选编码；保留尺度、基线、单位、样本、期间和必要限定。图形不得暗示数据不支持的因果或精度。

**验证**：复算关键值；核对标签、排序、单位、总和、基线和样本范围；缩到目标阅读尺寸检查标签与图例。若数据未提供或未核验，应明确标记假设或示例数据。
