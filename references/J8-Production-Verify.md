# J8 · Production & Verify — 生产底线与交付

> 这是唯一的"硬规则"区：可访问、信息诚实、一致性、生产可靠性不可谈判。
> 底线之上的一切，归 J1 判断管辖。

---

## 1. 硬底线（Floor，不过即改，无讨论）

### 1.1 可访问与可读
- 对比度：正文 ≥ 4.5:1；大字（≥24px，或 ≥18.67px/14pt bold）与图形/控件 ≥ 3:1。
- 标题层级有序；投影/打印场景同样成立（字号下限、灰阶可辨）。
- 图像有替代文本；不以颜色单独传达信息；屏幕动效尊重 `prefers-reduced-motion`。
- 键盘与焦点：可交互元素均可键盘到达，焦点顺序与视觉顺序一致，焦点态可见；触控目标 ≥24×24 CSS px（WCAG 2.2 AA 2.5.8）。
  合规以所列标准为依据，不凭印象宣称。

### 1.2 信息诚实（内容可靠性）
- **数字必有口径与来源**；刻度按图形类型判断，柱形/面积图基线从 0 起算（J5 §2.4）；截断显式标注；比例不误导。
- 不夸大、不移花接木、不删掉不利数据的口径——**误导性图表 = 错误内容**。
- 引用、案例、对比对象真实可溯；占位内容（示例数据）须显式标注。
- 生成式图像涉及真实人物、地点、产品或品牌时，须标注为示意或替换实拍（J5 §1.3）。

### 1.3 视觉一致性（全案同一世界观）
- 线宽、圆角、字距、间距、色彩关系全案成体系（判断卡为准）。
- 光源方向统一（图像类）；图标语言统一（J5 §3）；字号阶与排印声音不破（J4）；
  中西文混排规则全案统一（J4 §3）。

### 1.4 生产可靠性（媒介相关）
- 屏幕媒介：无布局抖动、资源克制、动效只动 transform/opacity（J3 §5）。
- 印刷/投影媒介：出血与安全边距、字体嵌入、色彩模式（CMYK/投影亮度）检查。
- 印刷装订：内侧需为装订损耗留足空间，具体数值以印厂与装订方式（骑马钉/锁线/胶装）为准，不套通用倍数；
  出血与安全边距以印厂规格为准（常用参考：出血 3mm、重要元素距裁切线 ≥5mm）。装订边是留白的生产约束，不是风格选择（J2 §0.1）。
- 反 AI 味通则见 J6 §6。

## 2. 交付姿态（Output Stance）

**默认输出 = 判断卡 + 方案本体**。过程属于内部，不属于交付。

- **L1 微任务**（修 bug/微调）：直接给结果。禁止诊断块、评分卡、套话。
- **L2 设计任务**（页面/幻灯/图文/方案）：
  1. 判断卡（模板 §5，20 行以内）
  2. 作品本体（含关键参数与理由——理由一句话即可）
  3. 一次强审查结果（J1 §6，只报"不过项"）
- **L3 立项/系统级**（品牌视觉体系/多页作品）：
  1. 判断卡（模板 §5，含 system 段的视觉语言）
  2. 原创视觉假设与样本校准声明（J6 §0、§7）
  3. 体系骨架（网格性格、版心策略、色彩骨架、排印声音、线与图标语言）
  4. 代表页样张 + 一次强审查
  5. 一条 lesson（J1 §7）

**作品形态**（原生可编辑格式优先）：网页 → HTML/CSS（交付断点与响应式行为、组件状态：默认/悬停/焦点/禁用/错误/空/加载，令牌以 CSS 变量按语义命名）；幻灯 → PPTX（或 HTML）；文档 → DOCX/PDF；
图形 → SVG，位图 → PNG/JPG。字体注明实际所用（J4 §0 回退链）；图像与字体随交付物嵌入或注明来源。

**禁止的交付物**：陪审团模拟、DQI 数值、七段式 YAML 诊断、"文明完整度"审计、
多 Agent 会签纪要、五轮迭代报告。这些是过程表演，消耗信任与注意力。

交付前最后一眼（非校验链，是交付纪律）：无过程表演 · 命名、rationale 与调用纪律见 §3。

## 3. 过程纪律（命名 · 决策记录 · 工具调用）

- **命名防通胀**：用版面、层级、色彩、材质、动效、排印这类直接词；"XX 引擎/系统"只在确有独立机制时使用；一案新增概念默认 ≤3 个，且须替代旧概念。
- **决策记录**：每个关键决定一行——"做了 X，因为 Y，放弃了 Z"（对照 J1 取舍语法）。
  归档 = 判断卡 + 3-5 行 rationale。**这是可编辑性的来源**：后来者改的是判断，不是猜谜。
- **最小调用**：一次高质量决策 > 多轮工具循环。搜索定点少量（不替代判断）；
  找图先有谱系判断（J6）；图像生成仅在 J1 §2.9 判定需要时（提示词含光/材质/画幅语言）；
  实现先判断卡后代码，组件化但不建"系统"；校验只跑一次强审查（J1 §6），
  不引入评分脚本/循环重试。

## 4. 小型单页快速通道（Starter · 无品牌资料）

改字、换数、微调不走本节（直接执行，J1 §4.1）。小型单页/单图，压缩为三步：
1. **一句话判断**：受众状态 + 目标 + 主张（每项一句）。
2. **一个样本锚**：J6 选一个，继承三项参数。
3. **交付 + 5 问抽查**（J1 §6 的 A 组）。
——跳过全链、跳过 YAML、跳过评分。质量来自判断的浓度，不来自流程的长度。

## 5. 判断卡模板（全案一次，后续继承；约 20 行内）

```yaml
judgment_card:
  strategy: { audience: "谁·场合·状态", objective: "单一目标", message: "约 20 字主张", insight: "对他成立的真相", visual_concept: "主张×洞察的视觉方向" }
  medium: "媒介 + 开本 · 密度档位 低|中|高"
  spatial: { occupancy: "版心占幅 + 理由", margins: "外>组间>组内", reading_path: "Z|F|单轴|焦点引导", gravity: "重心与配重" }
  system:
    grid: "J2 §1 网格性格（主/辅）"
    type: { voice: "J4 §0 一主一辅", scale: "J4 §1 比例与阶" }
    color: { base: "", support: "", accent: "注意力色·默认全案唯一（J1 §2.8）", semantic: "数据/状态/品牌规范色及其职责（无则写无）" }
    media: [{ kind: "图像|图表|图标", why: "不能没有它的理由" }]
  per_page: { focus: "主重心（默认唯一，多重心写明作用）", disappear: [ "消隐清单" ] }
  rhythm: "冷热拍 · 高潮数≈页数÷8（向上取整）· 母题与变奏维度"
  not_doing: [ "明确放弃的三件事" ]
```
