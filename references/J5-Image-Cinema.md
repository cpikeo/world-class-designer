# J5 · Image · Chart · Icon — 图像、图表与图标

> 三者都不是默认项（J1 §2.9）。要么增强叙事、质感或理解，要么不存在。
> 图像给**感受**，图表给**证明**，图标给**指引**——用错了就是装饰。

---

## 1. 图像（Image）——感受与叙事

### 1.1 必要性（先过 J1 §2.9）
需要建立实物感/情绪/人物/空间时才用。**好的排印 + 留白常优于凑图**；
一页图像 ≤2 张（图墙 = 无判断）。

### 1.2 摄影与图像语言（选定后全案统一）
- **叙事角色**：器物（质感证明）/ 记忆（情绪残留）/ 角色（人的关系）/ 象征（符号化主体）。
- **裁切与尺度**：大胆裁切优于完整展示；一张图独占对角或整栏，优于三张等分。
- **光影一致**：全案光源方向统一；接触影是"真实"的第一证据；禁止无光源泛光。
- **色调整合**：图像色调并入 J3 色彩骨架（它是色彩系统的一部分，不是独立滤镜）。
- **图文关系**：图注小字灰阶、紧贴图缘；图与主张直接相关，答不出"它证明什么"就删。

### 1.3 屏幕媒介的镜头感（按需）
画幅比即情绪（2.39:1 史诗 / 16:9 叙事 / 4:5 器物）；景别跳两级以上 = 剪辑事故。
滚动即运镜见 J3 §6。

## 2. 图表（Chart）——关系的证明

### 2.1 先选表达，再画图（图表必要性决策）
| 要表达 | 用什么 |
|:---|:---|
| 一个数 | **大数字排印**（J4 §4.1），不画图 |
| 2-5 个数 | 字段行 / 数字对齐行（J4 §4.2） |
| 精确比较 / 多维 | **表格**（常优于图，J4 §4.2） |
| 趋势 / 变化 | 折线（≤3 条系列） |
| 构成占比 | 堆叠条 / 单条占比（≤5 段） |
| 排序比较 | 横向条形（比饼图诚实） |
| 分布 / 相关 | 点图 / 散点（慎用，先减数据） |

### 2.2 感知层级（Cleveland-McGill —— 图形形式的诚实度）
**沿同一刻度的位置 > 长度 > 角度 > 面积 > 体积 > 饱和度。**
- 需要精确比较时用位置与长度（点图/条形）；角度（饼图）只用于 ≤3 段的粗略构成；
  面积/体积只作量级暗示，不承载精确读数。
- 一张图只编码一种主视觉通道；第二通道只做辅助（如颜色标出"看这条"）。

### 2.3 极简图表工艺（数据墨水比优先）
- **先减数据**：砍到回答主张所需的最少系列/最少刻度。
- 无网格线或仅极细基线；坐标轴仅留必要。
- **标注层是最强的图形元素**：直接在图上标注系列名、关键点与 So-What 线，去掉图例；
  标注排印服从 J4（小字、字距、对齐）。**需要图例才能读懂 = 表达没做完。**
- **小型复用（small multiples）**：同构小图对比多对象，优于一张拥挤大图。
- **一个强调色**：全图中性灰阶，只有"要读者看的那条/那段"用强调色（J3）。
- 数字标签直接放图上，不让人查轴；单位与口径写全。
- **来源行必有**（小字灰阶）：数据出处 + 时间口径。

### 2.4 信息诚实（底线，J8 §1）
坐标轴必须从 0 开始（截断需显式标注）；比例不失真；不为戏剧性放大差异；
不确定度（如有）要呈现——**误导性图表等于错误内容**。

## 3. 图标（Icon）——指引，不是填空

### 3.1 必要性（默认无图标）
- 图标只服务三件事：**动作**（可点）、**类别**（速辨）、**状态**（速读）。
- **文字标签更清楚时，用文字。** 一行四个图标带标签、每段开头加图标 = 填空式装饰，删。
- 一页图标 ≤5 个；图标密集的信息改用字段行与编号（J2 §4）。

### 3.2 线性图标语言（选定一套，全案统一）
- **线性优先**：描边风格，禁混填充风格。笔画统一 `1.5px @ 24px`（比例 ≈ 1/16）。
- **几何纯度**：圆、方、线的构造；圆角统一（2px @ 24px 一档）；端点统一（平头/圆头选一）。
- **光学对齐**：24px 网格 + 2px 内边距；与文字组合时对齐 x-高度/视觉中心，不机械对齐框。
- **尺寸档位**：16 / 20 / 24 三档；同界面不混档。
- **语义一致**：同一概念全案同一符号（如"设置"不换三种齿轮）。

### 3.3 反模式
拟物/多色/渐变图标、emoji 当图标、图标库随机混搭、笔画粗细不一、
用图标填补版面空隙、为"活泼"加圆角爆炸形。

---

## 4. 素材协同（一页之内的分工）

一页之内三者最多出现两种：图 + 字，或图 + 表，或字 + 图标行。
**图、表、图标同页竞争 = 三个重心**。分工原则：
图像管感受、图表管证明、图标管指引、排版管一切其余。
