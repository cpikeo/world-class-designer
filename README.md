# World Class Designer｜世界级设计智能

一个**判断层**技能：为具体受众、目标、内容和媒介作出准确、独特、可执行、可验证的设计决定。它回答“为什么这样设计、怎么判断它有效”；具体生产由专用技能与工具完成。

当前版本 **v11.1.0**。

## 它做什么 / 不做什么

**做**：任务理解与障碍判断、内容取舍、视觉概念、信息架构、版面结构与组合、排印、图像艺术指导、色彩、品牌语义、多页叙事、根因诊断、验收判据。

**不做**：不替代事实核验；不替代真实渲染与浏览器检查；不替代摄影、三维、视频的制作链；不生成模板库或自动布局引擎。

规则分三级，遇到冲突时先看等级：**〔硬〕** 违反即失效（事实、可读性下限、交付要求）；**〔验〕** 默认有效但可按任务调整，调整需说明代价；**〔境〕** 只能由受众、媒介、内容和真实输出决定。

## 安装

`SKILL.md` 是普通 Markdown 加 YAML frontmatter，任何能加载指令文件的 agent 环境都可以用。三种接法：

**1. 支持 skills 目录的环境**
把整个 `world-class-designer/` 目录放进去，确保 `SKILL.md` 在该目录根部，`references/` 保持同级。调用时使用技能名 `world-class-designer`。

**2. 以项目指令方式使用**
若你的环境使用项目级指令文件（如 Codex 的 `AGENTS.md`、Claude Code 的 `CLAUDE.md`），把 `SKILL.md` 内容并入该文件，并把 `references/` 放在项目内可读路径下。模型会按 SKILL.md 第 7 节的路由表按需读取参考。

**3. 无集成**
直接粘贴 `SKILL.md`，按任务附上一到两个 reference。适用于一次性使用或不支持技能加载的对话。

```

```

```

```

## 任务路由

SKILL.md 第 7 节是运行时路由；下表供人工查阅。

| 你现在要解决的问题 | 读哪份 |
|---|---|
| 任务理解、主张、内容取舍、概念、方案差异 | `01` |
| 信息架构、版面结构、结构组合、平衡、跨页与多页节奏 | `02` |
| 字体选择、层级、行长行距、断行、CJK 与混排、渲染检查 | `03` |
| 图片决策、摄影指导、取景光线材质、裁切、色彩、图表 | `04` |
| 品牌认知推导、文化表达、多页论证与高潮 | `05` |
| PPT／网页／出版／海报／视频／图表的具体版面与验收 | `06` |
| 修改既有作品、比较多版、验收分级、回退与停止 | `07` |

通常 `04` 与 `02`／`03` 同时需要；`06` 在形成实际交付物时必需；`07` 只在修订或验收时读。不要按编号全读。

## 使用纪律

- **每个主题只由一份文件拥有。** 跨文件用「章节名」引用，不按编号，改标题时才需要同步。
- **没有依据的数字不写成硬约束。** 字号倍率、标题行数、信息单元数、留白比例一类数值，必须带成立条件。
- **不做审美评分。** 质量结论只以可观察证据表达：`已检查〔范围〕，观察到〔现象〕，未检查〔范围〕`。
- 不得声称未经执行的渲染、盲测或验证已通过。

## 开发与评估

版本对比、真实作品评估、盲测与渲染检查在**独立开发工作区**完成，不属于本包。正式交付只保留运行所需的 `SKILL.md`、`references/` 与 `LICENSE`。

评估任务包与判据不随包分发。若需要重建，按 `07`「复跑与独立评估」的冻结任务包协议准备：固定输入事实、受众与约束，只改变技能版本，比较关键判断而非像素一致。
