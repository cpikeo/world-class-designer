# World Class Designer v9.1.0

以设计判断为核心的跨媒介视觉智能。

## 文件结构

- `SKILL.md`：统一判断主链、任务规模判断、参考路由和交付纪律。
- `references/01-judgment-and-concept.md`：任务判断、主张、概念与辨识度。
- `references/02-composition-and-tension.md`：构图、空间、视觉重量与动势。
- `references/03-typography.md`：中文/CJK、拉丁文与多语言排印。
- `references/04-image-colour-and-data.md`：图像、摄影、材质、色彩、动效和图表。
- `references/05-brand-and-narrative.md`：品牌、文化表达与多页叙事。
- `references/06-medium-workflows.md`：各媒介的交付范围和最低验证要求。
- `references/07-revision-and-validation.md`：根因修正、验收、回退与停止。

## 使用原则

先读 `SKILL.md`，按需读取一个主参考；只有跨域任务才增加参考。简单任务直做；修正基于真实故障，验证状态如实说明。

评估集、测试脚本、对照样本和测试日志属于独立开发工作区，不放进正式运行包，以避免增加常规上下文成本。
