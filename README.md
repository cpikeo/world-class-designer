## 它做什么 / 不做什么

**做**：任务理解与障碍判断、内容取舍、视觉概念、信息架构、版面结构与组合、出版级排印判断、摄影与图像艺术指导、色彩战略与输出校准、品牌战略与识别系统、视觉叙事、多媒介交付边界、根因诊断、验收判据。

**不做**：不替代事实核验；不替代真实渲染、浏览器、印刷打样与辅助技术检查；不替代摄影、三维、视频的制作链；不生成模板库、自动布局引擎或审美评分。

规则分三级（〔硬〕〔验〕〔境〕），定义与写作纪律只在 `SKILL.md` 第 2 节，本文件不复述。

## 安装

`SKILL.md` 是普通 Markdown 加 YAML frontmatter，任何能加载指令文件的 agent 环境都可以用。三种接法：

**1. 支持 skills 目录的环境**
把整个 `world-class-designer/` 目录放进去，确保 `SKILL.md` 在该目录根部，`references/` 保持同级。调用时使用技能名 `world-class-designer`。

**2. 以项目指令方式使用**
若你的环境使用项目级指令文件（如 Codex 的 `AGENTS.md`、Claude Code 的 `CLAUDE.md`），把 `SKILL.md` 内容并入该文件，并把 `references/` 放在项目内可读路径下。模型按 `SKILL.md` 第 7 节的路由表按需读取参考，读取量按任务规模封顶。

**3. 无集成**
直接粘贴 `SKILL.md`，按任务附上一到两个 reference。适用于一次性使用或不支持技能加载的对话。

```
用 world-class-designer 判断这份 16 页年报的版面结构：

```

```
用 world-class-designer 验收这版 PPT：
按 06 多媒介交付的不可省证据走，报告里写清检查范围与未检查项，不要给评分。
```

任务路由只有一处真源：`SKILL.md` 第 7 节「按任务读取参考」。本文件不另维护路由表。

## 开发与评估

版本对比、真实作品评估、盲测与渲染检查在**独立开发工作区**完成，不属于本包。正式仓库只保留运行和安装所需的 `SKILL.md`、`README.md`、`references/` 与 `LICENSE`；不附带测试脚本、基准数据、评估结果或生产依赖。

需要重建评估时，按 `07`「复跑与独立评估」的冻结任务包协议准备：固定输入事实、素材、受众与约束，只改变技能版本或模型条件，比较关键判断与真实产物，而非像素一致。
