# World Class Designer｜世界级设计智能

一个**判断层**技能：为具体受众、目标、内容和媒介作出准确、独特、可执行、可验证的设计决定。它回答“为什么这样设计、怎么判断它有效”；具体生产由专用技能与工具完成。

当前版本 **v12.0.0**。

## 它做什么 / 不做什么

**做**：任务理解与障碍判断、内容取舍、视觉概念与深度分级、信息架构、版面结构与力量分布、多重心与叠合、出版级排印与品牌字体系统、摄影艺术指导与系列一致性、色彩战略与推导、品牌识别常量与叙事、多媒介交付边界、能力核查与跨技能交接、根因诊断、验收判据。

**不做**：不替代事实核验；不替代真实渲染、浏览器、印刷打样与辅助技术检查；不替代摄影、三维、视频的制作链；不生成模板库、自动布局引擎或审美评分。

规则分三级，遇到冲突时先看等级：**〔硬〕** 违反即失效（事实、可读性下限、交付要求）；**〔验〕** 通常有效但可按任务调整，调整需说明代价；**〔境〕** 只能由受众、媒介、内容和真实输出决定。

## v12 的主要变化

v11 的判断机制与七文件架构保留不动；v12 补的是**表达深度**与**执行可信度**，不是规则数量。

- **力量分布从“平衡”扩到“多重心”**：主从、对峙、接力三种关系，四条纪律，以及不对称稳定的四组交换。新增层叠的可执行条件、高密度秩序的三条件、多页连续性（恒定锚 / 变奏轴 / 章节边界 / 重复元素合法化）。
- **字与图的关系成为独立判断**：让位、侵入、同构、分离四种关系，尺度博弈的三种解法，共用边缘与主体朝向。字体侧补选字依据链、中文字体四个语气变量、标题族与正文族关系、品牌字体五层结构与可变字体决策。
- **摄影从单张指导扩到类型与系列**：产品、静物、人文、建筑、自然五类的差异约束；六个统一变量、四种景别序列、三个一致性锚、参考图“只借一项”的纪律；真实质感的三处必查与材质清单。
- **色彩从战略扩到推导**：六类色源、明度骨架优先、色相偏移必须有源、面积节奏、材质落地；中性色的四级组织与低饱和层次；五条演进轴与“转折用断不用渐变”。
- **品牌补常量分层与延展方法**：语义 / 语法 / 资产三层常量，三种变量授权，常量的最小集，母题的变奏语法，多触点延展三问。
- **执行智能补两块硬缺口**：能力核查（能生成 / 能渲染 / 能测量 / 看不到什么）与跨技能交接八项契约，含“缺了会怎样”的下游失效说明。
- **验收闭环**：`07` 新增“从设计决定到验收证据”对应表——找不到对应决定的证据，说明这项检查没有判据。
- **五个完整案例**分布在 01–05，统一按“项目事实 → 设计问题 → 核心概念 → 视觉关系 → 具体设计决定 → 预期表达效果 → 真实产物验收依据”写，每个都标注“不可换的部分”，防止被当成样式复制。

## 安装

`SKILL.md` 是普通 Markdown 加 YAML frontmatter，任何能加载指令文件的 agent 环境都可以用。三种接法：

**1. 支持 skills 目录的环境**
把整个 `world-class-designer/` 目录放进去，确保 `SKILL.md` 在该目录根部，`references/` 保持同级。调用时使用技能名 `world-class-designer`。

**2. 以项目指令方式使用**
若你的环境使用项目级指令文件（如 Codex 的 `AGENTS.md`、Claude Code 的 `CLAUDE.md`），把 `SKILL.md` 内容并入该文件，并把 `references/` 放在项目内可读路径下。模型会按 SKILL.md 第 7 节的路由表按需读取参考。

**3. 无集成**
直接粘贴 `SKILL.md`，按任务附上一到两个 reference。适用于一次性使用或不支持技能加载的对话。

## 使用纪律

- **每个主题只由一份文件拥有。** 跨文件用「章节名」引用，不按编号，改标题时才需要同步。
- **没有依据的数字不写成硬约束。** 字号倍率、标题行数、信息单元数、留白比例一类数值，必须带成立条件。
- **不做审美评分。** 质量结论只以可观察证据表达：`已检查〔范围〕，观察到〔现象〕，未检查〔范围〕`。
- **验收证据必须对应设计决定。** 找不到对应决定的检查，不构成判据。
- 不得声称未经执行的渲染、盲测、能力或验证已通过。

## 开发与评估

版本对比、真实作品评估、盲测与渲染检查在**独立开发工作区**完成，不属于本包。正式仓库只保留运行和安装所需的 `SKILL.md`、`README.md`、`references/` 与 `LICENSE`；不附带测试脚本、基准数据、评估结果或生产依赖。

评估任务包与判据不随包分发。若需要重建，按 `07`「复跑与独立评估」的冻结任务包协议准备：固定输入事实、素材、受众与约束，只改变技能版本或模型条件，比较关键判断与真实产物，而非像素一致。
