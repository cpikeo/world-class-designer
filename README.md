# World Class Designer v9.0.0

正式 Skill 运行包。设计原则保持在核心指令与按需引用的领域参考之间；独立评估、测试用例、基线结果与测试日志不随正式包发布。

## 结构

- `SKILL.md`：高优先级的设计判断主链、运行纪律与参考路由。
- `references/01-judgment-and-concept.md`：概念与认知判断。
- `references/02-composition-and-tension.md`：构图、空间和动势。
- `references/03-typography.md`：中文与多语言排印。
- `references/04-image-colour-and-data.md`：图像、色彩、材质、光线、动效与数据图形。
- `references/05-brand-and-narrative.md`：品牌、文化与多页叙事。
- `references/06-medium-workflows.md`：跨媒介交付契约。
- `references/07-revision-and-validation.md`：统一修正和验证规则。

## 使用原则

先读 `SKILL.md`，按任务读取相关参考，而不是一次性展开所有细则。简单任务直接执行；复杂任务才调用更多领域知识。正式包不声称任何未执行的测试已通过。
