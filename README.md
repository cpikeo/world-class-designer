# world-class-designer · Design Intelligence

**世界级设计判断 · 艺术指导 · 编辑设计 · 信息设计**——不是网站模板生成器、
UI Design System、组件库、Layout Generator 或视觉规则执行器。

```
理解 → 判断 → 编排 → 构图 → 执行 → 校验

Audience → Objective → Message → Insight → Visual Concept
信息权重 → 焦点 → 空间结构 → 构图 → 排印 → 色彩 → 媒体 → 节奏
```

八位 Director 一体：Design · Art · Editorial · Information · Brand ·
Typography · Experience · Creative Strategy。

## 使用

从 [SKILL.md](SKILL.md) 开始：它是唯一的路由与宪法（六条根原则 + 八位 Director + 模块表）。
按媒介与任务激活 3-6 个模块（J1 永远、J2/J4 几乎永远，其余按需），**不要全量加载**。

## v6.0.0 升级要点

- **八位 Director 模型**：Typography Director 独立成模块 J4（补齐空号），
  J2 收敛为纯编辑空间（版心 · 网格 · 轴线 · 张力）。
- **判断链重排**为基准序：…空间结构 → 构图 → 排印 → 色彩 → 媒体 → 节奏
  （媒体晚于排印与色彩进入，服务于已成立的骨架）；补**补丁禁令**（回判断层重判，不做局部修补）。
- **最高裁决**新增第五条：Visual Concept > Styling。
- J1 判断卡新增 `type_voice` / `type_scale` / `rhythm_plan` 字段；取舍语法新增"统一 vs 重复"。
- J3 新增**灰度先行**与**注意力预算**；J5 新增**感知层级**（Cleveland-McGill）、
  标注层与 small multiples；J6 新增**数据新闻谱系**与中文编辑传统锚点；
  J7 新增**节奏曲线**与**全案终审四句**（统一而不重复 · 精致而不堆砌 ·
  充实而不拥挤 · 克制而不单薄）。

## 核心纪律

**Judgment > Rules · Meaning > Decoration · Content > Template ·
Clarity > Complexity · Visual Concept > Styling.**
先判断，再设计；先构图，再执行；能一次解决，不多轮修补。
删除 > 合并 > 简化 > 复用 > 新增。
